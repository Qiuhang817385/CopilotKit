## 什么是 A2UI？

A2UI 是 Google 推出的声明式生成式 UI 规范。它设计为：

- **基于 JSONL** - 使用 JSON Lines 格式进行流式传输
- **LLM 友好** - 易于语言模型生成
- **跨平台** - 可在任何平台上渲染
- **流式优先** - 为实时、渐进式渲染而构建

## 为什么选择 A2UI？

### 声明式方法
A2UI 允许智能体以声明方式描述 UI 组件，使 LLM 更容易生成动态界面，而无需了解实现细节。

### 流式支持
A2UI 在构建时考虑了流式传输，使智能体在生成响应时能够实现渐进式渲染，提供更好的用户体验。

### 跨平台
A2UI 规范可以在 Web、移动设备或任何其他平台上渲染，使您的智能体 UI 真正实现通用。
