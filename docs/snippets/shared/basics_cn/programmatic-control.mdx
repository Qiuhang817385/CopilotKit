## 概述

`useAgent` 钩子让您可以从任何 React 组件直接访问您的智能体。它让您实时访问智能体的状态、消息、执行状态，并允许您订阅自定义事件。

这使您能够构建自定义智能体仪表板、监控工具，以及响应智能体行为的交互式功能。

## 以编程方式运行智能体

使用 `copilotkit.runAgent()` 从任何组件触发您的智能体 —— 无需聊天 UI。这与 CopilotKit 内置的 `<CopilotChat />` 内部使用的方法相同。

```tsx title="page.tsx"
import { useAgent } from "@copilotkit/react-core/v2";
import { useCopilotKit } from "@copilotkit/react-core/v2";
import { randomUUID } from "@copilotkit/shared/v2";

export function AgentTrigger() {
  const { agent } = useAgent();
  // [!code highlight:1]
  const { copilotkit } = useCopilotKit();

  const handleRun = async () => {
    // 将用户消息添加到智能体的对话中
    agent.addMessage({
      id: randomUUID(),
      role: "user",
      content: "总结最新的销售数据",
    });

    // [!code highlight:2]
    // 运行智能体 —— 处理工具执行、跟进和流式传输
    await copilotkit.runAgent({ agent });
  };

  return <button onClick={handleRun}>运行智能体</button>;
}
```

### `copilotkit.runAgent()` vs `agent.runAgent()`

两种方法都可以触发智能体，但它们在级别上有所不同：

- **`copilotkit.runAgent({ agent })`** —— 推荐的方法。编排完整的智能体生命周期：执行前端工具、在工具请求时处理跟进运行，并通过订阅系统管理错误。
- **`agent.runAgent()`** —— 智能体实例上的底层方法。向运行时发送请求，但**不**执行前端工具或处理跟进。仅在需要直接控制智能体执行时使用（例如，使用 `forwardedProps` 从中断中恢复）。

### 停止运行

您可以使用 `copilotkit.stopAgent()` 停止正在运行的智能体：

```tsx title="page.tsx"
const handleStop = () => {
  copilotkit.stopAgent({ agent });
};
```
