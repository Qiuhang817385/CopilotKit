

## 什么是 CopilotKit Premium？
CopilotKit Premium 计划提供：
- 开源 CopilotKit 框架高级扩展的商业许可证（自托管或使用 Copilot Cloud）
- 访问 Copilot Cloud 托管服务。

CopilotKit Premium 专为使用 CopilotKit 构建生产级、智能体驱动的应用程序的团队而设计。
高级扩展功能 —— 如完全无头 UI 和调试工具 —— 可用于自托管和云托管部署。

Developer 等级的 CopilotKit Premium 始终免费。

## Premium 计划
- Developer – 永久免费，包括早期访问和有限的云使用
- Pro – 适用于在生产环境中构建的成长型团队
- Enterprise – 适用于具有高级可扩展性、安全性和支持需求的组织
## 早期访问
某些功能 —— 如无头 UI —— 最初将仅对 Premium 订阅者可用，然后随着框架成熟成为开源核心的一部分。
所有 CopilotKit Premium 订阅者都可以在新功能、工具发布后获得早期访问。

## 常见问题

### 如何访问高级功能？

#### 选项 1：使用 Copilot Cloud！
所有 CopilotKit Premium 功能都包含在 Copilot Cloud 中。

#### 选项 2：使用许可证密钥自托管。
访问高级功能需要公共许可证密钥。要获取您的密钥，请按照以下步骤操作。

<Steps>
  <Step>
    #### 注册

    在 [Copilot Cloud](https://cloud.copilotkit.ai) 创建一个*免费*账户。

    这不需要信用卡或使用 Copilot Cloud。
  </Step>
  <Step>
    #### 获取您的公共许可证密钥

    注册后，您将能够从左侧导航获取您的公共许可证密钥。
  </Step>
  <Step>
    #### 使用公共许可证密钥

    注册后，您将能够在 CopilotKit 实例中使用公共许可证密钥。

    ```tsx title="layout.tsx"
    <CopilotKit publicLicenseKey="your-public-license-key" />
    ```
  </Step>
</Steps>

### 我仍然可以使用公共许可证密钥自托管吗？

可以，您仍然可以使用公共许可证密钥自托管。只有当您想使用高级功能时才需要它，
要访问 Copilot Cloud，需要使用公共 API 密钥。


### 公共许可证密钥和公共 API 密钥有什么区别？

公共 API 密钥是您用于将应用连接到 Copilot Cloud 的密钥。公共许可证密钥用于访问高级功能
，不需要连接到 Copilot Cloud。
