使用一流的可观测性钩子监控 CopilotKit，这些钩子为聊天事件、用户交互和运行时错误发出结构化信号。将这些信号直接发送到您现有的技术栈，包括 Sentry、Datadog、New Relic 和 OpenTelemetry，或将其路由到您的分析管道。这些钩子暴露稳定的模式和 ID，因此您可以将智能体事件与应用遥测连接，端到端跟踪会话，并实时对故障发出警报。通过 `publicApiKey` 与 Copilot Cloud 一起使用，或通过 `publicLicenseKey` 自托管使用。

## 可观测性功能

### CopilotChat 可观测性钩子

使用全面的可观测性钩子跟踪用户交互、聊天行为和错误（如果自托管需要 `publicLicenseKey`，如果使用 CopilotCloud 则需要 `publicAPIkey`）：

```tsx
import { CopilotChat } from "@copilotkit/react-core/v2";

<CopilotChat
  observabilityHooks={{
    onMessageSent: (message) => {
      console.log("消息已发送:", message);
      // 跟踪消息分析
      analytics.track("chat_message_sent", { message });
    },
    onChatExpanded: () => {
      console.log("聊天已打开");
      // 跟踪参与度
      analytics.track("chat_expanded");
    },
    onChatMinimized: () => {
      console.log("聊天已关闭");
      // 跟踪用户行为
      analytics.track("chat_minimized");
    },
    onMessageRegenerated: (messageId) => {
      console.log("消息已重新生成:", messageId);
      // 跟踪重新生成请求
      analytics.track("chat_message_regenerated", { messageId });
    },
    onMessageCopied: (content) => {
      console.log("消息已复制:", content);
      // 跟踪内容分享
      analytics.track("chat_message_copied", { contentLength: content.length });
    },
    onFeedbackGiven: (messageId, type) => {
      console.log("已给出反馈:", messageId, type);
      // 跟踪用户反馈
      analytics.track("chat_feedback_given", { messageId, type });
    },
    onChatStarted: () => {
      console.log("聊天生成开始");
      // 跟踪 AI 开始响应时
      analytics.track("chat_generation_started");
    },
    onChatStopped: () => {
      console.log("聊天生成停止");
      // 跟踪 AI 停止响应时
      analytics.track("chat_generation_stopped");
    },
    onError: (errorEvent) => {
      console.log("发生错误", errorEvent);
      // 记录错误
      analytics.track("error_event", errorEvent);
    },
  }}
/>;
```

**可用可观测性钩子：**

- `onMessageSent(message)` - 用户发送消息
- `onChatExpanded()` - 聊天打开/展开
- `onChatMinimized()` - 聊天关闭/最小化
- `onMessageRegenerated(messageId)` - 消息重新生成
- `onMessageCopied(content)` - 消息被复制
- `onFeedbackGiven(messageId, type)` - 给出点赞/点踩反馈
- `onChatStarted()` - 聊天生成开始
- `onChatStopped()` - 聊天生成停止
- `onError(errorEvent)` - 错误事件和系统监控

**要求：**

- ✅ 需要 `publicLicenseKey`（自托管时）或来自 [Copilot Cloud](https://cloud.copilotkit.ai) 的 `publicApiKey`
- ✅ 适用于 `CopilotChat`、`CopilotPopup`、`CopilotSidebar` 和所有预构建组件

<Callout type="warn">
  **重要：** 没有有效的
  密钥，可观测性钩子将**不会触发**。这是一项安全功能，确保可观测性钩子仅在授权应用中工作。
</Callout>

## 错误事件结构

`onError` 处理程序接收具有丰富上下文的详细错误事件：

```typescript
interface CopilotErrorEvent {
  type:
    | "error"
    | "request"
    | "response"
    | "agent_state"
    | "action"
    | "message"
    | "performance";
  timestamp: number;
  context: {
    source: "ui" | "runtime" | "agent";
    request?: {
      operation: string;
      method?: string;
      url?: string;
      startTime: number;
    };
    response?: {
      endTime: number;
      latency: number;
    };
    agent?: {
      name: string;
      nodeName?: string;
    };
    messages?: {
      input: any[];
      messageCount: number;
    };
    technical?: {
      environment: string;
      stackTrace?: string;
    };
  };
  error?: any; // 错误事件时存在
}
```

## 常见可观测性模式

### 聊天事件跟踪

```tsx
<CopilotChat
  observabilityHooks={{
    onMessageSent: (message) => {
      // 跟踪消息分析
      analytics.track("chat_message_sent", {
        messageLength: message.length,
        timestamp: Date.now(),
        userId: getCurrentUserId(),
      });
    },
    onChatExpanded: () => {
      // 跟踪用户参与度
      analytics.track("chat_expanded", {
        timestamp: Date.now(),
        userId: getCurrentUserId(),
      });
    },
    onFeedbackGiven: (messageId, type) => {
      // 跟踪 AI 改进的反馈
      analytics.track("chat_feedback", {
        messageId,
        feedbackType: type,
        timestamp: Date.now(),
      });
    },
  }}
/>
```

### 组合事件和错误跟踪

```tsx
<CopilotKit
  publicApiKey="ck_pub_your_key" // [!code highlight] - 使用 publicApiKey 连接 Copilot Cloud
  // 或
  publicLicenseKey="ck_pub_your_key" // [!code highlight] - 使用 publicLicenseKey 进行自托管
  onError={(errorEvent) => {
    // 错误可观测性
    if (errorEvent.type === "error") {
      console.error("CopilotKit 错误:", errorEvent);
      analytics.track("copilotkit_error", {
        error: errorEvent.error?.message,
        context: errorEvent.context,
      });
    }
  }}
>
  <CopilotChat
    observabilityHooks={{
      onMessageSent: (message) => {
        // 事件跟踪
        analytics.track("chat_message_sent", { message });
      },
      onChatExpanded: () => {
        analytics.track("chat_expanded");
      },
    }}
  />
</CopilotKit>
```

## 错误可观测性模式

### 基本错误日志

```tsx
<CopilotKit
  publicApiKey="ck_pub_your_key" // [!code highlight] - 使用 publicApiKey 连接 Copilot Cloud
  // 或
  publicLicenseKey="ck_pub_your_key" // [!code highlight] - 使用 publicLicenseKey 进行自托管
  onError={(errorEvent) => {
    console.error("[CopilotKit 错误]", {
      type: errorEvent.type,
      timestamp: new Date(errorEvent.timestamp).toISOString(),
      context: errorEvent.context,
      error: errorEvent.error,
    });
  }}
>
  {/* 您的应用 */}
</CopilotKit>
```

### 与监控服务集成

```tsx
// Sentry 示例
import * as Sentry from "@sentry/react";

<CopilotKit
  publicApiKey="ck_pub_your_key" // [!code highlight] - 使用 publicApiKey 连接 Copilot Cloud
  // 或
  publicLicenseKey="ck_pub_your_key" // [!code highlight] - 使用 publicLicenseKey 进行自托管
  onError={(errorEvent) => {
    if (errorEvent.type === "error") {
      Sentry.captureException(errorEvent.error, {
        tags: {
          source: errorEvent.context.source,
          operation: errorEvent.context.request?.operation,
        },
        extra: {
          context: errorEvent.context,
          timestamp: errorEvent.timestamp,
        },
      });
    }
  }}
>
  {/* 您的应用 */}
</CopilotKit>;
```

### 自定义错误分析

```tsx
<CopilotKit
  publicApiKey="ck_pub_your_key" // [!code highlight] - 使用 publicApiKey 连接 Copilot Cloud
  // 或
  publicLicenseKey="ck_pub_your_key" // [!code highlight] - 使用 publicLicenseKey 进行自托管
  onError={(errorEvent) => {
    // 跟踪不同类型的错误
    analytics.track("copilotkit_event", {
      event_type: errorEvent.type,
      source: errorEvent.context.source,
      agent_name: errorEvent.context.agent?.name,
      latency: errorEvent.context.response?.latency,
      error_message: errorEvent.error?.message,
      timestamp: errorEvent.timestamp,
    });
  }}
>
  {/* 您的应用 */}
</CopilotKit>
```

```tsx

        analytics.track("chat_expanded");
      },
```
