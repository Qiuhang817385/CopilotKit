## 这是什么？

前端工具让您可以定义客户端函数，供您的智能体调用，执行完全在用户的浏览器中进行。当您的智能体调用前端工具时，逻辑在客户端运行，让您可以直接访问前端环境。

这可以用于让智能体控制 UI、生成式 UI，或进行人机交互（Human-in-the-loop）。在本指南中，我们介绍如何使用前端工具来驱动和与 UI 交互。

## 什么时候应该使用？

当您需要智能体与客户端原语交互时，请使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问浏览器 API，如 localStorage、sessionStorage 或 cookies
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户即时浏览器上下文的操作

## 创建前端工具

使用 `useFrontendTool` 钩子创建一个智能体可以从客户端调用的工具：

```tsx title="page.tsx"
import { z } from "zod";
import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

export function Page() {
  // ...

  // [!code highlight:12]
  useFrontendTool({
    name: "sayHello",
    description: "向用户问好",
    parameters: z.object({
      name: z.string().describe("要问候的用户名称"),
    }),
    handler: async ({ name }) => {
      alert(`你好，${name}！`);
      return `已向 ${name} 问好！`;
    },
  });

  // ...
}
```
