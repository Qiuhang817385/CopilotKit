## 这是什么？

前端工具使您能够定义代理可以调用的客户端函数，执行完全在用户的浏览器中进行。当您的代理调用前端工具时，逻辑在客户端运行，让您直接访问前端环境。

这可以用于让您的代理控制 UI、用于生成式 UI 或用于人机交互。在本指南中，我们涵盖了使用前端工具驱动和与 UI 交互。

## 何时使用此功能？

当您需要您的代理与客户端原语交互时使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问浏览器 API，如 localStorage、sessionStorage 或 cookies
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户即时浏览器上下文的操作

## 创建前端工具

使用 `useFrontendTool` 钩子创建一个代理可以从客户端调用的工具：

```tsx title="page.tsx"
import { z } from "zod";
import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

export function Page() {
  // ...

  // [!code highlight:12]
  useFrontendTool({
    name: "sayHello",
    description: "向用户问好",
    parameters: z.object({
      name: z.string().describe("要向其问好的用户的姓名"),
    }),
    handler: async ({ name }) => {
      alert(`您好, ${name}!`);
      return `已向 ${name} 问好！`;
    },
  });

  // ...
}
```
