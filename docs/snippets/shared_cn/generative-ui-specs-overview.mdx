## **生成式 UI 规范**

最近发布的几个规范使代理能够返回生成式 UI，增加了代理到用户对话的强大功能和灵活性。

**A2UI**、**MCP Apps** 和 **Open-JSON-UI** 都是生成式 UI 规范，允许代理不仅用文本而且用动态 UI 组件响应用户。
CopilotKit 现在为所有主要的生成式 UI 规范提供通用支持。

| **规范** | **来源 / 维护者** | **目的** |
| --- | --- | --- |
| **A2UI** | Google | 一种声明式、LLM 友好的生成式 UI 规范。基于 JSONL 和流式传输，专为平台无关渲染而设计。 |
| **Open-JSON-UI** | OpenAI | OpenAI 内部声明式生成式 UI 模式的开源标准化。 |
| **MCP Apps** | MCP 生态系统 | 基于 Iframe 的生成式 UI 扩展 MCP，使服务器能够返回交互式 UI 组件。 |

## **AG-UI 与生成式 UI 规范**

尽管命名相似，**AG-UI 不是生成式 UI 规范**——它是一个**用户交互协议**，提供代理和应用程序之间的**双向运行时连接**。

AG-UI 原生支持上述所有生成式 UI 规范，并允许开发人员**定义他们自己的自定义生成式 UI 标准**。
