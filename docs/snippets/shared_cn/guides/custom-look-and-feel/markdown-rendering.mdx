渲染助手消息时，CopilotKit 在底层使用 [`react-markdown`](https://remarkjs.github.io/react-markdown/)。
这使我们能够渲染带有链接、标题和其他 UI 组件的富文本。

如果你希望修改此行为，你可以丰富和覆盖单个 Markdown 组件，或完全替换整个 `<AssistantMessage />`。
这对于在助手回答文本中显示元素（如引用来源、推理步骤等）很有用。

以下是如何实现：

## 用你自己的组件替换/提供 Markdown 组件
我们将添加一个芯片组件。类似于 ChatGPT 引用来源时可用的那个。
<Steps>
<Step>
首先，让我们创建一个芯片组件
```tsx
import { CopilotKit } from "@copilotkit/react-core";
import { CopilotSidebar, ComponentsMap } from "@copilotkit/react-core/v2";
import "@copilotkit/react-ui/v2/styles.css";
// 为了方便，我们将样式放在单独的 css 文件中
import "./styles.css";

function YourComponent() {
    const customMarkdownTagRenderers: ComponentsMap<{ "reference-chip": { href: string } }> = {
        // 你可以创建自己的标签，或使用现有的有效 HTML 标签！
        "reference-chip": ({ children, href }) => {
            return (
                <a
                href={href}
                target="_blank"
                rel="noopener noreferrer"
                className="w-fit border rounded-xl py-1 px-2 text-xs" // 类列表为简洁起见已修剪
                >
                    {children}
                    <LinkIcon className="w-3.5 h-3.5" />
                </a>
            );
        },
    };

    return (
        <CopilotKit>
          <CopilotSidebar
            markdownTagRenderers={customMarkdownTagRenderers}
          />
        </CopilotKit>
    )
}
```
</Step>
<Step>
现在，让我们为组件添加样式
```css
.reference-chip {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    background-color: #f0f1f2;
    color: #444;
    border-radius: 12px;
    padding: 2px 8px;
    font-size: 0.8rem;
    font-weight: 500;
    text-decoration: none;
    margin: 0 2px;
    border: 1px solid #e0e0e0;
    cursor: pointer;
    box-shadow: 0 1px 2px rgba(0,0,0,0.05);
}
```
</Step>
</Steps>

## 替换整个 Markdown 渲染器

如果你希望完全避免使用 Markdown 渲染器，你可以替换 `<AssistantMessage />` 组件，它是使用它的组件。
请参阅[自定义子组件](/guides/custom-look-and-feel/bring-your-own-components)。
