## 这是什么？

工具是 LLM 调用预定义、通常是确定性函数的一种方式。CopilotKit 允许您在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 何时使用此功能？

当您的代理调用工具时，在 UI 中渲染工具对于向用户提供有关您的代理正在做什么的反馈很有用，特别是当您的代理正在调用工具时。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

## 在您的前端中渲染工具调用

使用 `useRenderTool` 钩子在 UI 中渲染工具调用。名称必须与代理中定义的工具名称匹配。

<Callout type="info" title="重要">
  为了在 UI 中渲染工具调用，名称必须与工具的名称匹配。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
import { z } from "zod";
// ...

const weatherParams = z.object({
  location: z.string().describe("要获取天气的位置"),
});

const YourMainContent = () => {
  // ...
  // [!code highlight:14]
  useRenderTool({
    name: "get_weather",
    parameters: weatherParams,
    render: ({ status, parameters }) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "正在调用天气 API..."}
          {status === "complete" && `已为 ${parameters.location} 调用天气 API。`}
        </p>
      );
    },
  });
  // ...
}
```
