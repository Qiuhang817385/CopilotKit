## 这是什么？

无头 UI 让您完全控制聊天体验——您提供自己的组件、布局和样式，而 CopilotKit 处理代理通信、消息管理和流式传输。这是构建在与程序化控制中介绍的相同原语（`useAgent` 和 `useCopilotKit`）之上的。

## 何时使用此功能？

当插槽系统不够用时使用无头 UI——例如，当您需要完全不同的布局、想要将聊天嵌入到现有 UI 中，或者正在构建仍然与代理通信的非聊天界面时。

## 实现

<Steps>
<Step>
### 访问代理和 CopilotKit

使用 `useAgent` 获取代理实例（消息、状态、执行状态），使用 `useCopilotKit` 运行代理。

```tsx title="components/custom-chat.tsx"
import { useAgent } from "@copilotkit/react-core/v2";
import { useCopilotKit } from "@copilotkit/react-core/v2";
import { randomUUID } from "@copilotkit/shared/v2";

export function CustomChat() {
  // [!code highlight:2]
  const { agent } = useAgent();
  const { copilotkit } = useCopilotKit();

  return <div>{/* 您的自定义 UI */}</div>;
}
```
</Step>

<Step>
### 显示消息

代理的消息可通过 `agent.messages` 获取。每条消息都有 `id`、`role`（`"user"` 或 `"assistant"`）和 `content`。

```tsx title="components/custom-chat.tsx"
export function CustomChat() {
  const { agent } = useAgent();
  const { copilotkit } = useCopilotKit();

  return (
    <div className="flex flex-col h-full">
      {/* [!code highlight:12] */}
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {agent.messages.map((msg) => (
          <div
            key={msg.id}
            className={msg.role === "user" ? "ml-auto bg-blue-100 rounded-lg p-3 max-w-md" : "bg-gray-100 rounded-lg p-3 max-w-md"}
          >
            <p className="text-sm font-medium">{msg.role}</p>
            <p>{msg.content}</p>
          </div>
        ))}
        {agent.isRunning && <div className="text-gray-400">思考中...</div>}
      </div>
    </div>
  );
}
```
</Step>

<Step>
### 发送消息并运行代理

向代理的对话添加消息，然后调用 `copilotkit.runAgent()` 触发执行。这与 CopilotKit 内置的 `<CopilotChat />` 内部使用的方法相同。

```tsx title="components/custom-chat.tsx"
import { useState, useCallback } from "react";

export function CustomChat() {
  const { agent } = useAgent();
  const { copilotkit } = useCopilotKit();
  const [input, setInput] = useState("");

  // [!code highlight:14]
  const sendMessage = useCallback(async () => {
    if (!input.trim()) return;

    agent.addMessage({
      id: randomUUID(),
      role: "user",
      content: input,
    });

    setInput("");

    await copilotkit.runAgent({ agent });
  }, [input, agent, copilotkit]);

  return (
    <div className="flex flex-col h-full">
      <div className="flex-1 overflow-y-auto p-4 space-y-4">
        {agent.messages.map((msg) => (
          <div key={msg.id} className={msg.role === "user" ? "ml-auto bg-blue-100 rounded-lg p-3 max-w-md" : "bg-gray-100 rounded-lg p-3 max-w-md"}>
            <p>{msg.content}</p>
          </div>
        ))}
        {agent.isRunning && <div className="text-gray-400">思考中...</div>}
      </div>

      {/* [!code highlight:12] */}
      <form
        className="border-t p-4 flex gap-2"
        onSubmit={(e) => { e.preventDefault(); sendMessage(); }}
      >
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          placeholder="输入消息..."
          className="flex-1 border rounded-lg px-3 py-2"
        />
        <button type="submit" disabled={agent.isRunning}>发送</button>
      </form>
    </div>
  );
}
```
</Step>

<Step>
### 停止代理

使用 `copilotkit.stopAgent()` 取消正在运行的代理：

```tsx title="components/custom-chat.tsx"
const stopAgent = useCallback(() => {
  // [!code highlight:1]
  copilotkit.stopAgent({ agent });
}, [agent, copilotkit]);

// 在您的 JSX 中：
{agent.isRunning && (
  <button onClick={stopAgent} className="text-red-500">
    停止
  </button>
)}
```
</Step>
</Steps>
