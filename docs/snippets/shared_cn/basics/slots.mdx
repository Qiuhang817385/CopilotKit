## 这是什么？

每个 CopilotKit 聊天组件都是由可组合的**插槽**构建的——您可以单独覆盖的命名子组件。插槽系统为您提供三个级别的自定义，而无需重建整个 UI：

1. **Tailwind 类** — 传递字符串以添加/覆盖 CSS 类
2. **属性覆盖** — 传递对象以覆盖默认组件上的特定属性
3. **自定义组件** — 传递您自己的 React 组件以完全替换插槽

插槽是递归的——您可以在任何深度钻取嵌套的子组件。

## Tailwind 类

自定义插槽的最简单方式。传递 Tailwind 类字符串，它将与默认组件的类合并。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

export function Chat() {
  return (
    <CopilotChat
      // [!code highlight:2]
      messageView="bg-gray-50 dark:bg-gray-900 p-4"
      input="border-2 border-blue-400 rounded-xl"
    />
  );
}
```

## 属性覆盖

传递对象以覆盖默认组件上的特定属性。这对于添加 `className`、事件处理程序、数据属性或默认组件接受的任何其他属性很有用。

```tsx title="page.tsx"
<CopilotChat
  // [!code highlight:4]
  messageView={{
    className: "my-custom-messages",
    "data-testid": "message-view",
  }}
  input={{ autoFocus: true }}
/>
```

## 自定义组件

要完全控制，请传递您自己的 React 组件。它接收与默认组件相同的所有属性。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

// [!code highlight:8]
const CustomMessageView = ({ messages, isRunning }) => (
  <div className="space-y-4 p-6">
    {messages?.map((msg) => (
      <div key={msg.id} className={msg.role === "user" ? "text-right" : "text-left"}>
        {msg.content}
      </div>
    ))}
    {isRunning && <div className="animate-pulse">思考中...</div>}
  </div>
);

export function Chat() {
  return (
    // [!code highlight:1]
    <CopilotChat messageView={CustomMessageView} />
  );
}
```

## 嵌套插槽（向下钻取）

插槽是递归的。您可以通过嵌套对象来自定义任何深度的子组件。

### 两层深

覆盖消息视图中的助手消息工具栏：

```tsx title="page.tsx"
<CopilotChat
  // [!code highlight:7]
  messageView={{
    assistantMessage: {
      toolbar: CustomToolbar,
      copyButton: CustomCopyButton,
    },
    userMessage: CustomUserMessage,
  }}
/>
```

### 三层深

覆盖助手消息工具栏中的特定按钮：

```tsx title="page.tsx"
<CopilotChat
  messageView={{
    // [!code highlight:5]
    assistantMessage: {
      copyButton: ({ onClick }) => (
        <button onClick={onClick}>复制</button>
      ),
    },
  }}
/>
```

### 输入子插槽

```tsx title="page.tsx"
<CopilotChat
  input={{
    // [!code highlight:2]
    textArea: CustomTextArea,
    sendButton: CustomSendButton,
  }}
/>
```

### 滚动视图子插槽

```tsx title="page.tsx"
<CopilotChat
  scrollView={{
    // [!code highlight:2]
    feather: CustomFeather,
    scrollToBottomButton: CustomScrollButton,
  }}
/>
```

### 建议视图子插槽

```tsx title="page.tsx"
<CopilotChat
  suggestionView={{
    // [!code highlight:2]
    suggestion: CustomSuggestionPill,
    container: CustomSuggestionContainer,
  }}
/>
```

## 子渲染函数

要完全控制布局，请使用 `children` 渲染函数模式。这为您提供可以按您喜欢的方式排列的预构建插槽元素。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

export function Chat() {
  return (
    <CopilotChat>
      {/* [!code highlight:8] */}
      {({ messageView, input, scrollView, suggestionView }) => (
        <div className="flex flex-col h-full">
          <header className="p-4 border-b font-semibold">我的代理</header>
          {scrollView}
          <div className="border-t p-4">{input}</div>
        </div>
      )}
    </CopilotChat>
  );
}
```

## 标签

通过 `labels` 属性自定义 UI 中的任何文本字符串。这不使用插槽系统——它是 `CopilotChat`、`CopilotSidebar` 和 `CopilotPopup` 上的一个单独的便捷属性。

```tsx title="page.tsx"
<CopilotChat
  // [!code highlight:5]
  labels={{
    chatInputPlaceholder: "向您的代理询问任何问题...",
    welcomeMessageText: "今天我能为您做什么？",
    chatDisclaimerText: "AI 回复可能不准确。",
  }}
/>
```

## 可用插槽

### `CopilotChat` / `CopilotSidebar` / `CopilotPopup`

这些是所有聊天组件上可用的根级插槽属性：

| 插槽 | 描述 |
|------|-------------|
| `messageView` | 消息列表容器。 |
| `scrollView` | 具有自动滚动行为的滚动容器。 |
| `input` | 带有发送/转录控件的文本输入区域。 |
| `suggestionView` | 消息下方显示的建议 pills。 |
| `welcomeScreen` | 初始空状态屏幕（传递 `false` 以禁用）。 |

`CopilotSidebar` 和 `CopilotPopup` 还有：

| 插槽 | 描述 |
|------|-------------|
| `header` | 模态标题栏。 |
| `toggleButton` | 打开/关闭切换按钮。 |

### `messageView` 子插槽

通过 `messageView={{ ... }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `assistantMessage` | 渲染助手回复。有自己的子插槽（见下文）。 |
| `userMessage` | 渲染用户消息。有自己的子插槽（见下文）。 |
| `reasoningMessage` | 渲染模型推理/思考步骤。有自己的子插槽（见下文）。 |
| `cursor` | 代理响应时显示的流式光标指示器。 |

### `assistantMessage` 子插槽

通过 `messageView={{ assistantMessage: { ... } }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `markdownRenderer` | Markdown 渲染组件。 |
| `toolbar` | 消息下方的操作工具栏。 |
| `copyButton` | 复制消息按钮。 |
| `thumbsUpButton` | 点赞反馈按钮。 |
| `thumbsDownButton` | 点踩反馈按钮。 |
| `readAloudButton` | 朗读按钮。 |
| `regenerateButton` | 重新生成回复按钮。 |
| `toolCallsView` | 工具调用可视化。 |

### `userMessage` 子插槽

通过 `messageView={{ userMessage: { ... } }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `messageRenderer` | 用户消息的文本渲染组件。 |
| `toolbar` | 悬停时的操作工具栏。 |
| `copyButton` | 复制消息按钮。 |
| `editButton` | 编辑消息按钮。 |
| `branchNavigation` | 消息分支之间的导航（编辑后）。 |

### `reasoningMessage` 子插槽

通过 `messageView={{ reasoningMessage: { ... } }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `header` | 可折叠的标题（点击展开/折叠）。 |
| `contentView` | 推理内容区域。 |
| `toggle` | 展开/折叠切换包装器。 |

### `input` 子插槽

通过 `input={{ ... }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `textArea` | 文本输入元素。 |
| `sendButton` | 发送/提交按钮。 |
| `addMenuButton` | 附件/工具菜单按钮。 |
| `startTranscribeButton` | 开始语音转录的按钮。 |
| `cancelTranscribeButton` | 取消转录的按钮。 |
| `finishTranscribeButton` | 完成转录的按钮。 |
| `audioRecorder` | 录音机组件。 |
| `disclaimer` | 输入下方的免责声明文本。 |

### `scrollView` 子插槽

通过 `scrollView={{ ... }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `feather` | 滚动区域底部的渐变叠加层。 |
| `scrollToBottomButton` | 向上滚动时出现的按钮。 |

### `suggestionView` 子插槽

通过 `suggestionView={{ ... }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `suggestion` | 单个建议 pill/按钮。 |
| `container` | 包装所有建议 pills 的容器。 |

### `welcomeScreen` 子插槽

通过 `welcomeScreen={{ ... }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `welcomeMessage` | 空状态上显示的欢迎文本。 |

### `header` 子插槽（仅限 Sidebar/Popup）

通过 `header={{ ... }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `titleContent` | 标题中的标题文本。 |
| `closeButton` | 关闭/最小化按钮。 |

### `toggleButton` 子插槽（仅限 Sidebar/Popup）

通过 `toggleButton={{ ... }}` 可用：

| 插槽 | 描述 |
|------|-------------|
| `openIcon` | 聊天关闭时显示的图标。 |
| `closeIcon` | 聊天打开时显示的图标。 |
