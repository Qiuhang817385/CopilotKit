要将 FastAPI 服务器连接到 Copilot Cloud，我们利用一个称为"远程端点"的概念，
它允许 CopilotKit Runtime 连接到各种后端。

要开始使用，<LinkToCopilotCloud asButton={false}>导航到 Copilot Cloud</LinkToCopilotCloud>。

<Callout title="不想使用隧道？">
只需跳过隧道设置，使用您托管的 FastAPI 服务器地址即可。
</Callout>

```sh
npx copilotkit@latest dev --port <port_number>
```
