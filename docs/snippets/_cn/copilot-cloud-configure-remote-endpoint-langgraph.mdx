要通过 Copilot Cloud 连接到 LangGraph 代理，我们利用一个称为"远程端点"的概念，
它允许 CopilotKit Runtime 连接到各种后端。

导航到 <LinkToCopilotCloud asButton={false}>cloud.copilotkit.ai</LinkToCopilotCloud> 并按照视频操作！

您需要一个 LangSmith API 密钥，您可以在 LangSmith 网站上 [按照本指南](https://docs.smith.langchain.com/administration/how_to_guides/organization_management/create_account_api_key#create-an-api-key) 获取。

<Accordions>
<Accordion title="使用 LangGraph Studio">

    如果您使用的是 LangGraph Studio 的本地部署，则需要打开到 LangGraph Studio 部署 URL 的隧道。

    ```bash
    npx copilotkit@latest dev --port <port_number>
    ```
</Accordion>
</Accordions>
