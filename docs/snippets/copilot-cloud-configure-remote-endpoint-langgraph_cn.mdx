要通过 Copilot Cloud 连接到 LangGraph 代理，我们利用一种称为"远程端点（Remote Endpoints）"的概念，它允许 CopilotKit 运行时连接到各种后端。

前往 <LinkToCopilotCloud asButton={false}>cloud.copilotkit.ai</LinkToCopilotCloud> 并按照视频操作！

您需要一个 LangSmith API 密钥，可以在 LangSmith 网站的[此指南](https://docs.smith.langchain.com/administration/how_to_guides/organization_management/create_account_api_key#create-an-api-key)中获取。

<Accordions>
<Accordion title="使用 LangGraph Studio">

    如果您使用 LangGraph Studio 的本地部署，需要为您的 LangGraph Studio 部署 URL 打开一个隧道。

    ```bash
    npx copilotkit@latest dev --port <port_number>
    ```
</Accordion>
</Accordions>
