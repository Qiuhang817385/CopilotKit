LLM 适配器负责使用 LLM 执行请求，并以 Copilot 运行时能够理解的方式标准化请求/响应格式。

目前，我们原生支持以下 LLM 适配器：

- [OpenAI 适配器（同时支持 Azure）](/reference/v1/classes/llm-adapters/OpenAIAdapter)
- [OpenAI 助手适配器](/reference/v1/classes/llm-adapters/OpenAIAssistantAdapter)
- [LangChain 适配器](/reference/v1/classes/llm-adapters/LangChainAdapter)
- [Groq 适配器](/reference/v1/classes/llm-adapters/GroqAdapter)
- [Google Generative AI 适配器](/reference/v1/classes/llm-adapters/GoogleGenerativeAIAdapter)
- [Anthropic 适配器](/reference/v1/classes/llm-adapters/AnthropicAdapter)

<Callout type="info">
  您可以使用 [LangChain
  适配器](/reference/v1/classes/llm-adapters/LangChainAdapter) 来使用我们尚未原生支持的任何 LLM 提供商！
</Callout>

<Callout type="info">
  从头开始编写您自己的 LLM 适配器并不困难——请参阅现有适配器获取灵感。当然，我们也欢迎您的贡献！⭐️
</Callout>
