## 概述

`CopilotChatMessageView` 渲染聊天消息列表，并在代理运行时可选地显示输入光标。它将单个消息的渲染委托给插槽组件（`assistantMessage` 和 `userMessage`），并支持用于完全控制布局的渲染 prop `children`。

## 导入

```tsx
import { CopilotChatMessageView } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## Props

<PropertyReference name="isRunning" type="boolean" default="false">
  代理当前是否正在执行。当为 `true` 时，光标插槽在最新消息后渲染，表示正在进行的活动。
</PropertyReference>

<PropertyReference name="messages" type="Message[]" default="[]">
  要渲染的聊天消息数组。每个消息对象至少包含一个 `id`、 `role`（`"user"` 或 `"assistant"`）和 `content`。
</PropertyReference>

<PropertyReference name="children" type="(props: { isRunning: boolean; messages: Message[]; messageElements: React.ReactElement[] }) => React.ReactElement">
  接收已解析状态和预构建消息元素的可选渲染 prop 函数。提供时，组件调用此函数而不是渲染默认的消息列表布局。

  回调接收：
  - `isRunning` -- 当前运行状态
  - `messages` -- 原始消息数组
  - `messageElements` -- 从 `assistantMessage` 和 `userMessage` 插槽构建的 React 元素数组
</PropertyReference>

## 插槽

所有插槽 prop 遵循 CopilotKit 插槽系统：每个都接受替换的 React 组件、合并到默认组件类中的 `className` 字符串，或扩展默认组件的部分 props 对象。

<PropertyReference name="assistantMessage" type="SlotProp<typeof CopilotChatAssistantMessage>">
  用于渲染助手消息的插槽。默认为 [`CopilotChatAssistantMessage`](/reference/v2/components/CopilotChatAssistantMessage)，它提供 Markdown 渲染、工具调用显示和操作工具栏。

  **作为替换组件：**
  ```tsx
  <CopilotChatMessageView
    assistantMessage={({ message }) => (
      <div className="my-assistant-msg">{message.content}</div>
    )}
  />
  ```

  **作为 className：**
  ```tsx
  <CopilotChatMessageView assistantMessage="bg-blue-50 rounded-lg" />
  ```

  **作为部分 props：**
  ```tsx
  <CopilotChatMessageView
    assistantMessage={{ toolbarVisible: false }}
  />
  ```
</PropertyReference>

<PropertyReference name="userMessage" type="SlotProp<typeof CopilotChatUserMessage>">
  用于渲染用户消息的插槽。默认为 [`CopilotChatUserMessage`](/reference/v2/components/CopilotChatUserMessage)，它提供右对齐的消息显示和可选的分支导航。

  **作为替换组件：**
  ```tsx
  <CopilotChatMessageView
    userMessage={({ message }) => (
      <div className="my-user-msg">{message.content}</div>
    )}
  />
  ```

  **作为 className：**
  ```tsx
  <CopilotChatMessageView userMessage="bg-gray-100 rounded-lg" />
  ```
</PropertyReference>

<PropertyReference name="cursor" type="SlotProp<typeof CopilotChatMessageView.Cursor>">
  当 `isRunning` 为 `true` 时显示的输入指示器的插槽。默认为 `CopilotChatMessageView.Cursor`，它渲染一个脉冲点动画。

  **作为替换组件：**
  ```tsx
  <CopilotChatMessageView
    cursor={() => <span className="animate-bounce">...</span>}
  />
  ```

  **作为 className：**
  ```tsx
  <CopilotChatMessageView cursor="text-blue-500" />
  ```
</PropertyReference>

## 用法

### 基本消息列表

```tsx
import { CopilotChatMessageView } from "@copilotkit/react-core/v2";
import { useAgent } from "@copilotkit/react-core/v2";

function MessageList() {
  const { agent } = useAgent();

  return (
    <CopilotChatMessageView
      messages={agent.messages}
      isRunning={agent.isRunning}
    />
  );
}
```

### 自定义消息插槽

```tsx
import { CopilotChatMessageView } from "@copilotkit/react-core/v2";

function CustomMessages() {
  const { agent } = useAgent();

  return (
    <CopilotChatMessageView
      messages={agent.messages}
      isRunning={agent.isRunning}
      assistantMessage="bg-blue-50 p-4 rounded-xl"
      userMessage="bg-gray-100 p-4 rounded-xl"
      cursor={() => <div className="animate-pulse text-gray-400">思考中...</div>}
    />
  );
}
```

### 用于自定义布局的 Children 渲染 Prop

```tsx
import { CopilotChatMessageView } from "@copilotkit/react-core/v2";

function CustomLayout() {
  const { agent } = useAgent();

  return (
    <CopilotChatMessageView
      messages={agent.messages}
      isRunning={agent.isRunning}
    >
      {({ isRunning, messages, messageElements }) => (
        <div className="flex flex-col gap-4 p-6">
          <div className="text-sm text-gray-500">
            {messages.length} 条消息
          </div>
          {messageElements}
          {isRunning && (
            <div className="text-sm text-blue-500 animate-pulse">
              代理正在回复...
            </div>
          )}
        </div>
      )}
    </CopilotChatMessageView>
  );
}
```

### 隐藏助手消息上的工具栏

```tsx
import { CopilotChatMessageView } from "@copilotkit/react-core/v2";

function MinimalChat() {
  const { agent } = useAgent();

  return (
    <CopilotChatMessageView
      messages={agent.messages}
      isRunning={agent.isRunning}
      assistantMessage={{ toolbarVisible: false }}
    />
  );
}
```

## 行为

- **消息渲染**：`messages` 数组中的每条消息都使用基于其 `role` 的相应插槽组件渲染。助手消息使用 `assistantMessage` 插槽；用户消息使用 `userMessage` 插槽。
- **光标显示**：仅在 `isRunning` 为 `true` 时渲染 `cursor` 插槽。它出现在列表中最后一条消息之后。
- **渲染 Prop 覆盖**：当 `children` 作为函数提供时，组件将所有布局委托给该函数。`messageElements` 数组是从插槽组件预构建的，因此自定义布局仍然受益于插槽自定义。
- **插槽系统**：每个插槽 prop 接受三种形式——替换组件、合并到默认组件的 className 字符串，或扩展默认组件 props 的部分 props 对象。
