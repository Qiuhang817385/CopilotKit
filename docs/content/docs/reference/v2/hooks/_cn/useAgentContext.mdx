## 概述

`useAgentContext` 为活动 Copilot 运行时的生命周期注册一个动态上下文对象。该 hook 在挂载时添加上下文，在卸载时移除它，因此代理始终看到你的应用程序状态的最新快照，无需手动清理。

更新传入的上下文对象以刷新代理看到的内容。这是 `useCopilotReadable` 的 v2 等价物——它允许你展示任何可序列化的应用程序状态（用户偏好、选中的项目、计算值等）作为代理在生成响应或做出决策时可以引用的上下文。

## 签名

```tsx
import { useAgentContext } from "@copilotkit/react-core/v2";

function useAgentContext(context: AgentContextInput): void;
```

## 参数

<PropertyReference name="context" type="AgentContextInput" required>
  描述要暴露给代理的上下文的对象。

  <PropertyReference name="description" type="string" required>
    上下文的人类可读描述。代理使用它来理解该值代表什么以及何时引用它。
  </PropertyReference>

  <PropertyReference name="value" type="JsonSerializable" required>
    要提供的上下文值。必须是 JSON 可序列化的：`string`、 `number`、 `boolean`、 `null`、数组，或具有字符串键和可序列化值的普通对象。对象值自动序列化。
  </PropertyReference>
</PropertyReference>

## 用法

### 基本用法

提供简单的应用程序状态作为代理的上下文。

```tsx
import { useAgentContext } from "@copilotkit/react-core/v2";

function UserGreeting({ user }: { user: { name: string; role: string } }) {
  useAgentContext({
    description: "当前登录的用户",
    value: { name: user.name, role: user.role },
  });

  return <div>欢迎, {user.name}</div>;
}
```

### 来自组件状态的动态上下文

当值在渲染之间变化时，上下文自动更新。

```tsx
import { useState } from "react";
import { useAgentContext } from "@copilotkit/react-core/v2";

function ProductCatalog() {
  const [selectedCategory, setSelectedCategory] = useState("electronics");
  const [priceRange, setPriceRange] = useState({ min: 0, max: 500 });

  useAgentContext({
    description: "用户当前的产品筛选设置",
    value: {
      category: selectedCategory,
      priceRange,
    },
  });

  return (
    <div>
      <select
        value={selectedCategory}
        onChange={(e) => setSelectedCategory(e.target.value)}
      >
        <option value="electronics">电子产品</option>
        <option value="books">图书</option>
        <option value="clothing">服装</option>
      </select>
      {/* ... 价格范围控件 ... */}
    </div>
  );
}
```

### 嵌套组件中的多个上下文

每个组件可以注册自己的上下文。所有注册的上下文同时对代理可见。

```tsx
import { useAgentContext } from "@copilotkit/react-core/v2";

function Dashboard() {
  useAgentContext({
    description: "当前仪表板视图和布局",
    value: { view: "analytics", columns: 3 },
  });

  return (
    <div>
      <Sidebar />
      <MainPanel />
    </div>
  );
}

function Sidebar() {
  const [collapsed, setCollapsed] = useState(false);

  useAgentContext({
    description: "侧边栏导航状态",
    value: { collapsed, activeSection: "reports" },
  });

  return <nav>{/* ... */}</nav>;
}
```

## 行为

- **挂载/卸载生命周期**：上下文在组件挂载时注册，在卸载时自动移除。不需要手动清理。
- **响应式更新**：当 `context` 对象在渲染之间变化时，代理立即看到更新后的值。
- **序列化**：`value` 必须符合 `JsonSerializable`（`string | number | boolean | null | JsonSerializable[] | { [key: string]: JsonSerializable }`）。非序列化值如函数、类实例或符号将导致错误。
- **多个上下文**：组件树中的多个 `useAgentContext` 调用对代理同时可见。每个都通过其描述和值标识。
- **无返回值**：该 hook 返回 `void`。与 `useCopilotReadable` 不同，它不为父子层次结构返回 ID。
