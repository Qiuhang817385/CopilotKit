title: "useFrontendTool"
description: "useFrontendTool hook 允许 Copilot 在前端执行工具。"
---

<Callout type="warning">
  `useFrontendTool` 仍然受支持，但我们建议迁移到 v2 API 的 [`useFrontendTool`](/reference/v2/hooks/useFrontendTool)，它使用 Zod 模式来定义参数。
</Callout>

`useFrontendTool` 允许你定义 AI 可以调用的可执行动作，并附带一个处理函数。
这是赋予你的 AI 代理在应用程序中执行操作能力的主要方式——无论是
更新状态、进行 API 调用还是触发副作用。

该 hook 需要三个主要部分：
1. 一个名称和描述，以便 AI 知道何时调用它
2. 一个参数定义，描述该工具接受哪些输入
3. 当 AI 调用该工具时执行的处理函数

可选地，你可以提供一个 `render` 函数来显示自定义 UI，在聊天界面中展示工具的执行
状态和结果。

## 用法

### 简单用法

```tsx
import { useFrontendTool } from "@copilotkit/react-core";

useFrontendTool({
  name: "sayHello",
  description: "向某人问好。",
  parameters: [
    {
      name: "name",
      type: "string",
      description: "要问候的人的姓名",
      required: true,
    },
  ],
  handler: async ({ name }) => {
    alert(`Hello, ${name}!`);
  },
});
```

### 自定义 UI 渲染

```tsx
import { useFrontendTool } from "@copilotkit/react-core";

useFrontendTool({
  name: "showWeatherCard",
  description: "显示某个位置的天气信息",
  parameters: [
    {
      name: "location",
      type: "string",
      description: "要显示天气的位置",
      required: true,
    },
    {
      name: "temperature",
      type: "number",
      description: "摄氏温度",
      required: true,
    },
  ],
  handler: async ({ location, temperature }) => {
    // 获取并返回天气数据
    return { location, temperature, conditions: "晴朗" };
  },
  render: ({ args, status, result }) => {
    if (status === "inProgress") {
      return <div>正在加载 {args.location} 的天气...</div>;
    }
    if (status === "complete" && result) {
      return (
        <WeatherCard
          location={result.location}
          temperature={result.temperature}
          conditions={result.conditions}
        />
      );
    }
    return null;
  },
});
```

## 生成式 UI

此 hook 使你能够动态生成 UI 元素并在 copilot 聊天中渲染它们。如需更多信息，请查看 [生成式 UI](/generative-ui/your-components/display-only) 页面。

## 从 useCopilotAction 迁移

如果你正在从 `useCopilotAction` 迁移，以下是主要区别：

1. 渲染组件的 props 包含 `name` 和 `description`

### 迁移示例

```tsx
// 使用 useCopilotAction 之前
useCopilotAction({
  name: "addTodo",
  parameters: [
    {
      name: "text",
      type: "string",
      description: "待办事项文本",
      required: true,
    },
  ],
  handler: ({ text }) => {
    addTodo(text);
  },
});

// 使用 useFrontendTool 之后
useFrontendTool({
  name: "addTodo",
  parameters: [
    {
      name: "text",
      type: "string",
      description: "待办事项文本",
      required: true,
    },
  ],
  handler: ({ text }) => {
    addTodo(text);
  },
});
```

## 参数

<PropertyReference name="name" type="string" required >
工具的名称。
</PropertyReference>

<PropertyReference name="description" type="string"  >
工具的描述。用于指导 Copilot 如何使用该工具。
</PropertyReference>

<PropertyReference name="parameters" type="T"  >
工具的参数定义数组。每个参数对象应具有：
- `name` (string): 参数名称
- `type` (string): 参数类型（例如 "string", "number", "boolean", "string[]", "object"）
- `description` (string): 参数的用途描述
- `required` (boolean): 参数是否为必填
- `properties` (array, optional): 对于对象类型，使用相同的模式定义嵌套属性

简单示例：`[{ name: "query", type: "string", description: "搜索查询", required: true }]`

嵌套示例：
```typescript
[
  {
    name: "user",
    type: "object",
    description: "用户信息",
    required: true,
    properties: [
      { name: "name", type: "string", description: "用户姓名", required: true },
      { name: "age", type: "number", description: "用户年龄", required: false }
    ]
  }
]
```
</PropertyReference>

<PropertyReference name="handler" type="FrontendAction<T>['handler']"  >
执行工具逻辑的处理函数。
</PropertyReference>

<PropertyReference name="followUp" type="boolean"  >
是否将工具调用的结果报告给 LLM，然后 LLM 将提供后续响应。传递 `false` 以禁用。
</PropertyReference>

<PropertyReference name="render" type="FrontendAction<T>['render']"  >
用于渲染工具自定义 UI 的 React 组件。
</PropertyReference>

<PropertyReference name="available" type="'disabled' | 'enabled'"  >
工具是否可用。设置为 "disabled" 以阻止调用该工具。
</PropertyReference>
