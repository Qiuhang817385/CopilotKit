## 这是什么？

你可以轻松地从原生应用写入 Agent 的状态，从而允许你从 UI 更新 Agent 的状态。

## 何时使用？

当你想向 Agent 的状态提供用户输入或控制时，可以使用此功能。随着应用状态的变化，你可以更新 Agent 状态以反映这些变化。

    ### 设置带状态的 Agent

    定义你的 Agent 状态 schema。AWS Strands 在整个执行过程中维护状态。

    ```python title="agent/main.py"
    import os
    from ag_ui_strands import StrandsAgent, StrandsAgentConfig, create_strands_app
    from strands import Agent
    from strands.models.openai import OpenAIModel

    model = OpenAIModel(
        client_args={"api_key": os.getenv("OPENAI_API_KEY", "")},
        model_id="gpt-4o",
    )

    # 创建 Strands Agent
    strands_agent = Agent(
        model=model,
        system_prompt="始终使用用户偏好语言进行沟通，如你的状态中所定义。不要使用任何其他语言进行沟通。",
    )

    # 将状态注入提示词
    def language_prompt(input_data, user_message: str) -> str:
        state_dict = getattr(input_data, "state", None)
        if isinstance(state_dict, dict) and "language" in state_dict:
            return f"当前语言: {state_dict['language']}\n\n用户请求: {user_message}"
        return user_message

    config = StrandsAgentConfig(state_context_builder=language_prompt)

    # 使用 AG-UI 集成进行包装
    agui_agent = StrandsAgent(
        agent=strands_agent,
        name="languageAgent",
        description="始终使用用户偏好语言进行沟通",
        config=config,
    )

    app = create_strands_app(agui_agent)
    ```
  </Step>

  <Step>
    ### 使用 `useAgent` Hook

    在你的 Agent 连接并运行后，调用 `useAgent` Hook，传入 Agent 的名称，并使用 `agent.setState` 来更新 Agent 状态。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    // 定义 Agent 状态类型以匹配你的 Strands Agent
    type AgentState = {
      language: "english" | "spanish";
    };

    function YourMainContent() {
      // [!code highlight:5]
      const { agent } = useAgent({
        agentId: "languageAgent",
        // 可选择提供类型安全的初始状态
        initialState: { language: "spanish" }
      });

      const toggleLanguage = () => {
        agent.setState({ language: agent.state?.language === "english" ? "spanish" : "english" }); // [!code highlight]
      };

      return (
        // 为简洁起见，省略了样式
        <div>
          <h1>你的主要内容</h1>
          {/* [!code highlight:2] */}
          <p>语言: {agent.state?.language}</p>
          <button onClick={toggleLanguage}>切换语言</button>
        </div>
      );
    }
    ```
    <Callout type="info">
      `useAgent` 中的 `agent.setState` 函数将更新 Agent 状态并在状态变化时触发重新渲染。
    </Callout>
  </Step>

  <Step>
    ### 试试看！

    你现在可以使用 `setState` 函数来更新 Agent 状态，使用 `state` 来读取它。尝试切换语言按钮并与你的 Agent 对话。你会看到语言变化以匹配 Agent 的状态。

    <Callout type="info" title="重要">
      AWS Strands 中的共享状态是提示词驱动的。这意味着你的 Agent 对共享状态的感知将通过你提供给 Agent 的指令来增强。
    </Callout>
