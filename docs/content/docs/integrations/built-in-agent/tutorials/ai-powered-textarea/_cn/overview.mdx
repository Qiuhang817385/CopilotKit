## 您将学习的内容

在本教程中，您将创建一个简单的电子邮件应用程序，并为其添加 AI 驱动的自动完成功能。该应用是一个简单的电子邮件客户端，使用常规文本区域来撰写电子邮件。您将向应用添加 CopilotKit，以便文本区域在您键入时提供相关的自动完成建议。该文本区域将了解完整的电子邮件历史记录。

您将学习：

- 💡 如何使用 `useCopilotReadable` 让您的 Copilot 读取应用的状态
- 💡 如何使用 `<CopilotTextarea />` 组件在您的应用中获取即时上下文感知自动完成
- 💡 如何使用 Copilot Textarea 操作弹出窗口生成文本或调整文本区域中的现有文本
