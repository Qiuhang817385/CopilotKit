## 接下来做什么？

以下是一些后续建议：

- 使用 [`useCopilotChatSuggestions`](/reference/v1/hooks/useCopilotChatSuggestions) Hook 为 Copilot 添加建议。
- 在聊天窗口中添加初始助手消息（更多信息请查看 [`<CopilotPopup />`](/reference/v1/components/chat/CopilotPopup) 文档）。
- 深入了解有用的 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) Hook，它可以让你设置系统消息、追加消息等。
- 使用 [`<CopilotTextarea />`](/reference/v1/components/CopilotTextarea) 组件实现自动补全功能。
- 跟随 [文本域自动补全教程](/built-in-agent/tutorials/ai-powered-textarea) 了解更多关于 CopilotKit 的内容。

我们还会有更多教程推出。
