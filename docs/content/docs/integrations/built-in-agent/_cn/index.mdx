**内置 Agent** 是 CopilotKit 最简单的 Agent 选项，即您"开箱即用"得到的功能。它直接连接到 LLM，完全支持工具、生成式 UI、共享状态以及所有 CopilotKit 功能——无需外部 Agent 框架。

它开箱即用地支持来自 OpenAI、Anthropic、Google 和 AI-SDK 定义模型的大多数流行模型。

## 何时使用内置 Agent

- **快速设置** — 无需配置或部署外部 Agent 框架
- **聊天 + 工具** — 您的用例主要是对话式的，带有前端和服务器工具
- **直接模型访问** — 您想直接使用 OpenAI、Anthropic、Google 或 AI-SDK 模型

<Callout type="info">
如果您需要对 Agent 循环进行更多控制，请考虑改用 [Agent 框架](/#explore-by-ai-backend)。
</Callout>
