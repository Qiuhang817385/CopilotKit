---
title: 文档贡献
---

我们理解，由于我们发展迅速，有时我们的文档网站可能会有些过时。因此，我们非常重视对文档的贡献。

## 先决条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- [pnpm](https://pnpm.io/) v9.x 全局安装 (`npm i -g pnpm@^9`)

## 如何贡献

<Steps>
  <Step>
  ### Fork 仓库

  首先，前往 [CopilotKit GitHub 仓库](https://github.com/CopilotKit/CopilotKit) 并创建一个 fork。

  然后，将 fork 的仓库克隆到您的本地机器：

  ```shell
  git clone https://github.com/<your-username>/CopilotKit
  cd CopilotKit/docs
  ```
  </Step>
  <Step>
  ### 在本地运行文档站点

  要在本地运行文档站点，请安装依赖项，然后以开发模式启动文档：

  ```shell
  pnpm install
  pnpm run dev
  ```

  文档站点应在 [http://localhost:3000](http://localhost:3000) 可用。
  </Step>
  <Step>
  ### 进行您的更改

  现在，您可以对文档网站进行更改。

  - 所有与文档相关的文件都位于 docs 仓库中
  - 您可能需要熟悉 [Nextra](https://nextra.site/) 以了解文档网站的结构。

  <Callout type="info">
    请确保检查您的更改是否有语法、拼写和格式错误。此外，确保链接和图片正常工作。
  </Callout>
  </Step>
  <Step>
  ### 审查更改并提交拉取请求

  一旦您对更改满意，就可以提交并推送它们。然后，前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls) 创建一个拉取请求。感谢您的贡献！
  </Step>
</Steps>
