## 这是什么？

CopilotKit 最常见的用例之一是使用 `useCopilotReadble` 注册应用状态和上下文。这样，您可以实时通知您的代理应用中的情况。

## 何时应该使用此功能？

当您想向用户提供关于工作内存的反馈时，可以使用此功能。随着代理状态的更新，您可以在应用程序中本地反映这些更新。

一些示例可能是：当前用户、当前页面等。这可以与您的代理实时共享。

## 实现
<Steps>
    <Step>
        ### 将您的数据包装在可读项中

        [`useAgentContext` 钩子](/reference/v1/hooks/useAgentContext)用于将数据作为上下文添加到 Copilot。

        ```tsx title="YourComponent.tsx" showLineNumbers {1, 7-10}
        "use client" // 仅在 Next.js 中使用 App Router 时需要。 // [!code highlight]
        import { useAgentContext } from "@copilotkit/react-core/v2"; // [!code highlight]
        import { useState } from 'react';

        export function YourComponent() {
            // 创建同事状态并添加一些示例数据
            const [colleagues, setColleagues] = useState([
                { id: 1, name: "John Doe", role: "Developer" },
                { id: 2, name: "Jane Smith", role: "Designer" },
                { id: 3, name: "Bob Wilson", role: "Product Manager" }
            ]);

            // 定义 Copilot 可读状态
            // [!code highlight:4]
            useAgentContext({
                description: "The current user's colleagues",
                value: colleagues,
            });
            return (
                // 您的自定义 UI 组件
                <>...</>
            );
        }
        ```
    </Step>

    <Step>
        ### 在您的 Mastra 代理中使用数据

        Mastra 有 `RuntimeContext` 类，可用于在运行时设置和访问额外上下文。
        CopilotKit 的上下文会自动注入到其中，并且可以立即使用。
        您可以在[这里](https://mastra.ai/en/docs/agents/runtime-context)阅读更多相关信息。

        ```tsx title="agent.ts"
        export const colleaguesContactorAgent = new Agent({
            name: "Colleagues contact Agent",
            model: openai("gpt-5.2"),
            // 使用注入的运行时上下文
            // [!code highlight:9]
            instructions: ({ runtimeContext }) => {
              // AG-UI 上下文是一个项目数组，可以通过过滤获取特定上下文
              const aguiContext = runtimeContext.get('ag-ui')?.context
              const colleaguesContextItem = aguiContext.find(contextItem => contextItem.description === 'The current user\'s colleagues"')
              return `
                You are a helpful assistant that can help emailing colleagues.
                The user's colleagues are: ${colleaguesContextItem.value}
              `
            },
            // ... 用于配置代理的其他所有内容
        });
        ```
    </Step>
    <Step>
        ### 试一试！
        向您的代理询问有关上下文的问题。它应该能够回答！
    </Step>
</Steps>
