该系统的基础建立在 Mastra 通过 AG-UI 提供的有状态架构之上。Mastra 代理可以在整个执行过程中保持其内部状态，您可以通过 `useCoAgentState` 钩子访问它。

## 何时应该使用此功能？
当您希望促进代理和用户之间的协作时，状态流式传输是完美的选择。您的 Mastra 代理持久化的任何状态都将自动与 UI 共享。同样，用户在 UI 中更新的任何状态都会自动反映出来。

这允许一致的体验，代理和用户都在同一页面上。
