## 这是什么？

工具是 LLM 调用预定义、通常是确定性函数的一种方式。CopilotKit 允许您在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 什么时候应该使用它？

当您想向用户提供有关 Agent 正在执行的操作的反馈时，在 UI 中渲染工具非常有用，特别是在您的 Agent 调用工具时。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

### 给您的 Agent 一个可调用的工具

<Tabs groupId="language_agent-spec_agent" items={['Python']} default="Python" persist>
    <Tab value="Python">
        ```python title="agent.py"

        # 创建 Agent
        from pyagentspec.agent import Agent
        from pyagentspec.llms import OpenAiCompatibleConfig
        from pyagentspec.property import StringProperty
        from pyagentspec.tools import ServerTool
        from pyagentspec.serialization import AgentSpecSerializer

        llm = OpenAiCompatibleConfig(
            name="my_llm",
            model_id="gpt-5.2-mini",
            url="https://api.openai.com/v1",
        )
        weather_tool = ServerTool( # ServerTool 是 Agent Spec 中的后端工具
            name="get_weather",
            description="获取指定位置的天气。",
            inputs=[StringProperty(title="location", description="要获取天气预报的位置。必须是城市/城镇名称。")],
            outputs=[StringProperty(title="weather_result")],
        )
        agent = Agent(
            name="my_agent",
            llm_config=llm,
            system_prompt="根据天气预报结果和用户输入，给写用户一个回复",
            tools=[weather_tool],
            human_in_the_loop=True,
        )
        agentspec_json_config = AgentSpecSerializer().to_json(agent)

        async def get_weather(location: str = "Everywhere ever") -> str:
            """获取指定位置的天气。确保位置完整拼写出来。"""
            return f"{location} 的天气是晴朗的。"

        # 启动服务器
        from fastapi import APIRouter, FastAPI
        from ag_ui_agentspec.agent import AgentSpecAgent
        from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint


        runtime = "langgraph" # 您也可以选择 "wayflow"
        router = APIRouter()
        add_agentspec_fastapi_endpoint(
            app=router,
            agentspec_agent=AgentSpecAgent(
                agentspec_json_config,
                runtime=runtime,
                tool_registry={"get_weather": get_weather},
            ),
            path=f"/{runtime}/path_to_my_agent",
        )
        app = FastAPI(title="Agent-Spec x AG-UI 示例 - 后端工具")
        app.include_router(router)

        if __name__ == "__main__":
            import uvicorn
            uvicorn.run(app, host="0.0.0.0", port=8000)

        ```
    </Tab>

</Tabs>

<Step>
### 在您的前端渲染工具调用
此时，您的 Agent 将能够调用 `get_weather` 工具。现在
我们只需要添加一个 `useRenderTool` Hook 来在 UI 中渲染工具调用。

<Callout type="info" title="重要">
  要在 UI 中渲染工具调用，操作的名称必须与工具的名称匹配。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:12]
  useRenderTool({
    name: "get_weather",
    render: ({status, args}) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "正在调用天气 API..."}
          {status === "complete" && `已为 ${args.location} 调用天气 API。`}
        </p>
      );
    },
  });
  // ...
}
```
