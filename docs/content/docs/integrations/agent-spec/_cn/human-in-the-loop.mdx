## 这是什么？

前端工具使你能够定义 Agent Spec Agent 可以调用的客户端函数，执行完全发生在用户的浏览器中。当你的 Agent 调用前端工具时，逻辑在客户端运行，让你直接访问前端环境。

这可以用于让[你的 Agent 控制 UI](/agent-spec/frontend-tools)、[生成式 UI](/agent-spec/frontend-tools)，或用于人在回路交互。

在本指南中，我们介绍前端工具在人在回路中的使用。

## 何时使用？

当你需要 Agent 与客户端原语交互时使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问浏览器 API，如 localStorage、sessionStorage 或 cookie
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户即时浏览器上下文的操作

## 实现步骤

<Steps>
    <Step>
      ### 运行并连接你的 Agent
      <RunAndConnect components={props.components} />
    </Step>

    <Step>
        ### 创建前端人在回路工具

        前端工具可以以多种方式利用。其中之一是拥有一个由用户决策控制工具响应的人在回路流程。

        在这个例子中，我们将模拟执行命令的"审批"流程。首先，使用 `useHumanInTheLoop` Hook 创建一个提示用户审批的工具。

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "给用户提供两个选项之间的选择，并让他们选择一个。",
            parameters: [
              {
                name: "option_1",
                type: "string",
                description: "第一个选项",
                required: true,
              },
              {
                name: "option_2",
                type: "string",
                description: "第二个选项",
                required: true,
              },
            ],
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} 被选中`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} 被选中`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 设置你的 Agent

        人在回路工具通过 Agent Spec 中的 `ClientTool` 概念启用。有关更多详细信息，请参阅[前端工具指南](/agent-spec/frontend-tools)。简而言之，在你的 Agent Spec 配置中，你需要提供工具声明，但执行发生在客户端（在你的前端）。
    </Step>
    <Step>
        ### 试试看！

        你现在赋予了 Agent 向用户展示两个选项并让他们选择一个的能力。然后 Agent 将知道用户的选择，并可以在后续步骤中使用它。

        ```
        你能给我看两个好的餐厅名称选项吗？
        ```
    </Step>
</Steps>
