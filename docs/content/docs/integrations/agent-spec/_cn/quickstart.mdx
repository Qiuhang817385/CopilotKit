## 前置要求

- Node.js 20+
- Python 3.10–3.13

## 1) 安装 Agent Spec AG-UI 适配器（后端）

Agent Spec 的 AG-UI 集成位于 `ag-ui/integrations/agent-spec/python`。以下是安装方法：

```bash
# 克隆适配器并进入 Python 包
git clone https://github.com/ag-ui-protocol/ag-ui.git
cd ag-ui/integrations/agent-spec/python
```

由于此集成包使用 `uv` 作为包管理器，你可以轻松安装：

```bash
uv sync
```

Agent Spec 是一种规范语言，用于声明你的 Agent 和工作流的结构。Agent Spec Agent 可以在各种 Agent 框架上运行。目前，我们支持 LangGraph 和 WayFlow（Oracle 的参考 Agent 框架，原生支持 Agent Spec）。
以下是取决于你要在哪个 Agent 框架上执行 Agent Spec Agent 的不同安装选项：

```bash
uv sync --extra langgraph                         # 用于 LangGraph
uv sync --extra wayflow                           # 用于 WayFlow
uv sync --extra langgraph --extra wayflow         # 用于两者
```

或者，你可以使用 `pip`：

```bash
pip install -e .[wayflow]
pip install -e .[langgraph]
pip install -e .[wayflow,langgraph]
```

注意：这些命令会从源代码安装 [`pyagentspec`](https://github.com/oracle/agent-spec) 和 [`wayflowcore`](https://github.com/oracle/wayflow) 包（即各自的 GitHub 仓库）。
相反，你可以单独从 PyPI 安装这些包：

```bash
pip install pyagentspec[langgraph]
pip install wayflowcore
```

环境：

```bash
export OPENAI_API_KEY=...
export OPENAI_MODEL=gpt-5.2
```

注意，这些环境变量可以指向任何 OpenAI 兼容的 LLM 提供商（例如，本地 vLLM 服务器、Together AI），但变量名需要是 `OPENAI_API_KEY` 和 `OPENAI_MODEL`。

参考：Agent Spec 文档 AG-UI 教程 https://oracle.github.io/agent-spec/26.1.0/howtoguides/howto_ag_ui.html。

## 2) 搭建 UI

从我们的启动模板开始：

```bash
npx copilotkit@latest create
```

或使用完整的启动模板仓库：https://github.com/CopilotKit/with-agent-spec。它包含一个 Agent Spec Agent 的示例定义[这里](https://github.com/CopilotKit/with-agent-spec/blob/main/agent/src/agentspec_agent.py)。

注意，`npx` 命令会自动在 https://github.com/ag-ui-protocol/ag-ui/tree/main/integrations/agent-spec/python 安装 AG-UI Agent Spec 集成，它会按上述说明安装 `pyagentspec` 和可选的运行时适配器依赖。

### 最小启动 Agent Spec Agent 定义

```python agentspec_agent.py
from pyagentspec.agent import Agent
from pyagentspec.llms import OpenAiCompatibleConfig
from pyagentspec.serialization import AgentSpecSerializer

agentspec_agent = Agent(
    name="AgentSpecAgent",
    description="一个可以调用工具的启动 Agent。",
    system_prompt="你是一个有用的助手，名叫 Specky，话很多。",
    llm_config=OpenAiCompatibleConfig(
        name="my-llm",
        model_id="gpt-5.2",
        url="https://api.openai.com/v1",
    ),
)

agent_spec_config = AgentSpecSerializer().to_json(agentspec_agent)
```

## 3) 添加最小 FastAPI 端点（后端）

创建一个 FastAPI 应用，加载你的 Agent Spec 文件并暴露一个 AG-UI FastAPI 端点。将 `runtime` 替换为与你的适配器匹配（`langgraph` 或 `wayflow`）。

```python src/main.py
from fastapi import FastAPI
from ag_ui_agentspec.agent import AgentSpecAgent
from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint

agent_spec_config = <加载你的 Agent Spec Agent 的 json/yaml 字符串>
runtime = "langgraph"  # 或 "wayflow"

app = FastAPI()
agent = AgentSpecAgent(agent_spec_config=agent_spec_config, runtime=runtime)
add_agentspec_fastapi_endpoint(app, agentspec_agent=agent, path="/")

if __name__ == "__main__":
    uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
```

这里，我们使用集成包中的 `add_agentspec_fastapi_endpoint` 工具。它设置了端点和 Agent Spec 跟踪事件到 AG-UI 事件的连接。

运行后端 Agent：

```bash
uv run src/main.py
```

## 4) 将 UI 连接到你的前端服务器

确保前端 UI 服务器知道后端 Agent 运行在哪个主机/端口。在本教程中，我们使用 http://localhost:8000/ 作为主机/端口。

## 5) 运行 Next.js

从[我们的启动模板仓库](https://github.com/sonleoracle/with-agent-spec/)的根目录运行：

```bash
pnpm dev
# 或 npm run dev / yarn dev / bun dev
```

注意，此命令也会在 `agent/src` 中启动 Agent 后端。现在，打开 http://localhost:3000 并开始与你的 Agent 聊天。

## 工具和工具注册表

如果你的 Agent Spec 包括在 Agent 相同环境中执行的服务端工具，请在加载 `AgentSpecAgent` 时按名称将它们映射到 Python 可调用对象的 `tool_registry` 字典中。

```python title="按名称绑定后端工具"
from __future__ import annotations
from fastapi import FastAPI
from ag_ui_agentspec.agent import AgentSpecAgent
from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint

def get_weather(city: str) -> Dict[str, Any]:
    return {"city": city, "temp_c": 22}

tool_registry = {"get_weather": get_weather}

app = FastAPI()
agent = AgentSpecAgent(
    agent_spec_config=<你的 Agent Spec Agent 的 json/yaml 字符串>,
    runtime="langgraph",  # 或 "wayflow"
    tool_registry=tool_registry,
)
add_agentspec_fastapi_endpoint(app, agentspec_agent=agent, path="/")
```

前端工具（对应于 Agent Spec `ClientTool`）在浏览器中运行，不需要添加到工具注册表 — 有关详细信息，请参阅[生成式 UI 前端工具](/agent-spec/frontend-tools)。

## 幕后发生了什么

Agent Spec 和 `pyagentspec` SDK 帮助你以可读且可移植的配置对象/JSON 文件定义 Agent 和工作流。
不同的适配器 LangGraph 和 WayFlow 将你的 Agent Spec 配置加载到特定于框架的对象中并执行它们。换句话说，Agent Spec 是"编译器"，框架是"运行时"。
在此转换过程中，适配器配置加载的对象，使其发出 Agent Spec 跟踪事件。这些在运行时之间是标准化的。
最后，AG-UI Agent Spec 集成监听 Agent Spec 跟踪事件并将它们导出为 AG-UI 事件。这些包括 Agent 执行、工具调用、Agent 发送的消息等。
换句话说，如果 Agent 在执行期间发出事件（这是运行时相关的），将创建相应的 AG-UI 事件。
在前端，CopilotKit 将 AG-UI 事件转换并渲染到 UI 中。
