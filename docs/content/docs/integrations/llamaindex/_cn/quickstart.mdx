## 先决条件

在开始之前，您需要准备以下内容：

- OpenAI API 密钥
- Node.js 20+
- Python 3.10+
- 您喜欢的包管理器

            <Step>
                ### 初始化您的智能体项目

                如果您还没有设置 Python 项目，请使用 `uv` 创建一个：

                ```bash
                uv init my-agent
                cd my-agent
                ```
            </Step>
            <Step>
                ### 安装带有 AG-UI 的 LlamaIndex

                将带有 AG-UI 支持的 LlamaIndex 和 uvicorn 添加到您的项目中：

                ```bash
                uv add llama-index llama-index-llms-openai llama-index-protocols-ag-ui fastapi uvicorn
                ```

                <Callout type="info" title="什么是 AG-UI？">
                  AG-UI 是一个用于前端-智能体通信的开放协议。`llama-index-protocols-ag-ui` 包提供了 CopilotKit 可以连接的 LlamaIndex 集成。
                </Callout>
            </Step>
            <Step>
                ### 配置环境

                将您的 OpenAI API 密钥设置为环境变量：

                ```bash
                export OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="其他模型怎么办？">
                  此示例使用 OpenAI 的 GPT-4o，但您可以修改它以使用 LlamaIndex 支持的任何语言模型。
                </Callout>
            </Step>
            <Step>
                ### 通过 AG-UI 暴露您的智能体

                更新您的智能体文件，将其暴露为 AG-UI ASGI 应用：

                ```python title="main.py"
                from fastapi import FastAPI
                from llama_index.llms.openai import OpenAI
                from llama_index.protocols.ag_ui.router import get_ag_ui_workflow_router

                # 初始化 LLM
                llm = OpenAI(model="gpt-5.2")

                # 创建 AG-UI 工作流路由器
                agentic_chat_router = get_ag_ui_workflow_router(
                    llm=llm,
                    system_prompt="你是一个有帮助的 AI 助手，可以访问各种工具和功能。",
                )

                # 创建 FastAPI 应用
                app = FastAPI(
                    title="LlamaIndex 智能体",
                    description="与 CopilotKit 集成的 LlamaIndex 智能体",
                    version="1.0.0"
                )

                # 包含路由器
                app.include_router(agentic_chat_router)

                # 健康检查端点
                @app.get("/health")
                async def health_check():
                    return {"status": "healthy", "agent": "llamaindex"}

                if __name__ == "__main__":
                    import uvicorn
                    uvicorn.run(app, host="localhost", port=8000)
                ```
            </Step>
            <Step>
                ### 创建您的前端

                CopilotKit 适用于任何基于 React 的前端。在此示例中，我们将使用 Next.js。

                ```bash
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit 包

                ```npm
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime @ag-ui/llamaindex
                ```
            </Step>
            <Step>
                ### 设置 Copilot 运行时

                创建一个 API 路由，将 CopilotKit 连接到您的 LlamaIndex 智能体：

                ```tsx title="app/api/copilotkit/route.ts"
                import {
                  CopilotRuntime,
                  ExperimentalEmptyAdapter,
                  copilotRuntimeNextJSAppRouterEndpoint,
                } from "@copilotkit/runtime";
                import { LlamaIndexAgent } from "@ag-ui/llamaindex";
                import { NextRequest } from "next/server";

                const serviceAdapter = new ExperimentalEmptyAdapter();

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new LlamaIndexAgent({ url: "http://localhost:8000/run" }),
                  }   
                });

                export const POST = async (req: NextRequest) => {
                  const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({
                    runtime,
                    serviceAdapter,
                    endpoint: "/api/copilotkit",
                  });

                  return handleRequest(req);
                };
               ```
            </Step>
            <Step>
                ### 配置 CopilotKit 提供者

                使用 CopilotKit 提供者包装您的应用：

                ```tsx title="app/layout.tsx"
                import { CopilotKit } from "@copilotkit/react-core"; // [!code highlight]
                import "@copilotkit/react-ui/v2/styles.css";

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="zh">
                      <body>
                        {/* [!code highlight:3] */}
                        <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent">
                          {children}
                        </CopilotKit>
                      </body>
                    </html>
                  );
                }
                ```
            </Step>
            <Step>
              ### 添加聊天界面

              将 CopilotSidebar 组件添加到您的页面：

              ```tsx title="app/page.tsx"
              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>您的应用</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
            <Step>
                ### 启动您的智能体

                从您的智能体目录，启动智能体服务器：

                ```bash
                uv run main.py
                ```

                您的智能体将在 `http://localhost:8000` 可用。
            </Step>

                        - 确保您的智能体在端口 8000 上运行
                        - 检查您的 OpenAI API 密钥是否正确设置
                        - 验证 `@ag-ui/llamaindex` 包是否已安装在您的前端
                    </Accordion>
