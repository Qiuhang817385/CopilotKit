## 什么是共享状态？

CoAgents 维护一个共享状态，将您的 UI 与智能体的执行无缝连接。这个共享状态系统允许您：

- 显示智能体的当前进度和中间结果
- 通过 UI 交互更新智能体的状态
- 实时响应整个应用程序中的状态变化

该系统的基础建立在 LlamaIndex 的 AG-UI 协议集成之上，它在工作流路由器中提供 `initial_state` 支持。

## 什么时候应该使用这个？

当您想要促进智能体和用户之间的协作时，状态流是完美的。您的 LlamaIndex 智能体
持久化的任何状态都将被 UI 自动共享。同样，用户在 UI 中更新的任何状态都将自动反映。

这允许一致的体验，智能体和用户都在同一页面上。
