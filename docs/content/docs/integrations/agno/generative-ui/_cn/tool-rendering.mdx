## 这是什么？

工具是 LLM 调用预定义、通常是确定性函数的一种方式。CopilotKit 允许您在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 何时使用？

当您想向用户提供关于 Agent 正在做什么的反馈时，在 UI 中渲染工具非常有用，特别是当您的 Agent 正在调用工具时。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

### 给您的 Agent 一个可调用的工具

<Tabs groupId="language_agno_agent" items={['Python']} default="Python" persist>
    <Tab value="Python">
        ```python title="agent.py"
        from agno.agent import Agent
        from agno.models.openai import OpenAIChat
        from agno.tools import tool
        # ...

        # [!code highlight:6]
        @tool
        def get_weather(location: str):
            """
            获取给定位置的天气。
            """
            return f"{location} 的天气是 70 度。"

        # ...

        agent = Agent(
            model=OpenAIChat(id="gpt-5.2"),
            tools=[get_weather], # [!code highlight]
            description="一个可以回答问题并提供信息的有用助手。",
            instructions="保持友好和乐于助人。在适当的地方使用 markdown 格式回复。",
        )
        ```
    </Tab>

</Tabs>
</Step>
<Step>
### 在您的前端渲染工具调用
此时，您的 Agent 将能够调用 `get_weather` 工具。现在
我们只需要添加一个 `useRenderTool` Hook 来在 UI 中渲染工具调用。

<Callout type="info" title="重要">
  要在 UI 中渲染工具调用，操作的名称必须与工具的名称匹配。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  {/* [!code highlight:12] */}
  useRenderTool({
    name: "get_weather",
    render: ({status, args}) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "正在调用天气 API..."}
          {status === "complete" && `已为 ${args.location} 调用天气 API。`}
        </p>
      );
    },
  });
  // ...
}
```

</Step>

渲染工具调用并显示传递给工具的参数。
