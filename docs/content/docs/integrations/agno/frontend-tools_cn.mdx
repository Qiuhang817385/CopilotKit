## 这是什么？
前端工具允许你定义客户端函数，你的 Agno 代理可以调用它们，执行完全在用户的浏览器中进行。当你的代理调用前端工具时，逻辑在客户端运行，让你直接访问前端环境。

这可以用于 [让你的代理控制 UI](/agno/frontend-tools)、[生成式 UI](/agno/frontend-tools) 或 [人在回路](/agno/human-in-the-loop) 交互。

在本指南中，我们介绍使用前端工具驱动和与 UI 交互。

## 什么时候使用？
当你需要代理与客户端原语交互时使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问浏览器 API，如 localStorage、sessionStorage 或 cookies
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户即时浏览器上下文的操作

    <Step>
        ### 创建前端工具

        首先，你需要使用 [useFrontendTool](/reference/v1/hooks/useFrontendTool) Hook 创建一个前端工具。这里有一个简单的示例来开始，它会向用户问好。

        ```tsx title="page.tsx"
        import { z } from "zod";
        import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          {/* [!code highlight:12] */}
          useFrontendTool({
            name: "sayHello",
            description: "Say hello to the user",
            parameters: z.object({
              name: z.string().describe("The name of the user to say hello to"),
            }),
            handler: async ({ name }) => {
              alert(`Hello, ${name}!`);
              return `Said hello to ${name}!`;
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 在你的 Agno 代理中定义前端工具

        现在，我们需要修改代理以访问这些前端工具。

        在你的 Agno 代理中，使用 `@tool(external_execution=True)` 装饰器定义一个工具。这告诉 Agno 该工具将在外部（在前端）执行。

        ```python title="tools/frontend.py"
        from agno.tools import tool

        @tool(external_execution=True)
        def sayHello(name: str):
            """
            Say hello to the user.

            Args:
                name: The name of the user to say hello to
            """
        ```

        向你的代理注册该工具：

        ```python title="agent.py"
        from agno.agent import Agent
        from agno.models.openai import OpenAIChat
        from agno.os import AgentOS
        from agno.os.interfaces.agui import AGUI
        from tools.frontend import sayHello

        agent = Agent(
            model=OpenAIChat(id="gpt-5.2"),
            tools=[sayHello],
            description="A helpful assistant that can answer questions and provide information.",
            instructions="Be helpful and friendly. Format your responses using markdown where appropriate.",
        )

        agent_os = AgentOS(agents=[agent], interfaces=[AGUI(agent=agent)])
        app = agent_os.get_app()
        ```
    </Step>
