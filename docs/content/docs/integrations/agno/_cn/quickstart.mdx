## 先决条件

在开始之前，您需要以下内容：

- OpenAI API 密钥
- Node.js 20+
- Python 3.9+
- 您喜欢的包管理器

            description="我已经有一个 Agno 智能体，想要添加 CopilotKit。"

            <Step>
                ### 初始化您的智能体项目

                如果您还没有设置 Python 项目，请使用 `uv` 创建一个：

                ```bash
                uv init my-agent
                cd my-agent
                ```
            </Step>
            <Step>
                ### 安装带 AG-UI 的 Agno

                将 Agno 和 uvicorn 添加到您的项目：

                ```bash
                uv add agno fastapi uvicorn openai ag-ui-protocol
                ```
            </Step>
            <Step>
                ### 配置您的环境

                将您的 OpenAI API 密钥设置为环境变量：

                ```bash
                export OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="其他模型呢？">
                  此示例使用 OpenAI 的 GPT-4o，但您可以修改它以使用 Agno 支持的任何语言模型。
                </Callout>
            </Step>
            <Step>
                ### 通过 AG-UI 暴露您的智能体

                更新您的智能体文件以将其作为 AG-UI ASGI 应用程序暴露：

                ```python title="main.py"
                from agno.agent import Agent
                from agno.models.openai import OpenAIChat
                from agno.os import AgentOS
                from agno.os.interfaces.agui import AGUI

                agent = Agent(
                    model=OpenAIChat(id="gpt-5.2"),
                    description="一个可以回答问题并提供信息的有用助手。",
                    instructions="乐于助人且友好。适当使用 markdown 格式化您的回复。",
                )

                agent_os = AgentOS(agents=[agent], interfaces=[AGUI(agent=agent)])
                app = agent_os.get_app()

                if __name__ == "__main__":
                    agent_os.serve(app="main:app", port=8000, reload=True)
                ```

                <Callout type="info" title="什么是 AG-UI？">
                  AG-UI 是一个用于前端-智能体通信的开放协议。带有 AGUI 接口的 AgentOS 创建一个 CopilotKit 可以连接的 ASGI 应用程序。
                </Callout>
            </Step>
            <Step>
                ### 创建您的前端

                CopilotKit 适用于任何基于 React 的前端。在本示例中，我们将使用 Next.js。

                ```bash
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit 包

                ```npm
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime @ag-ui/agno
                ```
            </Step>
            <Step>
                ### 设置 Copilot Runtime

                创建一个 API 路由将 CopilotKit 连接到您的 Agno 智能体：

                ```tsx title="app/api/copilotkit/route.ts"
                import {
                  CopilotRuntime,
                  ExperimentalEmptyAdapter,
                  copilotRuntimeNextJSAppRouterEndpoint,
                } from "@copilotkit/runtime";
                import { AgnoAgent } from "@ag-ui/agno";
                import { NextRequest } from "next/server";

                const serviceAdapter = new ExperimentalEmptyAdapter();

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new AgnoAgent({ url: "http://localhost:8000/agui" }),
                  }
                });

                export const POST = async (req: NextRequest) => {
                  const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({
                    runtime,
                    serviceAdapter,
                    endpoint: "/api/copilotkit",
                  });

                  return handleRequest(req);
                };
               ```
            </Step>
            <Step>
                ### 配置 CopilotKit 提供程序

                用 CopilotKit 提供程序包装您的应用程序：

                ```tsx title="app/layout.tsx"
                import { CopilotKit } from "@copilotkit/react-core"; // [!code highlight]
                import "@copilotkit/react-ui/v2/styles.css";

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent">
                          {children}
                        </CopilotKit>
                      </body>
                    </html>
                  );
                }
                ```
            </Step>
            <Step>
              ### 添加聊天界面

              将 CopilotSidebar 组件添加到您的页面：

              ```tsx title="app/page.tsx"
              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>您的应用程序</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
            <Step>
                ### 启动您的智能体

                从您的智能体目录，启动智能体服务器：

                ```bash
                cd ..
                uv run main.py
                ```

                您的智能体将在 `http://localhost:8000/agui` 可用。
            </Step>
            <Step>
                ### 启动您的 UI

                在单独的终端中，导航到您的前端目录并启动开发服务器：
