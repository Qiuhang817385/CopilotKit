## v0.3 有哪些新功能？

从 `v0.3` 开始，我们更改了智能体（LangGraph）与 CopilotKit 之间消息同步的方式。本质上，两者现在将共享完全相同的消息历史记录。

这意味着您需要从 LangGraph 节点返回您希望出现在 CopilotKit 聊天中的消息，例如：

```python
def my_node(state: State, config: RunnableConfig) -> State:
    response = # ... LLM 调用 ...
    return {
        "messages": response,
    }
```

所有工具消息现在默认都会发出，因此您无需手动调用 `copilotkit_customize_config` 来配置工具调用发出。

## 如何迁移？

1. 确保从您的 LangGraph 节点返回您希望成为消息历史记录一部分的任何消息（工具调用或文本消息）。

2. 可选地，当您想发出工具调用时，移除手动的 `copilotkit_customize_config` 调用。

3. 如果您想隐藏聊天中的工具调用或消息，请使用 `copilotkit_customize_config` 并将 `emit_tool_calls` 或 `emit_messages` 设置为 `False`。确保不要在节点中返回这些消息，这样它们就不会成为消息历史记录的一部分。
