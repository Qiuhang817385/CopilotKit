## 这是什么？

您可以轻松地在原生应用程序 UX 中使用实时智能体状态，而不仅仅是在聊天 UI 中。

## 何时应该使用？

当您想向用户提供有关智能体状态的反馈时，您可以使用此功能。随着智能体状态的更新，您可以在应用程序中原生地反映这些更新。

        ```python title="agent.py"
        from typing import Literal

            language: Literal["english", "spanish"] = "english"

        def chat_node(state: AgentState, config: RunnableConfig):
          # 如果语言未定义，设置一个值。
          # 这是因为状态类中的默认值在运行时不会被读取
          language = state.get("language", "english")

          # ... 添加节点实现的其余部分并使用 language 变量

          return {
            # ... 添加要返回的其余状态
            # 返回语言以使其可供下一个节点和前端读取

          }
        ```

        ```ts title="agent-js/src/agent.ts"
        import { Annotation } from "@langchain/langgraph";
        import { CopilotKitStateAnnotation } from "@copilotkit/sdk-js/langgraph";

        export const AgentStateAnnotation = Annotation.Root({
            language: Annotation<"english" | "spanish">,
            ...CopilotKitStateAnnotation.spec,
        });
        export type AgentState = typeof AgentStateAnnotation.State;

        async function chat_node(state: AgentState, config: RunnableConfig) {
          // 如果语言未定义，使用默认值。
          const language = state.language ?? 'english'

          // ... 添加节点实现的其余部分并使用 language 变量

          return {
            # ... 添加要返回的其余状态
            # 返回语言以使其可供下一个节点和前端读取
            language
          }
        }
        ```
      </Tab>

  <Step>
    ### 使用 `useAgent` 钩子
    连接并运行智能体后，剩下的就是调用 `useAgent` 钩子，传递智能体的 ID，然后读取状态。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    function YourMainContent() {
      // [!code highlight:3]
      const { agent } = useAgent({
        agentId: "sample_agent",
      });

      const language = (agent.state.language as string) ?? "english";

      // ...

      return (
        // 为简洁起见，省略了样式
        <div>
          <h1>您的主要内容</h1>
          {/* [!code highlight:1] */}
          <p>语言: {language}</p>
        </div>
      );
    }
    ```
    <Callout type="info">
      `agent.state` 是反应式的，当智能体状态变化时会自动更新。
    </Callout>

## 在聊天中渲染智能体状态

您还可以使用 `useRenderTool` 或在聊天 UI 中访问 `agent.state` 来渲染智能体的状态。该状态是反应式的，会自动更新。

```tsx title="ui/app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

function YourMainContent() {
  // [!code highlight:3]
  const { agent } = useAgent({
    agentId: "sample_agent",
  });

  const language = (agent.state.language as string) ?? "english";

  return (
    <div>
      <p>语言: {language}</p>
    </div>
  );
}
```

## 中间流式传输和渲染智能体状态
默认情况下，LangGraph 智能体状态只会在 LangGraph 节点转换_之间_更新——这意味着状态更新将是不连续和延迟的。

您可能希望**连续地**渲染智能体状态更新。

请参阅 **[发出中间状态](/langgraph/shared-state/predictive-state-updates)。**
