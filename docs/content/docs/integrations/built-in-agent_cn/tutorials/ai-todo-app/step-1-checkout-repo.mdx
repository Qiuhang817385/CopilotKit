---
title: "第 1 步：检出仓库"
---

<Steps>
<Step>
### 检出仓库
我们将从检出待办清单应用的基础代码开始。我们将从 `base-start-here` 分支开始。

```shell
git clone -b base-start-here https://github.com/CopilotKit/example-todos-app.git
cd example-todos-app
```
</Step>
<Step>
### 安装依赖

要安装依赖，请运行以下命令：

```shell
npm install
```
</Step>
<Step>
### 启动项目

现在，您可以通过运行以下命令来启动项目：

```shell
npm run dev
```

您应该能够访问 [http://localhost:3000](http://localhost:3000) 并看到待办清单应用。可以随意把玩该应用以熟悉它。
</Step>
</Steps>
