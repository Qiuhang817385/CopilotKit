## 您将学到什么

在本教程中，您将使用一个简单的电子邮件应用程序，并为其添加 AI 驱动的自动补全功能。该应用是一个简单的电子邮件客户端，使用普通的文本区域来撰写邮件。您将向该应用添加 CopilotKit，以便在您输入时，文本区域能够提供相关的自动补全。该文本区域将能够感知完整的邮件历史。

您将学习：

- 💡 如何使用 `useCopilotReadable` 让您的 copilot 读取您应用的状态
- 💡 如何使用 `<CopilotTextarea />` 组件在您的应用中获取即时上下文感知的自动补全
- 💡 如何使用 Copilot Textarea 操作弹出窗口生成文本或调整文本区域中的现有文本
