现在我们的待办清单应用已经运行起来，我们准备集成 CopilotKit。在本教程中，我们将安装以下依赖：

- `@copilotkit/react-core`：CopilotKit 的核心库，包含 CopilotKit 提供程序和实用的钩子。
- `@copilotkit/react-textarea`：CopilotKit 的文本区域组件，可让您在应用中获得即时上下文感知的自动补全。

## 安装依赖

要安装 CopilotKit 依赖，请运行以下命令：

```npm
npm install @copilotkit/react-core @copilotkit/react-textarea
```

### 配置 CopilotKit 提供程序

```tsx title="app/page.tsx" showLineNumbers {5,10,14}
"use client";

import { EmailThread } from "@/components/EmailThread";
import { EmailsProvider } from "@/lib/hooks/use-emails";
import { CopilotKit } from "@copilotkit/react-core"; // [!code highlight]
import "@copilotkit/react-textarea/styles.css"; // [!code highlight]

export default function Home() {
  return (
    <CopilotKit runtimeUrl="/api/copilotkit">
      {" "}
      // [!code highlight]
      <EmailsProvider>
        <EmailThread />
      </EmailsProvider>
    {/* [!code highlight:1] */}
    </CopilotKit>
  );
}
```

</Step>
</Steps>

让我们分解一下：

- 首先，我们从 `@copilotkit/react-core` 导入了 `CopilotKit` 提供程序。
- 然后，我们用 `<CopilotKit>` 提供程序包裹了页面。
- 我们从 `@copilotkit/react-textarea` 导入了内置样式。
