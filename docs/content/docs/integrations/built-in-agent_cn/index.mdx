**内置代理**是 CopilotKit 最简单的代理选项，即您"开箱即用"所获得的。它直接连接到 LLM，完全支持工具、生成式 UI、共享状态和所有 CopilotKit 功能——无需外部代理框架。

它原生支持来自 OpenAI、Anthropic、Google 和 AI-SDK 定义的大多数流行模型。

## 何时使用内置代理

- **快速设置** — 无需配置或部署外部代理框架
- **聊天 + 工具** — 您的用例主要是带有前端和服务器工具的对话式应用
- **直接模型访问** — 您想直接使用 OpenAI、Anthropic、Google 或 AI-SDK 模型

<Callout type="info">
如果您需要对代理循环有更多控制，请考虑使用[代理框架](/#explore-by-ai-backend)。
</Callout>
