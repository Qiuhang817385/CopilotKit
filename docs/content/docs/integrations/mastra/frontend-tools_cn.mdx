## 这是什么？
前端工具让您能够定义客户端函数，供 Mastra Agent 调用，执行完全在用户的浏览器中进行。当 Agent 调用前端工具时，
逻辑在客户端运行，让您直接访问前端环境。

这可以用于[让您的 Agent 控制 UI](/mastra/frontend-tools)、[生成式 UI](/mastra/frontend-tools)，或用于人机协同交互。

在本指南中，我们将介绍驱动和与 UI 交互的前端工具的使用。

## 何时使用？
当需要 Agent 与客户端原语交互时使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问浏览器 API，如 localStorage、sessionStorage 或 cookie
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户即时浏览器上下文的操作

    <Step>
        ### 创建前端工具

        首先，您需要使用 [useFrontendTool](/reference/v1/hooks/useFrontendTool) Hook 创建一个前端工具。这里有一个简单的入门示例，向用户问好。

        ```tsx title="page.tsx"
        import { z } from "zod";
        import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          // [!code highlight:12]
          useFrontendTool({
            name: "sayHello",
            description: "向用户问好",
            parameters: z.object({
              name: z.string().describe("要问候的用户姓名"),
            }),
            handler: async ({ name }) => {
              alert(`你好，${name}！`);
              return `已向 ${name} 问好！`;
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 访问前端工具

        由于 Mastra 原生支持 AG-UI 协议，前端工具自动作为工具供 Agent 使用。
    </Step>
