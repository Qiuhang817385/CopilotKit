## 这是什么？

工具是 LLM 调用预定义函数（通常是确定性的）的一种方式。CopilotKit 允许您在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 什么时候使用？

当您的代理调用工具时，如果您希望向用户提供有关代理正在执行的操作的反馈，那么在 UI 中渲染工具会很有用。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

### 给您的代理一个可调用的工具

添加一个新的工具定义：

```ts title="src/mastra/tools/weatherInfo.ts"
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

export const weatherInfo = createTool({
  id: "weatherInfo",
  inputSchema: z.object({
    location: z.string(),
  }),
  description: `获取给定位置的当前天气信息`,
  execute: async ({ location }) => {
    // 工具逻辑在此处（例如，API 调用）
    console.log("使用工具获取天气信息，位置：", location);
    return { temperature: 20, conditions: "晴朗" }; // 示例返回值
  },
});
```

然后，将工具传递给代理：

```ts title="src/mastra/agents/weatherAgent.ts"
import { Agent } from "@mastra/core/agent";
import { openai } from "@ai-sdk/openai";
import { weatherInfo } from "../tools/weatherInfo";

export const weatherAgent = new Agent({
  name: "Weather Agent",
  instructions:
    "您是一个提供当前天气信息的有用助手。当被问及天气时，使用天气信息工具获取数据。",
  model: openai("gpt-5.2-mini"),
  tools: {
    weatherInfo,
  },
});
```

</Step>
<Step>
### 在前端渲染工具调用
此时，您的代理将能够调用 `weatherInfo` 工具。现在
我们只需要添加一个 `useRenderTool` 钩子来在 UI 中渲染工具调用。

<Callout type="info" title="重要">
  为了在 UI 中渲染工具调用，操作的名称必须与工具的名称匹配。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:12]
  useRenderTool({
    name: "weatherInfo",
    render: ({ status, args }) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "正在调用天气 API..."}
          {status === "complete" &&
            `已为 ${args.location} 调用天气 API。`}
        </p>
      );
    },
  });
  // ...
};
```

</Step>
<Step>
### 试试看！

尝试让代理获取某个位置的天气。您应该看到我们添加的自定义 UI 组件渲染工具调用并显示传递给工具的参数。
