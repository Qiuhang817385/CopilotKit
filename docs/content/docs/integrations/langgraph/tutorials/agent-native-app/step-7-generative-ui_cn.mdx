我们快完成了！在这一步中，我们将为应用程序添加生成式 UI，以便能够在聊天 UI 中可视化 Agent 
状态。这样做的最终目标是让用户能够看到 Agent 研究进度的实时更新。

<Callout>
我们将从 Agent 状态或其工具调用渲染的 UI 称为"生成式 UI"。
</Callout>

在本指南中，我们将开始使用 CopilotKit SDK 手动发出 Agent 状态。这是因为在
LangGraph 中，状态仅在节点变化时更新（即遍历边时）。

因此，进行中的工作默认不会向用户发出。但是，我们可以使用 `copilotkit_emit_state`
函数手动发出状态。通过发出的状态，我们将使用 `useCoAgentStateRender` Hook 在聊天中渲染更新，让用户
了解进度。

## 手动发出状态
研究 ANA 在多个地方发出状态。为了简单起见，我们将在 `agent/graph.py` 文件中添加 `copilotkit_emit_state` 函数
以便您了解它的工作原理。但是，如果您想查看，状态也会在以下文件中发出：
- `agent/tools/outline_writer.py`
- `agent/tools/section_writer.py`
- `agent/tools/tavily_extract.py`
- `agent/tools/tavily_search.py`

这些文件都会将进度写入 Agent 状态的 `logs` 字段。紧接着，我们调用 `copilotkit_emit_state` 将状态发送到前端。

例如，在 `tool_node` 中，我们根据工具结果更新一些状态，然后使用 `copilotkit_emit_state` 将状态发送到前端。

```python title="agent/graph.py"
# ...
from copilotkit.langchain import copilotkit_emit_state # [!code ++]
#...

async def tool_node(self, state: ResearchState, config: RunnableConfig) -> Command[Literal["process_feedback_node", "call_model_node"]]:
        # ...
        for tool_call in state["messages"][-1].tool_calls:
            # ...

            tool_state = {
                "title": new_state.get("title", ""),
                "outline": new_state.get("outline", {}),
                "sections": new_state.get("sections", []),
                "sources": new_state.get("sources", {}),
                "proposal": new_state.get("proposal", {}),
                "logs": new_state.get("logs", []),
                "tool": new_state.get("tool", {}),
                "messages": msgs
            }
            await copilotkit_emit_state(config, tool_state) # [!code ++]

        return tool_state
```

随着此循环的迭代，工具写入的中间状态将被发送到前端。基本上，任何时候您想要将状态发送到前端，都可以通过调用 `copilotkit_emit_state` 来实现。

</Step>

## 渲染发出的状态
现在，我们的状态正在被发送到前端。但是，我们需要在聊天中渲染它。为此，我们将使用 `useCoAgentStateRender` Hook。

```tsx title="frontend/src/app/layout.tsx"
import { useCoAgentStateRender, useLangGraphInterrupt } from "@copilotkit/react-core/v2"; // [!code ++]

export default function HomePage() {
    //...
    const { state: researchState, setResearchState } = useResearch()
    // ...

    // [!code ++:10]
    useCoAgentStateRender<ResearchState>({
        name: 'agent',
        render: ({ state }) => {
            if (state.logs?.length > 0) {
                return <Progress logs={state.logs} />;
            }
            return null;
        },
    }, [researchState]);

    // ...
}
```
