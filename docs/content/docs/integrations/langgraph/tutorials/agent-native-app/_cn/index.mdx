## 你将学到什么

在本教程中，我们将使用 CopilotKit 构建一个研究智能体原生应用程序 (ANA)。从一个基本的应用程序开始，我们将逐步添加智能体功能。

你将学习：
- 🎯 智能体原生应用程序的核心原则
- 🔄 LangGraph 如何帮助构建 LLM 行为
- 🧱 Copilot 智能体 (CoAgent) 的构建块
- 🛠️ 使用 CopilotKit 创建交互式智能体体验
