## 你将学到什么

在本教程中，你将使用一个智能体助手来增强一个简单的旅行应用程序。你将学习：

- 💡 什么是智能体助手以及如何使用它来增强你的应用程序
- 💡 如何使用 `useCoAgent` 在 UI 和智能体执行之间实现共享状态
- 💡 如何使用 `useCoAgentStateRender` 实现人机协同工作流
- 💡 如何渲染智能体执行的中间状态
