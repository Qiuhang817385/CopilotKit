### 设置 threadId

在 CopilotKit 中设置 `threadId` 属性时，即：

<Callout>
  使用 LangGraph 平台时，`threadId` 必须是 UUID。
</Callout>

```tsx
<CopilotKit threadId="2140b272-7180-410d-9526-f66210918b13">
  <YourApp />
</CopilotKit>
```

CopilotKit 将从数据库中恢复线程的完整状态，包括消息。（有关更多详细信息，请参阅 [消息持久化](/langgraph/advanced/persistence/message-persistence)。）

### 加载代理状态

这意味着任何代理的状态也将被恢复。例如：

```tsx
import { useAgent } from "@copilotkit/react-core/v2";

const { agent } = useAgent({ agentId: "research_agent" });

// agent.state 现在将是上面给定线程 ID 中 research_agent 的状态
```
