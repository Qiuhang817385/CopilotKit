## 这是什么？
默认情况下，CopilotKit 会将您的状态和工具调用流式传输到前端。
您可以通过使用 CopilotKit 的自定义 `RunnableConfig` 来禁用此功能。

## 什么时候应该使用这个功能？

偶尔，您会希望暂时禁用流式传输——例如，LLM 可能正在执行某些当前用户不应该看到的事情，例如在 HR 系统中发出涉及其他员工的工具调用或问题。

## 实现

### 禁用所有流式传输
您可以通过将 `emit_messages=False` 和 `emit_tool_calls=False` 传递给 CopilotKit 配置来禁用所有消息流式传输和工具调用流式传输。

<Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
    <Tab value="Python">
        ```python
        from copilotkit.langgraph import copilotkit_customize_config

        async def frontend_actions_node(state: AgentState, config: RunnableConfig):

            # 1) 配置 CopilotKit 不发出消息
            modifiedConfig = copilotkit_customize_config(
                config,
                emit_messages=False, # 如果您想禁用消息流式传输 # [!code highlight]
                emit_tool_calls=False # 如果您想禁用工具调用流式传输 # [!code highlight]
            )

            # 2) 向 LLM 提供操作
            model = ChatOpenAI(model="gpt-5.2").bind_tools([
              *state["copilotkit"]["actions"],
              # ... 您想要提供给模型的任何工具
            ])

            # 3) 使用 CopilotKit 的修改后的配置调用模型 # [!code highlight]
            response = await model.ainvoke(state["messages"], modifiedConfig) # [!code highlight]

            # 不返回新响应以向用户隐藏它
            return state
        ```

    <Callout type="warn" title="注意！">
        在 LangGraph Python 中，周围命名空间中的 `config` 变量被**隐式**传递到 LangChain LLM 调用中，即使没有显式提供。
