## 这是什么？

`useComponent` 让您可以将 React 组件注册为 Agent 可调用的工具。当 Agent 调用工具时，CopilotKit 会直接在聊天中用工具参数作为 props 渲染您的组件。

这是最简单的生成式 UI 形式 —— Agent 决定何时显示组件，CopilotKit 渲染它。无需处理逻辑，无需用户交互。

## 何时使用？

在以下情况使用 `useComponent`：
- 在聊天中内联显示丰富的 UI（卡片、图表、表格）
- 展示 Agent 响应中的结构化数据
- 渲染预览、状态指示器或视觉反馈
- 让 Agent 呈现纯文本之外的信息

对于需要用户交互的组件，请参阅 [交互式](/langgraph/generative-ui/your-components/interactive) 或 [中断式](/langgraph/generative-ui/your-components/interrupt-based)。

## 实现

<Steps>
  <Step>
    ### 运行并连接您的 Agent
    <RunAndConnect components={props.components} />
  </Step>
  <Step>
    ### 注册组件

    使用 `useComponent` Hook 注册 React 组件。Agent 可以通过名称调用它，CopilotKit 将用工具参数作为 props 渲染它。

    ```tsx title="app/page.tsx"
    import { useComponent } from "@copilotkit/react-core/v2"; // [!code highlight]
    import { z } from "zod";

    const weatherSchema = z.object({
      city: z.string().describe("城市名称"),
      temperature: z.number().describe("华氏温度"),
      condition: z.string().describe("天气状况"),
    });

    function WeatherCard({ city, temperature, condition }: z.infer<typeof weatherSchema>) {
      return (
        <div className="rounded-lg border p-4">
          <h3 className="font-semibold">{city}</h3>
          <p className="text-2xl">{temperature}°F</p>
          <p className="text-sm text-gray-500">{condition}</p>
        </div>
      );
    }

    function YourMainContent() {
      // [!code highlight:9]
      useComponent({
        name: "showWeather",
        description: "显示城市的天气卡片。",
        parameters: weatherSchema,
        render: WeatherCard,
      });

      return <div>{/* ... */}</div>;
    }
    ```
  </Step>
  <Step>
    ### 安装 CopilotKit SDK

    现在，我们需要确保 Agent 可以访问前端工具。在终端中，导航到 Agent 的文件夹并从那里继续。

    <InstallSDKSnippet components={props.components}/>
  </Step>
  <Step>
    ### 继承自 CopilotKitState

    要访问 CopilotKit 提供的前端工具，请在 Agent 的状态定义中继承 `CopilotKitState`：

    <Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
      <Tab value="Python">

        from copilotkit import CopilotKitState # [!code highlight]

        export const AgentStateAnnotation = Annotation.Root({
          ...CopilotKitStateAnnotation.spec, // [!code highlight]

    当 Agent 的 LLM 决定使用工具时，CopilotKit 会自动在聊天中渲染您的组件。该工具注册为前端工具，Agent 可以发现并调用它。

## 无参数

对于不需要类型化参数的简单组件：

```tsx
useComponent({
  name: "showGreeting",
  render: ({ message }: { message: string }) => (
    <div className="rounded border p-3 bg-blue-50">
      <p>{message}</p>
    </div>
  ),
});
```

## 限定 Agent 范围

在多 Agent 设置中，将组件限定到特定 Agent：

```tsx
useComponent({
  name: "renderProfile",
  parameters: z.object({ userId: z.string() }),
  render: ProfileCard,
  agentId: "support-agent",
});
```
