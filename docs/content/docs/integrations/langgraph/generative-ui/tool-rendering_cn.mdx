## 这是什么？

工具是 LLM 调用预定义（通常是确定性）函数的一种方式。CopilotKit 允许您在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 何时使用？

当想要向用户提供 Agent 正在做什么的反馈时，在 UI 中渲染工具很有用，特别是在 Agent 调用工具时。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

    <Tab value="TypeScript">
        ```typescript title="agent-js/src/agent.ts"
        import { ChatOpenAI } from "@langchain/openai";
        import { tool } from "@langchain/core/tools";
        import { z } from "zod";

        // [!code highlight:12]
        const get_weather = tool(
          (args) => {
            return `${args.location} 的天气是 70 度。`;
          },
          {
            name: "get_weather",
            description: "获取给定位置的天气。",
            schema: z.object({
              location: z.string().describe("要获取天气的位置"),
            }),
          }
        );

        async function chat_node(state: AgentState, config: RunnableConfig) {
          const model = new ChatOpenAI({ temperature: 0, model: "gpt-5.2" });
          const modelWithTools = model.bindTools([get_weather]); // [!code highlight]

          const response = await modelWithTools.invoke([
            new SystemMessage("您是一个有用的助手。"),
            ...state.messages,
          ], config);

          // ...
        }
        ```

### 在前端渲染工具调用
此时，Agent 将能够调用 `get_weather` 工具。现在
我们只需要添加一个 `useRenderTool` Hook 在 UI 中渲染工具调用。

<Callout type="info" title="重要">
  要在 UI 中渲染工具调用，名称必须与工具名称匹配。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
import { z } from "zod";
// ...

const weatherParams = z.object({
  location: z.string().describe("要获取天气的位置"),
});

const YourMainContent = () => {
  // ...
  // [!code highlight:14]
  useRenderTool({
    name: "get_weather",
    parameters: weatherParams,
    render: ({ status, parameters }) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "正在调用天气 API..."}
          {status === "complete" && `已调用 ${parameters.location} 的天气 API。`}
        </p>
      );
    },
  });
  // ...
}
```
