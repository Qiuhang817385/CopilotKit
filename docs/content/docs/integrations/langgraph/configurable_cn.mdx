## 这是什么？
LangGraph Agent 能够接受执行参数，例如认证令牌和类似的属性。
您可以使用此功能添加这些参数。

如果您想进一步了解，可以参考 [LangGraph 的配置指南](https://docs.langchain.com/oss/python/langgraph/graph-api#add-runtime-configuration)

## 何时使用？

当您想要发送执行时配置信息（例如不同会话的不同令牌或元数据）且这些信息不应属于 Agent 状态时，此功能非常有用。

## 实现

默认情况下，LangGraph Agent 会用一个 `config` 参数调用。此配置具有一个 `configurable` 属性，可以访问并填充您的数据。

<Steps>
<Step>
### 从前端传递配置
首先，按照您希望在 Agent 中接收的方式传递配置属性

```tsx title="app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

function YourMainContent() {
  // ...

  // [!code highlight:3]
  const { agent } = useAgent({
    agentId: "sample_agent",
  });

  // 运行 Agent 时传递配置
  // [!code highlight:8]
  agent.runAgent({
    forwardedProps: {
      config: {
        configurable: {
          authToken: 'example-token'
        },
        recursion_limit: 50,
      }
    }
  });

  // ...

  return (... 您的组件 UI 标记)
}
```
</Step>
<Step>
### 在 Agent 中使用可配置项
现在您可以在任何 Agent 节点中从提供的 config 参数中拉取值

<Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
    <Tab value="Python">
        ```python
        async def agent_node(state: AgentState, config: RunnableConfig):

            auth_token = config['configurable'].get('authToken', None)

            return state
        ```
    </Tab>
    <Tab value="TypeScript">
        ```typescript
        async function agentNode(state: AgentState, config: RunnableConfig): Promise<AgentState> {
            const authToken = config.configurable?.authToken ?? null;

            return state;
        }
        ```
    </Tab>
</Tabs>
</Step>
<Step>
    ### 可选：定义可配置项模式
    如果需要，您可以定义一个模式来指示您希望接收哪些可配置项。
    传递给"configurables"但不包含在模式中的任何项目都将被过滤掉。

    您可以在[此处](https://docs.langchain.com/oss/python/langgraph/graph-api#add-runtime-configuration%23define-graph)阅读更多相关信息。
    <Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
        <Tab value="Python">
            ```python
            from typing import TypedDict

            # 定义配置中允许哪些属性
            class ConfigSchema(TypedDict):
              authToken: str

            # ...添加所有必要的图节点

            # 定义状态图时，应用配置模式
            workflow = StateGraph(AgentState, config_schema=ConfigSchema)
            ```
        </Tab>
        <Tab value="TypeScript">
            ```typescript
            import { Annotation } from "@langchain/langgraph";

            // 定义配置中允许哪些属性
            export const ConfigSchemaAnnotation = Annotation.Root({
              authToken: Annotation<string>
            })

            // ...添加所有必要的图节点

            // 定义状态图时，应用配置模式
            const workflow = new StateGraph(AgentStateAnnotation, ConfigSchemaAnnotation)
            ```
        </Tab>
    </Tabs>
</Step>
</Steps>
