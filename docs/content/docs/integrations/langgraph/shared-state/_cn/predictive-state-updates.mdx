## 这是什么？

LangGraph Agent 的状态是不连续更新的；仅在图中的节点转换之间。
但即使图中的一个_节点_通常也需要许多秒才能运行，并且包含用户感兴趣的子步骤。

**Agent 原生应用程序**向最终用户反映 Agent 正在做什么，**尽可能连续地**。

CopilotKit 通过其 **_预测状态更新_** 概念实现这一点。


## 何时使用？
您可以在想要向用户提供有关 Agent 正在做什么的反馈时使用此功能，特别是：

- **保持用户参与**，避免长时间的加载指示器
- **建立信任**，通过展示 Agent 正在处理什么
- 启用 **Agent 引导** - 允许用户在需要时纠正 Agent 的方向

## 重要说明

当 LangGraph 中的节点完成执行时，**其返回的状态成为唯一真实来源**。虽然中间状态更新对于实时反馈很棒，但您想要持久化的任何更改必须显式包含在节点的最终返回状态中。否则，当节点完成时，它们将被覆盖。

                    <Tab value="Python">
                        ```python
                        from copilotkit.langgraph import copilotkit_customize_config
                        from copilotkit import CopilotKitState
                        from langgraph.types import Command
                        from langgraph.graph import END
                        from langchain.tools import tool
                        from langchain_openai import ChatOpenAI
                        from langchain_core.messages import SystemMessage, AIMessage
                        from langchain_core.runnables import RunnableConfig

                        # 定义一个步骤进度工具供 LLM 报告步骤
                        @tool
                        def step_progress_tool(steps: list[str])
                            """读取和报告步骤"""

                        async def frontend_actions_node(state: AgentState, config: RunnableConfig):
                            # 配置 CopilotKit 将步骤进度工具调用视为最终状态的预测
                            config = copilotkit_customize_config(
                                config,
                                emit_intermediate_state=[
                                    {
                                        "state_key": "observed_steps",
                                        "tool": "step_progress_tool",
                                        "tool_argument": "steps"
                                    },
                                ]
                            )

                            system_message = SystemMessage(
                                content=f"您是一个任务执行者。假装执行给您的任务，使用 step_progress_tool 报告步骤。"
                            )

                            # 向 LLM 提供操作
                            model = ChatOpenAI(model="gpt-4").bind_tools(
                                [
                                    *state["copilotkit"]["actions"],
                                    step_progress_tool
                                    # 您的其他工具放在这里
                                ],
                            )

                            # 使用 CopilotKit 的修改后的配置调用模型
                            response = await model.ainvoke([
                                system_message,
                                *state["messages"],
                            ], config)

                            # 在状态中设置步骤，以便它们被持久化并传达给前端
                            if isinstance(response, AIMessage) and response.tool_calls and response.tool_calls[0].get("name") == 'step_progress_tool':
                                return Command(
                                    goto=END,
                                    update={
                                        "messages": response,
                                        "observed_steps": response.tool_calls[0].get("args", None).get('steps')
                                    }
                                )

                            return Command(goto=END, update={"messages": response})
                        ```

                        ```typescript
                        import { copilotkitCustomizeConfig } from '@copilotkit/sdk-js/langgraph';

                        async function frontendActionsNode(state: AgentState, config: RunnableConfig): Promise<AgentState> {
                            const modifiedConfig = copilotkitCustomizeConfig(config, {
                                emitIntermediateState: [
                                {
                                    stateKey: "observed_steps",
                                    tool: "StepProgressTool",
                                    toolArgument: "steps",
                                },
                                ],
                            });

                            const stepProgress = tool(
                                async (args) => args,
                                {
                                    name: "StepProgressTool",
                                    description: "通过更新步骤数组记录进度",
                                    schema: z.object({
                                        steps: z.array(z.string()),
                                    }),
                                }
                            );

                            const model = new ChatOpenAI({
                                model: "gpt-5.2",
                            }).bindTools([stepProgress]);

                            const system_message = new SystemMessage("您是一个任务执行者。假装执行给您的任务，使用 StepProgressTool 报告步骤。")
                            const response = await model.invoke([system_message, ...state.messages], modifiedConfig);


                            if (response.tool_calls?.length) {
                                return {
                                    messages: response;
                                    observed_steps: response.tool_calls[0].args.steps,
                                }

                            return { messages: response };
                        }
                        ```

        ### 观察预测
        这些预测将在 Agent 运行时发送，允许您在最终状态确定之前跟踪其进度。

        ```tsx title="ui/app/page.tsx"
        import { useAgent } from '@copilotkit/react-core/v2'; // [!code highlight]

        const YourMainContent = () => {
            // [!code highlight:3]
            const { agent } = useAgent({
                agentId: "sample_agent",
            });

            const observedSteps = (agent.state.observed_steps as string[]) ?? [];

            return (
                <div>
                    <h1>Agent 进度</h1>
                    {observedSteps.length > 0 && (
                        <div>
                            <h3>步骤：</h3>
                            <ul>
                                {observedSteps.map((step, i) => (
                                    <li key={i}>{step}</li>
                                ))}
                            </ul>
                        </div>
                    )}
                </div>
            )
        }
        ```
