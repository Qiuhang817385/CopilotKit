## 前提条件

在开始之前，您需要以下内容：

- OpenAI API 密钥
- Node.js 20+
- 您喜欢的包管理器
- LangSmith API 密钥 - 仅在部署到 LangSmith 平台时需要

## 入门
<Steps>
    <Step>
        ### 初始化您的 Agent 项目

        如果您还没有设置 Python 项目，请使用 `uv` 创建一个：

        ```bash
        uv init my-agent
        cd my-agent
        ```
    </Step>
    <Step>
        ### 添加必要的依赖

        对于这个 Agent，我们只需要 `deepagents`、`langchain-openai` 和 `copilotkit` 包：

        ```bash
        uv add deepagents copilotkit langchain-openai
        ```
    </Step>
    <Step>
        如果您已经编写了一个 LangGraph Agent，只需参考以下代码。在此步骤中
        我们创建一个简单的 LangGraph Agent 用于演示。

        <Tabs groupId="deployment_method" items={['LangSmith', 'FastAPI']}>
            <Tab value="LangSmith">
                首先，我们将创建一个简单的 LangGraph Agent：

                ```python title="main.py"
                from deepagents import create_deep_agent
                from copilotkit import CopilotKitMiddleware
                from langgraph.checkpoint.memory import MemorySaver

                def get_weather(location: str):
                    """获取位置的天气"""
                    return f"{location} 的天气晴朗。"

                agent = create_deep_agent(
                    model="openai:gpt-5.2",
                    tools=[get_weather],
                    middleware=[CopilotKitMiddleware()], # 用于前端工具和上下文
                    system_prompt="您是一个有用的研究助手。",
                    checkpointer=MemorySaver()
                )
                ```

                然后要使用 LangSmith 进行测试和部署，我们还需要一个 `langgraph.json`

                ```sh
                touch langgraph.json
                ```

                ```json title="langgraph.json"
                {
                    "python_version": "3.12",
                    "dockerfile_lines": [],
                    "dependencies": ["."],
                    "package_manager": "uv",
                    "graphs": {
                        "sample_agent": "./main.py:agent"
                    },
                    "env": ".env"
                }
                ```
            </Tab>
            <Tab value="FastAPI">
                首先，将 `ag-ui-langgraph`、`fastapi` 和 `uvicorn` 包添加到您的项目：

                ```bash
                uv add ag-ui-langgraph fastapi uvicorn
                ```

                然后创建一个简单的 LangGraph Agent，添加一个 FastAPI 应用，并将我们的 Agent 作为 AG-UI 端点附加。

                ```python title="main.py"
                import os

                # [!code highlight:2]
                from ag_ui_langgraph import add_langgraph_fastapi_endpoint
                from copilotkit import CopilotKitMiddleware, CopilotKitState, LangGraphAGUIAgent
                from deepagents import create_deep_agent
                from langgraph.checkpoint.memory import MemorySaver

                def get_weather(location: str):
                    """获取位置的天气"""
                    return f"{location} 的天气晴朗。"

                agent = create_deep_agent(
                    model="openai:gpt-5.2",
                    tools=[get_weather],
                    middleware=[CopilotKitMiddleware()], # 用于前端工具和上下文
                    system_prompt="您是一个有用的研究助手。",
                    checkpointer=MemorySaver()
                )

                # [!code highlight:9]
                add_langgraph_fastapi_endpoint(
                    app=app,
                    agent=LangGraphAGUIAgent(
                        name="sample_agent",
                        description="用作您自己 Agent 起点的示例 Agent。",
                        graph=agent,
                    ),
                    path="/",
                )

                def main():
                    """运行 uvicorn 服务器。"""
                    uvicorn.run(
                        "main:app",
                        host="0.0.0.0",
                        port="8123",
                        reload=True,
                    )

                if __name__ == "__main__":
                    main()
                ```
            </Tab>
        </Tabs>

        <Callout type="info" title="什么是 AG-UI？">
            AG-UI 是一个用于前端-Agent 通信的开放协议。
        </Callout>
    </Step>
    <Step>
        ### 配置您的环境

        在您的 Agent 目录中创建一个 `.env` 文件并添加您的 OpenAI API 密钥：

        ```plaintext title=".env"
        OPENAI_API_KEY=your_openai_api_key
        ```

        <Callout type="info" title="其他模型呢？">
        入门模板默认配置为使用 OpenAI 的 GPT-4o，但您可以修改它以使用 LangGraph 支持的任何语言模型。
        </Callout>
    </Step>
    <Step>
        ### 创建您的前端

        CopilotKit 可与任何基于 React 的前端配合使用。我们将在此示例中使用 Next.js。

        ```bash
        npx create-next-app@latest frontend
        cd frontend
        ```
    </Step>
    <Step>
        ### 安装 CopilotKit 包

        ```npm
        npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime
        ```
    </Step>
    <Step>
        ### 设置 Copilot Runtime

        创建一个 API 路由以将 CopilotKit 连接到您的 LangGraph Agent：

        ```sh
        mkdir -p app/api/copilotkit && touch app/api/copilotkit/route.ts
        ```

        <Tabs groupId="deployment_method" items={['LangSmith', 'FastAPI']}>
            <Tab value="LangSmith">
                ```tsx title="app/api/copilotkit/route.ts"
                import {
                    CopilotRuntime,
                    ExperimentalEmptyAdapter,
                    copilotRuntimeNextJSAppRouterEndpoint,
                } from "@copilotkit/runtime";
                // [!code highlight]
                import { LangGraphAgent } from "@copilotkit/runtime/langgraph";
                import { NextRequest } from "next/server";

                const serviceAdapter = new ExperimentalEmptyAdapter();

                const runtime = new CopilotRuntime({
                    agents: {
                        // [!code highlight:5]
                        sample_agent: new LangGraphAgent({
                            deploymentUrl:  process.env.LANGGRAPH_DEPLOYMENT_URL || "http://localhost:8123",
                            graphId: "sample_agent",
                            langsmithApiKey: process.env.LANGSMITH_API_KEY || "",
                        }),
                    }
                });

                export const POST = async (req: NextRequest) => {
                    const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({
                        runtime,
                        serviceAdapter,
                        endpoint: "/api/copilotkit",
                    });

                    return handleRequest(req);
                };
                ```
            </Tab>
            <Tab value="FastAPI">
                ```tsx title="app/api/copilotkit/route.ts"
                import {
                    CopilotRuntime,
                    ExperimentalEmptyAdapter,
                    copilotRuntimeNextJSAppRouterEndpoint,
                } from "@copilotkit/runtime";
                // [!code highlight]
                import { LangGraphHttpAgent } from "@copilotkit/runtime/langgraph";
                import { NextRequest } from "next/server";

                const serviceAdapter = new ExperimentalEmptyAdapter();

                const runtime = new CopilotRuntime({
                    agents: {
                        // [!code highlight:3]
                        sample_agent: new LangGraphHttpAgent({
                            url:  process.env.LANGGRAPH_DEPLOYMENT_URL || "http://localhost:8123",
                        }),
                    }
                });

                export const POST = async (req: NextRequest) => {
                    const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({
                        runtime,
                        serviceAdapter,
                        endpoint: "/api/copilotkit",
                    });

                    return handleRequest(req);
                };
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### 配置 CopilotKit Provider

        用 CopilotKit Provider 包装您的应用程序：

        ```tsx title="app/layout.tsx"
        // [!code highlight:2]
        import { CopilotKit } from "@copilotkit/react-core";
        import "@copilotkit/react-ui/v2/styles.css";

        // ...

        export default function RootLayout({ children }: {children: React.ReactNode}) {
            return (
                <html lang="en">
                    <body>
                        {/* [!code highlight:3] */}
                        <CopilotKit runtimeUrl="/api/copilotkit" agent="sample_agent">
                            {children}
                        </CopilotKit>
                    </body>
                </html>
            );
        }
        ```
    </Step>
    <Step>
    ### 添加对话界面

    将 CopilotSidebar 组件添加到您的页面：

    ```tsx title="app/page.tsx"
    "use client";

    import { CopilotSidebar } from "@copilotkit/react-core/v2";
    import { useDefaultRenderTool } from "@copilotkit/react-core/v2";

    export default function Page() {
        useDefaultRenderTool({
        render: ({name, status, args, result}) => (
            <details>
                <summary>
                    {status === "complete"? `已调用 ${name}` : `正在调用 ${name}`}
                </summary>

                <p>状态: {status}</p>
                <p>参数: {JSON.stringify(args)}</p>
                <p>结果: {JSON.stringify(result)}</p>
            </details>
        )})

        return (
            <main>
                <h1>您的应用</h1>
                <CopilotSidebar />
            </main>
        );
    }
    ```
    </Step>
    <Step>
        ### 启动您的 Agent
        从您的 Agent 目录，启动 Agent 服务器：

        <Tabs groupId="deployment_method" items={['LangSmith', 'FastAPI']}>
        <Tab value="LangSmith">
            ```bash
            cd ..
            npx @langchain/langgraph-cli dev --port 8123 --no-browser
            ```
        </Tab>
        <Tab value="FastAPI">
            ```bash
            cd ..
            uv run main.py
            ```
        </Tab>
        </Tabs>

        您的 Agent 将在 `http://localhost:8123` 可用。
    </Step>
    <Step>
        ### 启动您的 UI

        在单独的终端中，导航到您的前端目录并启动开发服务器：

            </Tab>
        </Tabs>
    </Step>
