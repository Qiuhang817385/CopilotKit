AG-UI 是 CopilotKit 中使用的新 Agent-to-UI 协议。
它已与 LangGraph Agent 集成。

本指南展示如何进行过渡。

    <TailoredContentOption
        id="lgp"
        title="LangGraph Platform"
        description="我正在使用 LangGraph 的 Platform 来服务我的 Agent（云或自托管）。"
    >
        ### 将您当前的 `CopilotRuntime` 实例化从
        ```typescript
        import { langGraphPlatformEndpoint, CopilotRuntime } from "@copilotkit/runtime";

        let runtime = new CopilotRuntime({
            remoteEndpoints: [
                langGraphPlatformEndpoint({
                    deploymentUrl: "https://your-deployment-url",
                    langsmithApiKey: '<langsmith API key>', // 可选
                    agents: [], // 您之前的 Agent 定义
                })
            ],
        })
        ```
        改为
        ```typescript
        import { LangGraphAgent, CopilotRuntime } from "@copilotkit/runtime";

        let runtime = new CopilotRuntime({
            agents: {
                'sample_agent': new LangGraphAgent({
                    deploymentUrl: "https://your-deployment-url",
                    langsmithApiKey: '<langsmith API key>', // 可选
                    graphId: 'sample_agent', // 与 `langgraph.json` graphs 配置中定义的相同。
                }),
            }
        })
        ```
        就是这样！您已完成设置！
    </TailoredContentOption>
    <TailoredContentOption
        id="fastapi"
        title="自托管 (FastAPI)"
        description="我正在自托管我的 Agent，并通过 FastAPI 提供服务。"
    >

假设您的 Python Agent 设置如下：
```python
from fastapi import FastAPI
from copilotkit.integrations.fastapi import add_fastapi_endpoint
from copilotkit import CopilotKitRemoteEndpoint, LangGraphAgent
from .agent import graph

app = FastAPI()
sdk = CopilotKitRemoteEndpoint(
    agents=[
        LangGraphAgent(
            name="sample_agent",
            description="my agent",
            graph=graph,
        ),
    ],
)

add_fastapi_endpoint(app, sdk, "/copilotkit")
```

要迁移，请导入并使用新的端点初始化器和 Agent 类。
其他所有内容（主要是您的图）保持不变。

<Steps>
    <Step>
        ### 首先，将您的 FastAPI 端点迁移为使用新的 Agent 类
        ```python
        from fastapi import FastAPI
        from copilotkit import LangGraphAGUIAgent
        from ag_ui_langgraph import add_langgraph_fastapi_endpoint
        from .agent import graph

        app = FastAPI()
        add_langgraph_fastapi_endpoint(
            app=app,
            agent=LangGraphAGUIAgent(
                name="sample_agent",
                description="my agent",
                graph=graph,
            ),
            path="/agent/sample_agent" # Agent 将在此路径上提供服务。使用 "/" 挂载到根目录。
        )
        ```
    </Step>
    <Step>
        ### 然后，在您的 `CopilotRuntime` 实例化中，使用新的 `LangGraphHttpAgent`
        ```typescript
        let runtime = new CopilotRuntime({
            agents: {
                'sample_agent': new LangGraphHttpAgent({
                    url: "http://localhost:8000/agent/sample_agent",
                }),
            }
        })
        ```
    </Step>
</Steps>

                通过 `useCoAgent` Hook 或在 Agent 类上使用新的 `config` 参数来配置 Agent。
            </Accordion>
