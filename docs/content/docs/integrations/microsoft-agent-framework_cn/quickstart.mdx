## 先决条件

在开始之前，您需要以下内容：

- GitHub 个人访问令牌（用于 GitHub Models API - 免费 AI 访问）
- .NET 9.0 SDK 或更高版本
- Node.js 20+
- 您喜欢的包管理器（npm、pnpm、yarn 或 bun）

                ### 启动您的 Microsoft Agent Framework 智能体

                确保您的智能体正在运行并暴露 AG-UI 端点。以下是一个最小示例：

                <Tabs groupId="language_microsoft-agent-framework_agent" items={['.NET', 'Python']} persist>
                    <Tab value=".NET">
                        首先，设置一个新的 .NET 项目：
                        ```bash
                        dotnet new web -n AGUIServer
                        cd AGUIServer
                        dotnet add package Microsoft.Agents.AI.Hosting.AGUI.AspNetCore --version 1.0.0-preview.251110.1
                        dotnet add package Microsoft.Extensions.AI.OpenAI --version 9.10.2-preview.1.25552.1
                        dotnet add package OpenAI --version 2.6.0
                        dotnet user-secrets init
                        ```

                        构建一个最小智能体并通过 AG-UI 提供服务：

                        ```csharp title="Program.cs"
                        using Microsoft.Agents.AI;
                        # [!code highlight:1]
                        using Microsoft.Agents.AI.Hosting.AGUI.AspNetCore;
                        using Microsoft.Extensions.AI;
                        using OpenAI;

                        var builder = WebApplication.CreateBuilder(args);
                        # [!code highlight:1]
                        builder.Services.AddAGUI();
                        var app = builder.Build();

                        // 获取您的 GitHub 令牌以使用 GitHub Models（免费）
                        var githubToken = builder.Configuration["GitHubToken"]!;
                        var openAI = new OpenAIClient(
                            new System.ClientModel.ApiKeyCredential(githubToken),
                            new OpenAIClientOptions {
                                Endpoint = new Uri("https://models.inference.ai.azure.com")
                            });

                        var chatClient = openAI.GetChatClient("gpt-5.2-mini").AsIChatClient();
                        var agent = new ChatClientAgent(
                            chatClient,
                            name: "MyAgent",
                            description: "你是一个有用的助手。");

                        # [!code highlight:1]
                        app.MapAGUI("/", agent);
                        app.Run("http://localhost:8000");
                        ```

                        然后只需设置环境并运行您的智能体：

                        ```bash
                        # 设置您的 GitHub 令牌并运行
                        dotnet user-secrets set GitHubToken "$(gh auth token)"
                        dotnet run
                        ```
                    </Tab>
                    <Tab value="Python">
                        创建一个最小 FastAPI 服务器，通过 AG-UI 暴露 Microsoft Agent Framework 智能体：

                        ```python title="agent/src/byo_agent.py"
                        from __future__ import annotations

                        import os

                        import uvicorn
                        from agent_framework import ChatClientProtocol
                        from azure.identity import DefaultAzureCredential
                        from agent_framework.azure import AzureOpenAIChatClient
                        from agent_framework.openai import OpenAIChatClient
                        from agent_framework import ChatAgent
                        from agent_framework.ag_ui import add_agent_framework_fastapi_endpoint
                        from dotenv import load_dotenv
                        from fastapi import FastAPI


                        load_dotenv()


                        def _build_chat_client() -> ChatClientProtocol:
                            if bool(os.getenv("AZURE_OPENAI_ENDPOINT")):
                                deployment_name = os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT_NAME", "gpt-5.2-mini")
                                return AzureOpenAIChatClient(
                                    credential=DefaultAzureCredential(),
                                    deployment_name=deployment_name,
                                    endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
                                )

                            if bool(os.getenv("OPENAI_API_KEY")):
                                return OpenAIChatClient(
                                    model_id=os.getenv("OPENAI_CHAT_MODEL_ID", "gpt-5.2-mini"),
                                    api_key=os.getenv("OPENAI_API_KEY"),
                                )

                            raise RuntimeError(
                                "缺少凭据。设置 AZURE_OPENAI_ENDPOINT (+ AZURE_OPENAI_CHAT_DEPLOYMENT_NAME) "
                                "或 OPENAI_API_KEY 作为环境变量。"
                            )


                        chat_client = _build_chat_client()

                        agent = ChatAgent(
                            name="MyAgent",
                            instructions="你是一个有用的助手。",
                            chat_client=chat_client,
                        )

                        app = FastAPI(title="Microsoft Agent Framework (Python) - 快速入门")
                        add_agent_framework_fastapi_endpoint(app=app, agent=agent, path="/")


                        if __name__ == "__main__":
                            uvicorn.run("byo_agent:app", host="0.0.0.0", port=8000, reload=True)
                        ```

                        然后设置您的环境并运行：

                        ```bash
                        # OpenAI (agent/.env)
                        OPENAI_API_KEY=sk-...your-openai-key-here...
                        OPENAI_CHAT_MODEL_ID=gpt-5.2-mini
                        # 或 Azure OpenAI (agent/.env)
                        AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
                        AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=gpt-5.2-mini
                        # (可选) AZURE_OPENAI_API_KEY=...

                        # 运行智能体
                        cd agent
                        uv run src/byo_agent.py
                        ```

                ### 设置 Copilot 运行时

                CopilotKit 需要一个 Copilot 运行时端点来安全地与您的智能体通信。这可以在任何 Node.js 可以运行的地方提供服务，但在此示例中我们将使用 Next.js。

                在 `app/api/copilotkit/route.ts` 创建一个新的 API 路由：

                ```tsx title="app/api/copilotkit/route.ts"
                import {
                  CopilotRuntime,
                  ExperimentalEmptyAdapter,
                  copilotRuntimeNextJSAppRouterEndpoint,
                } from "@copilotkit/runtime";
                import { HttpAgent } from "@ag-ui/client";
                import { NextRequest } from "next/server";

                // 1. 您可以在此处使用任何服务适配器以实现多智能体支持。我们使用
                //    空适配器，因为我们只使用一个智能体。
                const serviceAdapter = new ExperimentalEmptyAdapter();

                // 2. 创建 CopilotRuntime 实例并利用 Microsoft Agent Framework
                //    AG-UI 集成来设置连接。
                // [!code highlight:5]
                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
                  },
                });

                // 3. 构建处理 CopilotKit 运行时请求的 Next.js API 路由。
                export const POST = async (req: NextRequest) => {
                  const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({
                    runtime,
                    serviceAdapter,
                    endpoint: "/api/copilotkit",
                  });

                  return handleRequest(req);
                };
                ```

                ### 配置 CopilotKit 提供程序

                接下来，用 CopilotKit 提供程序包装您的应用程序，以便 CopilotKit 可以通过 Microsoft Agent Framework 智能体在您的应用程序中实现控制。

                ```tsx title="app/layout.tsx"
                import { CopilotKit } from "@copilotkit/react-core"; // [!code highlight]
                import "@copilotkit/react-ui/v2/styles.css";

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent">
                          {children}
                        </CopilotKit>
                      </body>
                    </html>
                  );
                }
                ```

                **智能体连接问题**
                - 如果您看到"我连接到我的工具时遇到问题"，请确保：
                  - C# 智能体在端口 8000 上运行

                - 验证 .NET SDK 是否已安装：

                  ```bash
                  dotnet --version  # 应为 9.0.x 或更高版本
                  ```
