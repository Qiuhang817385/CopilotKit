## 这是什么？

您可以轻松地在聊天 UI 中使用实时智能体状态，也可以在原生应用程序 UX 中使用。

## 何时使用？

当您想向用户提供有关智能体状态的反馈时使用此功能。随着智能体状态的更新，您可以在应用程序中实时反映这些更新。

      language: "english" | "spanish";

  <Step>
    ### 使用 `useAgent` 钩子
    连接并运行智能体后，剩下要做的就是调用 `useAgent` 钩子，传递智能体的名称，并可选地提供初始状态。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    // 定义智能体状态类型，应与智能体的实际状态匹配
    type AgentState = {
      language: "english" | "spanish";
    }

    function YourMainContent() {
      // [!code highlight:4]
      const { agent } = useAgent({
        agentId: "sample_agent",
        initialState: { language: "english" }  // 可选地提供初始状态
      });

      // ...

      return (
        // 为简洁起见，省略样式
        <div>
          <h1>您的主要内容</h1>
          {/* [!code highlight:1] */}
          <p>语言：{agent.state?.language}</p>
        </div>
      );
    }
    ```
    <Callout type="info">
      `useAgent` 中的 `agent.state` 是响应式的，当智能体状态更改时会自动更新。
    </Callout>
  </Step>

## 在聊天中渲染智能体状态

您还可以在聊天 UI 中渲染智能体的状态。这对于以更情境化的方式向用户通知智能体的状态非常有用。为此，您可以使用带有 `render` 函数的 `useAgent` 钩子。

```tsx title="ui/app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

// 定义智能体状态类型，应与智能体的实际状态匹配
type AgentState = {
  language: "english" | "spanish";
}

function YourMainContent() {
  // ...
  // [!code highlight:7]
  useAgent({
    agentId: "sample_agent",
    render: ({ state }) => {
      if (!state.language) return null;
      return <div>语言：{state.language}</div>;
    },
  });
  // ...
}
```

<Callout type="info">
  `useAgent` 中的 `agent.state` 是响应式的，当智能体状态更改时会自动更新。
</Callout>

## 高级：发出中间状态

默认情况下，智能体状态更新会在智能体执行期间的自然检查点到达。对于在长时间运行操作期间更细粒度的实时更新，您可以从智能体逻辑中发出状态快照。有关在执行期间流式传输自定义状态事件的模式，请参阅 [Microsoft Agent Framework 文档](https://learn.microsoft.com/en-us/agent-framework/user-guide/overview)。
