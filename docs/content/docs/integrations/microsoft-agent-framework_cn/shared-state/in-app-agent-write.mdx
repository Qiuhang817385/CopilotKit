## 这是什么？

本指南向您展示如何从应用程序写入智能体的状态。

## 何时使用？

当您需要从应用程序更新智能体状态时使用此功能——例如，更改用户偏好、切换设置或提供影响智能体行为的用户输入。

        ```python title="agent/src/agent.py (节选)"
        from typing import Annotated
        from agent_framework import ChatAgent, ChatClientProtocol, ai_function
        from agent_framework.ag_ui import AgentFrameworkAgent
        from pydantic import Field

        STATE_SCHEMA: dict[str, object] = {
            "language": {
                "type": "string",
                "enum": ["english", "spanish"],
                "description": "首选语言。",
            }
        }

        PREDICT_STATE_CONFIG: Dict[str, Dict[str, str]] = {
            "language": {"tool": "update_language", "tool_argument": "language"}
        }

        @ai_function(
            name="update_language",
            description="更新首选语言（english 或 spanish）。",
        )
        def update_language(
            language: Annotated[str, Field(description="首选语言：'english' 或 'spanish'")],
        ) -> str:
            normalized = (language or "").strip().lower()
            if normalized not in ("english", "spanish"):
                return "语言未更改。请使用 'english' 或 'spanish'。"
            return f"语言已更新为 {normalized}。"

        def create_agent(chat_client: ChatClientProtocol) -> AgentFrameworkAgent:
            base_agent = ChatAgent(
                name="sample_agent",
                instructions="你是一个有用的助手。",
                chat_client=chat_client,
                tools=[update_language],   # [!code highlight:1]
            )

            return AgentFrameworkAgent(
                agent=base_agent,
                name="CopilotKitMicrosoftAgentFrameworkAgent",
                description="跟踪简单语言状态的助手。",
                state_schema=STATE_SCHEMA,               # [!code highlight:2]
                predict_state_config=PREDICT_STATE_CONFIG, # [!code highlight:2]
                require_confirmation=False,
            )
        ```
      </Tab>

  <Step>
    ### 从 `useAgent` 钩子调用 `agent.setState`
    `useAgent` 返回一个带有 `setState` 方法的 `agent` 对象，您可以使用该方法来更新智能体状态。调用此方法将更新智能体状态并触发任何依赖于智能体状态的内容重新渲染。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    // 定义智能体状态类型，应与智能体的实际状态匹配
    type AgentState = {
      language: "english" | "spanish";
    }

    // 在伪 React 组件中的示例用法
    function YourMainContent() {
      const { agent } = useAgent({ // [!code highlight]
        agentId: "sample_agent",
        initialState: { language: "english" }  // 可选地提供初始状态
      });

      // ...

      const toggleLanguage = () => {
        agent.setState({ language: agent.state?.language === "english" ? "spanish" : "english" }); // [!code highlight]
      };

      // ...

      return (
        // 为简洁起见，省略样式
        <div>
          <h1>您的主要内容</h1>
          {/* [!code highlight:1] */}
          <p>语言：{agent.state?.language}</p>
          <button onClick={toggleLanguage}>切换语言</button>
        </div>
      );
    }
    ```
  </Step>

## 高级用法

### 重新运行智能体并提示更改内容

新的智能体状态将在下次智能体运行时使用。
如果您想手动重新运行它，请使用 `copilotkit.runAgent()`。

智能体将使用最新更新的状态重新运行。您还可以在重新运行之前添加提示消息。

```tsx title="ui/app/page.tsx"
import { useAgent, useCopilotKit } from "@copilotkit/react-core/v2";

// ...

function YourMainContent() {
  const { agent } = useAgent({
    agentId: "sample_agent",
  });
  const { copilotkit } = useCopilotKit(); // [!code highlight]

  // 设置在某些应用程序事件发生时调用
  const toggleLanguage = async () => {
    const newLanguage = agent.state?.language === "english" ? "spanish" : "english";
    agent.setState({ language: newLanguage });

    // 添加提示消息并重新运行智能体
    // [!code highlight:7]
    agent.addMessage({
      id: crypto.randomUUID(),
      role: "user",
      content: `语言已更新为 ${newLanguage}`,
    });
    await copilotkit.runAgent({ agent });
  };

  return (
    // ...
  );
}
```

### 关于状态更新的说明
根据您的智能体实现，您可以选择通过工具响应或消息而不是频繁的状态快照来展示进度。有关推荐的模式，请参阅[生成式 UI](/microsoft-agent-framework/generative-ui/tool-rendering)。
