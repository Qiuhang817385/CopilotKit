## 前提条件

在开始之前，您需要准备以下内容：

- OpenAI API 密钥
- Node.js 20+
- Python 3.9+
- 您喜欢的包管理器

                ```plaintext title="agent/.env"
                OPENAI_API_KEY=your_openai_api_key
                ```

                </Tabs>

                这将同时启动 UI 和智能体服务器。
            </Step>
        </TailoredContentOption>
        <TailoredContentOption
            id="bring-your-own"
            title="使用现有智能体"
            description="我已经有一个 Pydantic AI 智能体，想添加 CopilotKit。"
        >
            <Step>
                ### 初始化您的智能体项目

                如果您还没有设置 Python 项目，请使用 `uv` 创建一个：

                ```bash
                uv init my-agent
                cd my-agent
                ```
            </Step>
            <Step>
                ### 安装带 AG-UI 的 Pydantic AI

                将带 AG-UI 支持的 Pydantic AI 和 uvicorn 添加到您的项目：

                ```bash
                uv add 'pydantic-ai-slim[ag-ui]' 'pydantic-ai-slim[openai]' uvicorn
                ```
            </Step>
            <Step>
                ### 配置环境

                将您的 OpenAI API 密钥设置为环境变量：

                ```bash
                export OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="其他模型呢？">
                  本示例使用 OpenAI 的 GPT-4.1-mini，但您可以修改它以使用 Pydantic AI 支持的任何语言模型。
                </Callout>
            </Step>
            <Step>
                ### 通过 AG-UI 暴露您的智能体

                更新您的智能体文件以将其暴露为 AG-UI ASGI 应用程序：

                ```python title="main.py"
                from pydantic_ai import Agent

                agent = Agent('openai:gpt-4.1-mini', instructions='Be fun!')
                app = agent.to_ag_ui()

                if __name__ == "__main__":
                    import uvicorn
                    uvicorn.run(app, host="localhost", port=8000)
                ```

                <Callout type="info" title="什么是 AG-UI？">
                  AG-UI 是一个用于前端-智能体通信的开放协议。Pydantic AI 的 `.to_ag_ui()` 方法创建一个 CopilotKit 可以连接的 ASGI 应用。
                </Callout>
            </Step>
            <Step>
                ### 创建您的前端

                CopilotKit 可与任何基于 React 的前端一起使用。在本示例中，我们将使用 Next.js。

                ```bash
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit 包

                ```npm
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime @ag-ui/client
                ```
            </Step>
            <Step>
                ### 设置 Copilot Runtime

                创建一个 API 路由以将 CopilotKit 连接到您的 Pydantic AI 智能体：

                ```tsx title="app/api/copilotkit/route.ts"
                import {
                  CopilotRuntime,
                  ExperimentalEmptyAdapter,
                  copilotRuntimeNextJSAppRouterEndpoint,
                } from "@copilotkit/runtime";
                import { HttpAgent } from "@ag-ui/client";
                import { NextRequest } from "next/server";

                const serviceAdapter = new ExperimentalEmptyAdapter();

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
                  }
                });

                export const POST = async (req: NextRequest) => {
                  const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({
                    runtime,
                    serviceAdapter,
                    endpoint: "/api/copilotkit",
                  });

                  return handleRequest(req);
                };
               ```
            </Step>
            <Step>
                ### 配置 CopilotKit 提供程序

                用 CopilotKit 提供程序包裹您的应用程序：

                ```tsx title="app/layout.tsx"
                import { CopilotKit } from "@copilotkit/react-core"; // [!code highlight]
                import "@copilotkit/react-ui/v2/styles.css";

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent">
                          {children}
                        </CopilotKit>
                      </body>
                    </html>
                  );
                }
                ```
            </Step>
            <Step>
              ### 添加聊天界面

              将 CopilotSidebar 组件添加到您的页面：

              ```tsx title="app/page.tsx"
              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>您的应用</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
            <Step>
                ### 启动您的智能体

                从您的智能体目录，启动智能体服务器：

                ```bash
                cd ..
                uv run main.py
                ```

                您的智能体将在 `http://localhost:8000` 可用。
            </Step>
            <Step>
                ### 启动您的 UI

                在单独的终端中，导航到您的前端目录并启动开发服务器：

                <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn', 'bun']}>
                    <Tab value="npm">
                        ```bash
                        cd my-copilot-app
                        npm run dev
                        ```
                    </Tab>
                    <Tab value="pnpm">
                        ```bash
                        cd my-copilot-app
                        pnpm dev
                        ```
                    </Tab>
                    <Tab value="yarn">
                        ```bash
                        cd my-copilot-app
                        yarn dev
                        ```
                    </Tab>
                    <Tab value="bun">
                        ```bash
                        cd my-copilot-app
                        bun dev
                        ```
                    </Tab>
                </Tabs>
            </Step>
        </TailoredContentOption>
    </TailoredContent>

        ### 🎉 开始聊天！

        您的 AI 智能体现在可以使用了！导航到 `localhost:3000` 并尝试问它一些问题：

                - 如果遇到连接问题，请尝试使用 `0.0.0.0` 或 `127.0.0.1` 代替 `localhost`
                - 确保您的智能体在 8000 端口运行
                - 检查您的 OpenAI API 密钥是否正确设置
                - 验证 `@ag-ui/client` 包是否已安装在前端
            </Accordion>
