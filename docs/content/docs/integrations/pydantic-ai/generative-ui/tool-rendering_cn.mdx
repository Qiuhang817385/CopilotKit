## 这是什么？

工具是 LLM 调用预定义函数（通常是确定性的）的一种方式。CopilotKit 允许您在 UI 中
将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 什么时候应该使用它？

在 UI 中渲染工具在以下情况下非常有用：当您想向用户提供有关智能体正在执行的操作的反馈，特别是
当您的智能体正在调用工具时。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

<Step>
### 给您的智能体一个可调用的工具

<Tabs groupId="language_pydantic-ai_agent" items={['Python']} default="Python" persist>
    <Tab value="Python">
        ```python title="agent.py"
        from pydantic_ai import Agent

        agent = Agent("openai:gpt-5.2-mini")


        @agent.tool_plain
        async def get_weather(location: str = "Everywhere ever") -> str:
            """Get the weather for a given location. Ensure location is fully spelled out."""
            return f"The weather in {location} is sunny."


        app = agent.to_ag_ui()

        if __name__ == "__main__":
            import uvicorn

            uvicorn.run(app, host="0.0.0.0", port=8000)
        ```
    </Tab>

</Tabs>
</Step>
<Step>
### 在前端渲染工具调用
此时，您的智能体将能够调用 `get_weather` 工具。现在
我们只需要添加一个 `useRenderTool` 钩子来在
UI 中渲染工具调用。

<Callout type="info" title="重要">
  要在 UI 中渲染工具调用，操作的名称必须与工具的名称匹配。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:12]
  useRenderTool({
    name: "get_weather",
    render: ({status, args}) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "正在调用天气 API..."}
          {status === "complete" && `已为 ${args.location} 调用天气 API。`}
        </p>
      );
    },
  });
  // ...
}
```

</Step>
