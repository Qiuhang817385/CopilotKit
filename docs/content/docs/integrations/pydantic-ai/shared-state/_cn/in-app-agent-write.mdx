## 这是什么？

本指南向您展示如何从您的应用程序写入代理的状态。

## 什么时候应该使用这个？

您可以在想要向用户提供有关代理正在做什么的反馈时使用此功能，特别是
当您的代理正在调用工具时。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

  <Step>
    ### 定义代理状态

    使用有状态结构创建您的 Pydantic AI 代理。下面是一个跟踪语言的完整示例：

    ```python title="agent.py"
    from textwrap import dedent

    from pydantic import BaseModel
    from pydantic_ai import Agent, RunContext
    from pydantic_ai.ag_ui import StateDeps


    class AgentState(BaseModel):
        """代理的状态。"""
        language: str = "english"


    agent = Agent("openai:gpt-5.2-mini", deps_type=StateDeps[AgentState])


    @agent.instructions()
    async def language_instructions(ctx: RunContext[StateDeps[AgentState]]) -> str:
        """语言跟踪代理的指令。

        参数：
            ctx: 包含语言状态信息的运行上下文。

        返回：
            语言跟踪代理的指令字符串。
        """
        return dedent(
            f"""
            您是跟踪语言的有用助手。

            重要：
            - 始终使用小写表示语言
            - 始终使用当前语言响应：{ctx.deps.state.language}
            """
        )


    app = agent.to_ag_ui(deps=StateDeps(AgentState()))

    if __name__ == "__main__":
        import uvicorn
        uvicorn.run(app, host="0.0.0.0", port=8000)
    ```

  </Step>
  <Step>
    ### 从 `useAgent` 钩子调用 `agent.setState`
    `useAgent` 返回一个带有 `setState` 方法的 `agent` 对象，您可以使用该方法来更新代理状态。调用此方法
    将更新代理状态并触发依赖于代理状态的任何内容的重新渲染。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    // 定义代理状态类型，应与代理的实际状态匹配
    type AgentState = {
      language: "english" | "spanish";
    }

    // 伪 React 组件中的示例用法
    function YourMainContent() {
      const { agent } = useAgent({ // [!code highlight]
        agentId: "my_agent",
        initialState: { language: "english" }  // 可选地提供初始状态
      });

      // ...

      const toggleLanguage = () => {
        agent.setState({ language: agent.state?.language === "english" ? "spanish" : "english" }); // [!code highlight]
      };

      // ...

      return (
        // 为简洁起见省略样式
        <div>
          <h1>您的主要内容</h1>
          {/* [!code highlight:2] */}
          <p>语言：{agent.state?.language}</p>
          <button onClick={toggleLanguage}>切换语言</button>
        </div>
      );
    }
    ```

    <Callout type="warn" title="重要">
      `name` 参数必须与您在 CopilotRuntime 配置中定义的代理名称完全匹配（例如，快速入门中的 `my_agent`）。
    </Callout>

  </Step>
  <Step>
    ### 试一试！
    现在您可以使用 `agent.setState` 更新代理状态，并使用 `agent.state` 读取它。尝试切换语言按钮
    并与您的代理交谈。您会看到语言更改为与代理的状态匹配。

## 高级用法

### 使用有关已更改内容的提示重新运行代理

新的代理状态将在下次代理运行时使用。
如果您想手动重新运行它，请使用 `copilotkit.runAgent()`。

代理将使用最新更新的状态重新运行。您还可以在重新运行之前添加提示消息。

```tsx title="ui/app/page.tsx"
import { useAgent, useCopilotKit } from "@copilotkit/react-core/v2";

// ...

function YourMainContent() {
  const { agent } = useAgent({
    agentId: "my_agent",
  });
  const { copilotkit } = useCopilotKit(); // [!code highlight]

  // 设置为在应用中发生某些事件时调用
  const toggleLanguage = async () => {
    const newLanguage = agent.state?.language === "english" ? "spanish" : "english";
    agent.setState({ language: newLanguage });

    // 添加提示消息并重新运行代理
    // [!code highlight:7]
    agent.addMessage({
      id: crypto.randomUUID(),
      role: "user",
      content: `语言已更新为 ${newLanguage}`,
    });
    await copilotkit.runAgent({ agent });
  };

  return (
    // ...
  );
}
```

### 中间流式传输和渲染代理状态

默认情况下，Pydantic AI 代理状态只会在 Pydantic AI 代理节点转换之间更新 ——
这意味着状态更新将是不连续和延迟的。
