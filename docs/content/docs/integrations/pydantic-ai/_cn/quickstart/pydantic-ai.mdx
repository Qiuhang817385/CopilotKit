                ```bash
                export OPENAI_API_KEY=your_openai_api_key
                ```

                或在 Agent 的 `.env` 文件中设置。

                ```plaintext title="agent/.env"

                ```
            </Step>
            <Step>

                现在您可以在同一个终端中一起运行您的 Agent 和 UI！

        <TailoredContentOption
            id="exiting-agent"
            title="使用现有 Agent"
            description="我已经有一个 Pydantic AI Agent，想将其与 CopilotKit 一起使用。"
            icon={<PydanticAIIcon className="w-4 h-4 text-bold" />}
        >
            <Step>
                ### 添加必要的依赖
                Pydantic AI 的集成依赖于 [AG-UI](https://docs.ag-ui.com/)，因此
                您需要将其安装到您的项目中。

                我们的示例还将使用 uvicorn 来运行 Agent。

                ```sh
                pip install 'pydantic-ai-slim[ag-ui]' uvicorn
                ```
            </Step>
            <Step>
                ### 将您的 Agent 暴露为 AG-UI ASGI 应用程序

                ```python title="agent.py"
                from pydantic_ai import Agent

                agent = Agent('openai:gpt-4.1', instructions='Be fun!')
                app = agent.to_ag_ui()

                # 如果您希望服务器在调用时运行，可以执行以下操作：
                if __name__ == "__main__":
                    import uvicorn
                    uvicorn.run(app, host="localhost", port=8000)

                ```
            </Step>
            <Step>
                ### 创建您的前端
                CopilotKit 可以在任何运行 React 的地方运行。因此，您可以使用 Next.js、
                Vite 或任何其他 React 环境。

                对于此示例，我们将创建一个新的 Next.js 应用程序。

                ```bash
                npx create-next-app@latest
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit
                首先，将 CopilotKit 的最新包安装到您的前端。
                ```package-install
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime
                ```
            </Step>
            <Step>
                ### 设置 Copilot 运行时
                CopilotKit 的运行时负责 Agent 与前端之间的安全通信。随着您的应用程序的进展，
                这将是您设置线程或身份验证的地方。

                现在，让我们从一个最小设置开始。

                ```tsx title="app/api/copilotkit/route.ts"
                import {
                  CopilotRuntime,
                  ExperimentalEmptyAdapter,
                  copilotRuntimeNextJSAppRouterEndpoint,
                } from "@copilotkit/runtime";
                import { HttpAgent } from "@ag-ui/client";
                import { NextRequest } from "next/server";

                // 1. 您可以在此处使用任何服务适配器以实现多 Agent 支持。我们使用
                //    空适配器，因为我们只使用一个 Agent。
                const serviceAdapter = new ExperimentalEmptyAdapter();

                // 2. 创建 CopilotRuntime 实例并使用 PydanticAI AG-UI
                //    集成来设置连接。
                const runtime = new CopilotRuntime({
                  agents: {
                    // 我们的 AG-UI 端点 URL
                    "my_agent": new HttpAgent({ url: "http://localhost:8000/" }),
                  }
                });

                // 3. 构建一个处理 CopilotKit 运行时请求的 Next.js API 路由。
                export const POST = async (req: NextRequest) => {
                  const { handleRequest } = copilotRuntimeNextJSAppRouterEndpoint({
                    runtime,
                    serviceAdapter,
                    endpoint: "/api/copilotkit",
                  });

                  return handleRequest(req);
                };
               ```
            </Step>
            <Step>
                ### 设置 CopilotKit 提供商
                CopilotKit 提供商组件负责管理与当前 Agent 的会话。通常，
                用户会将整个应用程序包装在 CopilotKit 提供商中。

                ```tsx title="app/layout.tsx"
                import "./globals.css";
                import { ReactNode } from "react";
                import { CopilotKit } from "@copilotkit/react-core";

                export default function RootLayout({ children }: { children: ReactNode }) {
                  return (
                    <html lang="en">
                      <body>
                        {/* 这指向我们在上一步中设置的运行时 */}
                        {/* [!code highlight:3] */}
                        <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent">
                          {children}
                        </CopilotKit>
                      </body>
                    </html>
                  );
                }
                ```
            </Step>
            <Step>
                ### 设置 Copilot UI
                最后一步是使用 CopilotKit 的 UI 组件来渲染与您的 Agent 的聊天交互。在大多数情况下，
                这是与您的核心页面组件一起完成的，例如在您的 `page.tsx` 文件中。

                ```tsx title="page.tsx"
                // [!code highlight:2]
                import "@copilotkit/react-ui/v2/styles.css";
                import { CopilotSidebar } from "@copilotkit/react-core/v2";

                export function YourApp() {
                return (
                    <main>
                    <h1>您的主内容</h1>
                    {/* [!code highlight:6] */}
                    <CopilotSidebar
                        labels={{
                            modalHeaderTitle: "弹出助手",
                            welcomeMessageText: "嗨！我已连接到 Agent。我能帮您什么？",
                        }}
                    />
                    </main>
                );
                }
                ```

                <Callout type="info">
                    正在寻找其他聊天组件选项？查看我们的 [Agent 聊天 UI](/pydantic-ai/prebuilt-components) 指南。
                </Callout>
            </Step>
        </TailoredContentOption>
    </TailoredContent>
