## 这是什么？

工具是 LLM 调用预定义的、通常是确定性的函数的一种方式。CopilotKit 允许您在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 何时使用此功能？

当 Agent 调用工具时，如果您想向用户提供有关 Agent 正在做什么的反馈，在 UI 中渲染工具非常有用。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

<Step>
### 给您的 Agent 一个可调用的工具

<Tabs groupId="language_pydantic-ai_agent" items={['Python']} default="Python" persist>
    <Tab value="Python">
        ```python title="agent.py"
        from pydantic_ai import Agent

        agent = Agent("openai:gpt-5.2-mini")


        @agent.tool_plain
        async def get_weather(location: str = "Everywhere ever") -> str:
            """获取给定位置的天气。确保位置完全拼写出来。"""
            return f"{location} 的天气是晴朗的。"


        app = agent.to_ag_ui()

        if __name__ == "__main__":
            import uvicorn

            uvicorn.run(app, host="0.0.0.0", port=8000)
        ```
    </Tab>

</Tabs>
</Step>
<Step>
### 在您的前端中渲染工具调用
此时，您的 Agent 将能够调用 `get_weather` 工具。现在
我们只需要添加一个 `useRenderTool` Hook 来在 UI 中渲染工具调用。

<Callout type="info" title="重要">
  要在 UI 中渲染工具调用，操作的名称必须与工具的名称匹配。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:12]
  useRenderTool({
    name: "get_weather",
    render: ({status, args}) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "正在调用天气 API..."}
          {status === "complete" && `已为 ${args.location} 调用天气 API。`}
        </p>
      );
    },
  });
  // ...
}
```

</Step>
