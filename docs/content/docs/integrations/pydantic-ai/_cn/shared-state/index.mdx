## 什么是共享状态？

CoAgents 维护一个共享状态，无缝连接您的 UI 与 Agent 的执行。这个共享状态系统允许您：

- 显示 Agent 的当前进度和中间结果
- 通过 UI 交互更新 Agent 的状态
- 在整个应用程序中实时响应状态变化

该系统的基础建立在 Pydantic AI 通过 AG-UI 实现的有状态架构之上。

## 何时使用此功能？

当您希望促进 Agent 与用户之间的协作时，状态流是完美的选择。您的 Pydantic AI Agent 持久化的任何状态都将自动被 UI 共享。同样，用户在 UI 中更新的任何状态也将自动反映出来。

这提供了一致的体验，让 Agent 和用户保持同步。
