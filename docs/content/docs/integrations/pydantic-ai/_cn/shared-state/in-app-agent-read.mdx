## 这是什么？

您可以轻松地在原生应用程序 UX 中使用实时 Agent 状态，而不仅仅是在聊天 UI 中。

## 何时使用此功能？

当您想向用户提供有关 Agent 状态的反馈时，可以使用此功能。随着 Agent 状态的更新，您可以在应用程序中原生地反映这些更新。

## 实现

<Steps>
  <Step>
    ### 运行并连接您的 Agent
    <RunAndConnect components={props.components} />
  </Step>
  <Step>
    ### 定义 Agent 状态

    使用有状态结构创建您的 Pydantic AI Agent。以下是一个跟踪语言的完整示例：

    ```python title="agent.py"
    from textwrap import dedent

    from pydantic import BaseModel
    from pydantic_ai import Agent, RunContext
    from pydantic_ai.ag_ui import StateDeps


    class AgentState(BaseModel):
        """Agent 的状态。"""
        language: str = "english"


    agent = Agent("openai:gpt-5.2-mini", deps_type=StateDeps[AgentState])


    @agent.instructions()
    async def language_instructions(ctx: RunContext[StateDeps[AgentState]]) -> str:
        """语言跟踪 Agent 的指令。

        Args:
            ctx: 包含语言状态信息的运行上下文。

        Returns:
            语言跟踪 Agent 的指令字符串。
        """
        return dedent(
            f"""
            您是一个用于跟踪语言的有用助手。

            重要：
            - 语言始终使用小写
            - 始终使用当前语言回复：{ctx.deps.state.language}
            """
        )


    app = agent.to_ag_ui(deps=StateDeps(AgentState()))

    if __name__ == "__main__":
        import uvicorn
        uvicorn.run(app, host="0.0.0.0", port=8000)
    ```

  </Step>
  <Step>
    ### 使用 `useAgent` Hook
    当您的 Agent 连接并运行后，剩下要做的就是调用 `useAgent` Hook，传递 Agent 的名称，并可选择提供初始状态。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    // 定义 Agent 状态类型，应与您的 Agent 实际状态匹配
    type AgentState = {
      language: "english" | "spanish";
    }

    function YourMainContent() {
      // [!code highlight:4]
      const { agent } = useAgent({
        agentId: "my_agent",
        initialState: { language: "english" }  // 可选地提供初始状态
      });

      // ...

      return (
        // 为简洁起见，省略了样式
        <div>
          <h1>您的主内容</h1>
          {/* [!code highlight:1] */}
          <p>语言：{agent.state?.language}</p>
        </div>
      );
    }
    ```

    <Callout type="warn" title="重要">
      `name` 参数必须与您在 CopilotRuntime 配置中定义的 Agent 名称完全匹配（例如快速入门中的 `my_agent`）。
    </Callout>

    <Callout type="info">
      `useAgent` 中的 `agent.state` 是响应式的，当 Agent 的状态变化时会自动更新。
    </Callout>

  </Step>
  <Step>
    ### 试一试！
    随着 Agent 状态的更新，您的 `state` 变量将自动随之更新！在此示例中，您会看到语言设置为 "english"，因为我们设置了初始状态。
  </Step>
</Steps>

## 在聊天中渲染 Agent 状态

您还可以在聊天 UI 中渲染 Agent 的状态。这对于以更上下文相关的方式告知用户 Agent 的状态很有用。为此，您可以使用带有 `render` 函数的 `useAgent` Hook。

```tsx title="ui/app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

// 定义 Agent 状态类型，应与您的 Agent 实际状态匹配
type AgentState = {
  language: "english" | "spanish";
};

function YourMainContent() {
  // ...
  // [!code highlight:7]
  useAgent({
    agentId: "my_agent",
    render: ({ state }) => {
      if (!state.language) return null;
      return <div>语言：{state.language}</div>;
    },
  });
  // ...
}
```

<Callout type="warn" title="重要">
  `name` 参数必须与您在 CopilotRuntime 配置中定义的 Agent 名称完全匹配（例如快速入门中的 `my_agent`）。
</Callout>

<Callout type="info">
  `useAgent` 中的 `agent.state` 是响应式的，当 Agent 的状态变化时会自动更新。
</Callout>

## 中间流式传输和渲染 Agent 状态

默认情况下，Pydantic AI Agent 状态仅在 Pydantic AI Agent 节点转换_之间_更新——这意味着状态更新将是不连续且延迟的。
