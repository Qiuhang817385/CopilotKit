## 什么是多 Agent 流程？

在构建原生 Agent 应用程序时，您通常希望编排需要协调多个
Agent 的复杂流程。这传统上称为多 Agent 编排。

## 何时使用此功能？

当您希望编排需要协调多个 Agent 的复杂流程时，多 Agent 流程非常有用。随着
您的原生 Agent 应用程序的增长，将子任务委托给其他 Agent 可以帮助您扩展应用程序的关键部分。
- 将上下文划分为更小的块
- 将子任务委托给其他 Agent
- 使用单个 Agent 编排流程

## CopilotKit 如何支持此功能？

CopilotKit 可以在两种不同模式之一中使用：**路由模式**或**Agent 锁定**。默认情况下，CopilotKit
将使用路由模式，利用您定义的 LLM 在 Agent 之间路由请求。

### 路由模式（默认）
在使用 CoAgents 时默认启用路由模式。要使用它，请在 `CopilotKit` 提供商组件中指定运行时 URL 属性并省略 `agent` 属性，如下所示：
```tsx
<CopilotKit runtimeUrl="<copilot-runtime-url>">
  {/* 您的应用程序组件 */}
</CopilotKit>
```

在路由模式下，CopilotKit 充当中央枢纽，根据用户输入动态选择和_路由_不同 Agent 或操作之间的请求。这种模式非常适合以聊天为先的体验，其中 LLM 聊天机器人是各种交互的入口点，这些交互可以保留在聊天 UI 中或扩展到包含原生 React UI 小部件。

在此模式下，CopilotKit 将根据上下文和用户输入智能地将请求路由到最合适的 Agent 或操作。

<Callout type="warn">
    路由模式要求您设置 LLM 适配器。请参阅文档中的["设置 Copilot 运行时"](https://docs.copilotkit.ai/direct-to-llm/guides/quickstart?copilot-hosting=self-hosted#set-up-a-copilot-runtime-endpoint)部分了解如何操作。
</Callout>

### Agent 锁定模式
要使用 Agent 锁定模式，请在 `CopilotKit` 组件中使用 `agent` 属性指定 Agent 名称：
```tsx
// [!code word:agent]
<CopilotKit runtimeUrl="<copilot-runtime-url>" agent="<the-name-of-the-agent>">
  {/* 您的应用程序组件 */}
</CopilotKit>
```

在此模式下，CopilotKit 配置为与特定 Agent 独占工作。当您想专注于特定任务或领域时，此模式非常有用。而在路由模式下，LLM 和 CopilotKit 的路由器可以在不同 Agent 之间自由切换以处理用户请求，在 Agent 锁定模式下，所有请求将保留在单个工作流程图中，确保对工作流程的精确控制。

使用最适合您的应用程序体验的模式！另外，请注意，虽然您不能嵌套 `CopilotKit` 提供商，但您可以在应用程序的不同区域使用不同的 Agent 或模式——例如，您可能想要一个处于路由模式的聊天机器人，可以调用任何 Agent 或工具，但也可能想在其他地方集成一个特定的 Agent 以实现更专注的工作流程。
