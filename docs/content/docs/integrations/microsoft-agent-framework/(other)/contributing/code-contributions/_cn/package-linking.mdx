title: "高级：包链接"
---

在本指南中，我们将教您如何将 CopilotKit 包链接到您自己的项目以测试您的更改。这样，您可以在 CopilotKit monorepo 中运行 `turbo run dev`，并在您自己的项目中立即看到更改。

## 使用 `pnpm` 进行全局包链接

我们将使用 pnpm 的[全局链接功能](https://pnpm.io/cli/link#pnpm-link---global)将 CopilotKit 包链接到您自己的项目。

<Steps>
  <Step>
  ### 在 CopilotKit Monorepo 中
  假设您按照贡献指南中的所有步骤操作，您应该已经正确设置并准备就绪。

  导航到 CopilotKit monorepo 并运行以下命令以全局链接包：

  ```bash
  turbo run link:global
  ```
  </Step>
  <Step>
  ### 在您的项目中
  在您的项目中，确保您已配置 pnpm。这不会阻止您同时使用 npm 或 yarn。但出于全局链接的目的，您必须使用 pnpm。

  ```bash
  cd your-project
  pnpm i
  ```

  接下来，在您的项目中链接所需的包：
  ```bash
  # 例如，要链接 @copilotkit/react-core 包：
  pnpm link --global @copilotkit/react-core
  ```

  您可以为所有包运行此命令，或者只为您需要的包运行。您的更改现在将同步。
  </Step>
  <Step>
  ### 取消链接
  完成后，您可以通过在 CopilotKit monorepo 中运行以下命令来撤消全局链接：

  ```bash
  turbo run unlink:global
  ```

  然后在您的项目中：
  ```bash
  pnpm install
  ```

  就这样，一切恢复正常！
  </Step>
</Steps>
