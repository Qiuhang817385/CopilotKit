## 这是什么？
前端工具使您能够定义客户端函数，您的代理可以调用这些函数，而执行完全发生在用户的浏览器中。当您的代理调用前端工具时，逻辑在客户端运行，让您直接访问前端环境。

这可以用于让您的代理控制 UI、驱动生成式 UI，或支持人机交互（Human-in-the-loop）交互。

在本指南中，我们介绍使用前端工具驱动和与 UI 交互。

## 什么时候使用？
当您需要您的代理与客户端原语交互时使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问浏览器 API，如 localStorage、sessionStorage 或 cookie
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户立即浏览器上下文的操作

    <Step>
        ### 创建前端工具

        首先，您需要使用 [useFrontendTool](/reference/v1/hooks/useFrontendTool) 钩子创建一个前端工具。这里有一个简单的入门示例，用于向用户问好。

        ```tsx title="page.tsx"
        import { z } from "zod";
        import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          // [!code highlight:12]
          useFrontendTool({
            name: "sayHello",
            description: "向用户问好",
            parameters: z.object({
              name: z.string().describe("要问候的用户姓名"),
            }),
            handler: async ({ name }) => {
              alert(`您好，${name}！`);
              return `已向 ${name} 问好！`;
            },
          });

          // ...
        }
        ```
    </Step>

        ### 修改您的服务器
        现在，我们将确保您的 AG-UI 服务器可以接收并将这些前端操作传递给您的代理逻辑。

    <Step>
        ### 创建您的 AG-UI 服务器

        设置您的 AG-UI 服务器以服务于您的代理。使用 `useFrontendTool` 注册的前端工具会自动通过 AG-UI 协议提供给您的代理。

        <Tabs groupId="language_microsoft-agent-framework_agent" items={['.NET', 'Python']} persist>
          <Tab value=".NET">
            ```csharp title="Program.cs"
            using Azure.AI.OpenAI;
            using Azure.Identity;
            using Microsoft.Agents.AI;
            using Microsoft.Agents.AI.Hosting.AGUI.AspNetCore;

            var builder = WebApplication.CreateBuilder(args);
            builder.Services.AddAGUI();
            var app = builder.Build();

            string endpoint = builder.Configuration["AZURE_OPENAI_ENDPOINT"]!;
            string deployment = builder.Configuration["AZURE_OPENAI_DEPLOYMENT_NAME"]!;

            // 创建代理
            var agent = new AzureOpenAIClient(new Uri(endpoint), new DefaultAzureCredential())
                .GetChatClient(deployment)
                .CreateAIAgent(name: "AGUIAssistant", instructions: "您是一个有用的助手。");

            // 映射 AG-UI 端点
            app.MapAGUI("/", agent);
            await app.RunAsync();
            ```
          </Tab>
          <Tab value="Python">
            ```python title="agent/src/byo_agent.py"
            from __future__ import annotations
            import os
            from fastapi import FastAPI
            from dotenv import load_dotenv
            from agent_framework import ChatAgent
            from agent_framework import ChatClientProtocol
            from agent_framework.azure import AzureOpenAIChatClient
            from agent_framework.openai import OpenAIChatClient
            from agent_framework.ag_ui import add_agent_framework_fastapi_endpoint
            from azure.identity import DefaultAzureCredential

            load_dotenv()

            def _build_chat_client() -> ChatClientProtocol:
                if bool(os.getenv("AZURE_OPENAI_ENDPOINT")):
                    return AzureOpenAIChatClient(
                        credential=DefaultAzureCredential(),
                        deployment_name=os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT_NAME", "gpt-5.2-mini"),
                        endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
                    )
                if bool(os.getenv("OPENAI_API_KEY")):
                    return OpenAIChatClient(
                        model_id=os.getenv("OPENAI_CHAT_MODEL_ID", "gpt-5.2-mini"),
                        api_key=os.getenv("OPENAI_API_KEY"),
                    )
                raise RuntimeError("在 agent/.env 中设置 AZURE_OPENAI_* 或 OPENAI_API_KEY")

            chat_client = _build_chat_client()
            agent = ChatAgent(
                name="AGUIAssistant",
                instructions="您是一个有用的助手。",
                chat_client=chat_client,
            )

            app = FastAPI(title="AG-UI Server (Python)")
            add_agent_framework_fastapi_endpoint(app=app, agent=agent, path="/")
            ```
