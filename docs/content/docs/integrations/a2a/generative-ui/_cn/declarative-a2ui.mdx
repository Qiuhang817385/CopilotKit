    小部件被注入到代理的提示中，在本例中使用 `RESTAURANT_UI_EXAMPLES` 变量。
    小部件通过它们应该输出的 json 数组示例为代理定义，并包装在注释块中。
    - 指示示例开始的注释
    - beginRendering：小部件渲染的开始
    - surfaceUpdate：小部件的 json 结构示例
    - dataModelUpdate：用于填充小部件的数据示例
    - 指示示例结束的注释

    在示例仓库中，所有小部件都在 prompt_builder.py 文件中定义在一个变量中，但您可以根据需要组织它们，
    它们只需要以清晰划分的方式注入到代理的提示中即可。

    ### 配置您的应用程序以渲染 A2UI
    AG-UI 负责与您的 a2a 代理通信，并将 a2ui 消息作为 `ActivityMessage` 对象来回传递。
    为了在前端中渲染它们，您需要配置活动消息渲染。

    Copilotkit 为 A2UI 消息提供了一个渲染器，您只需使用主题实例化它并将其传递给您的 CopilotKitProvider 即可。

    ```tsx title="app/page.tsx"
    "use client";

    import { CopilotChat, CopilotKitProvider } from "@copilotkitnext/react";
    import { createA2UIMessageRenderer } from "@copilotkitnext/a2ui-renderer";
    import { theme } from "./theme";

    // 禁用此页面的静态优化
    export const dynamic = "force-dynamic";

    const A2UIMessageRenderer = createA2UIMessageRenderer({ theme });

    export default function Home() {
      return (
        <CopilotKitProvider
          runtimeUrl="/api/copilotkit"
          showDevConsole="auto"
          renderActivityMessages={[A2UIMessageRenderer]}
        >
          <main
            className="flex min-h-screen flex-1 flex-col overflow-hidden"
            style={{ minHeight: "100dvh" }}
          >
            <Chat />
          </main>
        </CopilotKitProvider>
      );
    }

    function Chat() {
      return (
        <div className="flex flex-1 flex-col overflow-hidden">
          <CopilotChat style={{ flex: 1, minHeight: "100%" }} />
        </div>
      );
    }
    ```
