## 这是什么？

您可以轻松地在聊天 UI 和原生应用程序 UX 中使用实时代理状态。

## 何时使用？

当您想向用户提供有关代理状态的反馈时，可以使用此功能。随着代理状态的更新，您可以在应用程序中原生地反映这些更新。

## 实现

<Steps>
  <Step>
    ### 运行并连接您的代理
    <RunAndConnect components={props.components} />
  </Step>
  <Step>
    ### 设置带状态的代理

    定义代理的状态模式。AWS Strands 会在整个执行过程中维护状态。

    ```python title="agent/main.py"
    import os
    from ag_ui_strands import StrandsAgent, StrandsAgentConfig, create_strands_app
    from strands import Agent
    from strands.models.openai import OpenAIModel

    model = OpenAIModel(
        client_args={"api_key": os.getenv("OPENAI_API_KEY", "")},
        model_id="gpt-4o",
    )

    # 创建 Strands 代理
    strands_agent = Agent(
        model=model,
        system_prompt="始终使用用户偏好的语言进行交流，如状态中定义的那样。不要使用其他语言进行交流。",
    )

    # 将状态注入提示
    def language_prompt(input_data, user_message: str) -> str:
        state_dict = getattr(input_data, "state", None)
        if isinstance(state_dict, dict) and "language" in state_dict:
            return f"当前语言: {state_dict['language']}\n\n用户请求: {user_message}"
        return user_message

    config = StrandsAgentConfig(state_context_builder=language_prompt)

    # 包装 AG-UI 集成
    agui_agent = StrandsAgent(
        agent=strands_agent,
        name="languageAgent",
        description="始终使用用户偏好的语言进行交流",
        config=config,
    )

    app = create_strands_app(agui_agent)
    ```
  </Step>

  <Step>
    ### 使用 `useAgent` Hook

    在代理连接并运行后，调用 `useAgent` hook，传入代理名称，并可选择提供初始状态。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    // 定义代理状态类型以匹配您的 Strands 代理
    type AgentState = {
      language: "english" | "spanish";
    };

    function YourMainContent() {
      // [!code highlight:5]
      const { agent } = useAgent({
        agentId: "languageAgent",
        // 可选地提供类型安全的初始状态
        initialState: { language: "spanish" }
      });

      // ...

      return (
        // 为简洁起见省略样式
        <div>
          <h1>您的主要内容</h1>
          {/* [!code highlight:1] */}
          <p>语言: {agent.state?.language}</p>
        </div>
      );
    }
    ```
    <Callout type="info">
      `useAgent` 中的 `agent.state` 是响应式的，当代理状态变化时会自动更新。
    </Callout>
  </Step>

  <Step>
    ### 试试看！

    当代理状态更新时，您的 `state` 变量会自动随之更新！在本例中，您会看到语言设置为 "spanish"，因为那是我们设置的初始状态。
  </Step>
</Steps>

## 在聊天中渲染代理状态

您也可以在聊天 UI 中渲染代理状态。这对于以更上下文相关的方式告知用户状态很有用。为此，您可以将 `useAgent` hook 与 `render` 函数一起使用。

```tsx title="ui/app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

// 定义代理状态类型，应与代理的实际状态匹配
type AgentState = {
  language: "english" | "spanish";
}

function YourMainContent() {
  // ...
  // [!code highlight:7]
  useAgent({
    agentId: "languageAgent",
    render: ({ state }) => {
      if (!state.language) return null;
      return <div>语言: {state.language}</div>;
    },
  });
  // ...
}
```

<Callout type="info">
  `useAgent` 中的 `agent.state` 是响应式的，当代理状态变化时会自动更新。
</Callout>
