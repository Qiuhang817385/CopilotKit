## 什么是共享状态？

CoAgents 维护一个共享状态，将您的 UI 与智能体的执行无缝连接。这个共享状态系统允许您：

- 显示智能体的当前进度和中间结果
- 通过 UI 交互更新智能体的状态
- 在整个应用程序中实时响应状态变化

该系统的基础建立在 CrewAI 的有状态架构之上。

## 什么时候应该使用它？

当您想促进智能体与用户之间的协作时，状态流式传输是完美的选择。您的 CrewAI Flow 持久化的任何状态将自动被 UI 共享。同样，用户在 UI 中更新的任何状态将自动反映出来。

这允许提供一致的体验，智能体和用户都在同一页面上。
