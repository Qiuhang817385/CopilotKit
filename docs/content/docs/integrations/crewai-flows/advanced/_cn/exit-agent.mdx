在您的智能体完成工作流后，您通常希望通过在 Python 代码中调用 `copilotkit_exit()` 方法来显式结束该循环。

退出智能体的效果取决于模式：

- **路由器模式**：退出智能体将处理输入的责任交还给路由器，路由器可以启动聊天、调用操作、其他智能体等。路由器可以稍后返回到此智能体（启动新循环）以满足用户请求。

- **智能体锁定模式**：退出智能体会重新启动当前智能体的工作流循环。

在这个来自[我们的邮件发送应用](https://github.com/copilotkit/copilotkit/tree/main/examples/coagents-qa)的示例中，`send_email` 节点显式退出，然后手动将响应作为 `ToolMessage` 发送回用户：

        ### 退出智能体循环
        这将在当前 CrewAI 运行完成后退出智能体会话，无论是通过断点还是到达 `END` 节点。

        <Tabs groupId="language_crewai-flows_agent" items={['Python']} default="Python" persist>
            <Tab value="Python">
                ```python
                import uuid
                from litellm import completion
                from crewai.flow.flow import start
                from copilotkit.crewai import copilotkit_exit
                # ...
                @start()
                async def send_email(self):
                    """发送邮件。"""


                    # 获取最后一条消息并转换为 ToolMessage
                    last_message = self.state["messages"][-1]
                    if last_message["content"] == "CANCEL":
                        text_message = "❌ 已取消发送邮件。"
                    else:
                        text_message = "✅ 已发送邮件。"
                    self.state["messages"].append({"role": "assistant", "content": text_message, "id": str(uuid.uuid4())})
                    # 处理后退出智能体循环
                    await copilotkit_exit() # [!code highlight]
                ```
