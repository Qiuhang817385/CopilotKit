### 设置 threadId

当在 CopilotKit 中设置 `threadId` 属性时，即：

```tsx
<CopilotKit threadId="2140b272-7180-410d-9526-f66210918b13">
  <YourApp />
</CopilotKit>
```

CopilotKit 将从数据库恢复会话的完整状态，包括消息。
（有关更多详细信息，请参阅[消息持久化](/crewai-flows/persistence/message-persistence)。）

### 加载代理状态

<Callout>
  **重要：** 要正确加载代理状态，您必须首先确保
  消息历史和持久化已正确配置。请按照
  [会话与持久化](/crewai-flows/persistence/loading-message-history)和[消息
  持久化](/crewai-flows/persistence/message-persistence)指南进行操作。
</Callout>

这意味着任何代理的状态也将被恢复。例如：

```tsx
const { state } = useAgent({ agentId: "research_agent" });

// state 现在将是上面给出的会话 id 中 research_agent 的状态
```
