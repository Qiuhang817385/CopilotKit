## 用于智能体聊天的预置组件

CopilotKit 的聊天组件为你提供了一个开箱即用、可完全自定义的 AI 聊天界面。
它们处理流式传输、生成式 UI 和深度自定义——因此你可以专注于智能体的行为，而不是 UI 基础设施。
