## 通过 hooks 实现完全渲染控制

CopilotKit 的 headless hooks 让您完全控制聊天体验 —— 管理消息、流式传输和工具调用，零 UI 限制。
带来您自己的设计系统，以您的方式渲染一切。

<Tabs items={['chat.tsx']}>
  <Tab value="chat.tsx">
  ```tsx
  import { useAgent, useCopilotKit } from "@copilotkit/react-core/v2";

  export default function Chat() {
    const { agent } = useAgent();
    const { copilotkit } = useCopilotKit();

    return (
      <div>
        {agent.messages.map((m) => (
          <p key={m.id}>{m.content}</p>
        ))}
        <button onClick={() => copilotkit.runAgent({ agent })}>
          {agent.isRunning ? "思考中..." : "发送"}
        </button>
      </div>
    );
  }
  ```
  </Tab>
</Tabs>

## 何时使用？

在以下情况下使用 headless UI：
- 使用自己的设计系统构建完全自定义的聊天界面
- 将智能体聊天集成到现有的 UI 模式中
- 完全控制消息渲染和交互
