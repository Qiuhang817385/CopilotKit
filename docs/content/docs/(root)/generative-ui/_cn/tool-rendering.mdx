## 这是什么？

工具渲染允许您自定义 Agent 的后端工具调用在聊天中的显示方式。您可以渲染自定义 React 组件来展示工具参数、进度和结果，而不是显示原始的工具执行过程。

## 何时使用？

在以下场景中使用工具渲染：
- 向用户展示 Agent 正在调用什么工具以及使用什么参数
- 在工具执行时显示进度指示器
- 在工具完成时渲染自定义结果
- 创建精致、透明的 Agent 体验
