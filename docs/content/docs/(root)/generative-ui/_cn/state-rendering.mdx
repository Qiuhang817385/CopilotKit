## 这是什么？

状态渲染允许您构建反映 Agent 实时状态的 UI。当您的 Agent 在节点间推进并发出状态更新时，您的前端将渲染这些变化——展示进度、草稿或中间结果。

## 何时使用？

在以下场景中使用状态渲染：
- 展示实时进度（例如"正在研究... 2/5 完成"）
- 展示随 Agent 工作而更新的草稿
- 构建反映 Agent 状态的仪表板
- 在聊天之外渲染结构化输出
