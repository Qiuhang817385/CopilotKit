## 这是什么？

工具渲染让您可以自定义智能体后端工具调用在聊天中的显示方式。您可以渲染自定义 React 组件来显示工具参数、执行进度和结果，而不是显示原始的工具执行过程。

## 何时使用？

在以下情况下使用工具渲染：
- 向用户展示智能体调用的工具及其参数
- 在工具执行时显示进度指示器
- 在工具完成时渲染自定义结果
- 创建精致、透明的智能体体验
