## 这是什么？

工具渲染允许你自定义智能体的后端工具调用在聊天中的显示方式。你可以渲染自定义的 React 组件来显示工具参数、执行进度和结果，而不是显示原始的工具执行信息。

## 什么时候应该使用这个？

当你想要以下功能时，请使用工具渲染：
- 向用户展示你的智能体正在调用什么工具以及使用什么参数
- 在工具执行时显示进度指示器
- 在工具完成时渲染自定义结果
- 创建精致、透明的智能体体验
