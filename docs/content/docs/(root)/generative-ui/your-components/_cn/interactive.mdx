## 这是什么？

交互式生成式 UI 通过用户交互扩展了展示组件。您的 Agent 渲染可供用户点击、输入或操作的组件，操作结果将反馈给 Agent。

## 何时使用？

在以下场景中使用交互式生成式 UI：
- 允许用户在聊天中确认或修改 Agent 的建议
- 在聊天中构建类似表单的交互
- 创建用户可接受/拒绝 Agent 操作的审批工作流
- 为 Agent 输出添加交互式控件（滑块、开关、选择器）
