## 这是什么？

MCP 应用是暴露带有相关 UI 资源工具的 MCP 服务器。当智能体调用这些工具之一时，CopilotKit 会自动获取并在聊天中渲染 UI 组件——无需额外的前端代码。

主要优势：
- **零前端代码**——UI 组件由 MCP 服务器提供
- **完全交互性**——组件可以使用 HTML、CSS 和 JavaScript
- **安全沙盒**——内容在隔离的 iframe 中运行
- **会话持久化**——MCP 应用存储在对话历史记录中，并在重新连接时恢复
