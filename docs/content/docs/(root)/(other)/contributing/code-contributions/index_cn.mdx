title: 代码贡献

我们非常感谢你对贡献 CopilotKit 的兴趣。我们欢迎新的贡献者，并感谢你对改进 CopilotKit 的帮助。

本指南将帮助你尽可能顺利地开始。

## 第 1 步：安装先决条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- [pnpm](https://pnpm.io/) v9.x 全局安装 (`npm i -g pnpm@^9`)
- [Turborepo v2.x](https://turborepo.org/) 全局安装 (`npm i -g turbo@2`)

## 第 2 步：仓库设置

<Steps>
  <Step>
  ### Fork 仓库
  首先，前往 [CopilotKit 仓库](https://github.com/CopilotKit/CopilotKit) 创建一个 Fork。

  然后，将你的 Fork 克隆到本地机器：
  ```bash
  git clone https://github.com/<你的用户名>/CopilotKit
  cd CopilotKit
  ```
  </Step>
  <Step>
  ### 安装依赖
  <Callout type="info">
    CopilotKit 仓库是基于 [Turborepo](https://turborepo.org/) 的 monorepo。
    我们使用 [pnpm](https://pnpm.io/) 作为包管理器。
  </Callout>

  使用 pnpm 安装依赖：
  ```bash
  pnpm install
  ```
  </Step>
  <Step>
  ### 构建包
  为了确保一切正常工作，让我们先构建所有包一次：
  ```bash
  turbo run build
  ```
  </Step>
</Steps>

## 第 3 步：开发模式
现在一切已设置好并正常工作，你可以开始开发了：

```bash
# 以开发模式启动所有包
turbo run dev

# 以开发模式启动特定包
turbo run dev --filter="@copilotkit/包名"
```

现在你可以开始对代码进行修改了。

<Callout type="info">
你可以在 monorepo 的 `packages` 文件夹下找到所有 `@copilotkit/*` 包。
</Callout>

## 第 4 步：实时测试更改

在大多数情况下，你希望在开发时能够无缝地实时测试你的更改。

我们在 monorepo 中有一个 `examples` 文件夹，包含几个使用 CopilotKit 的不同示例。你可以运行这些示例来测试你的更改，因为它们与 monorepo 中的 `@copilotkit/*` 包已链接。

在本教程中，我们将使用 `next-openai` 示例，特别是演示文稿演示 (`/presentation`)。

在单独的终端中，运行以下命令来启动示例：

```bash
cd examples/next-openai
export OPENAI_API_KEY=<你的-openai-api-密钥>
pnpm run example-dev
```

<Callout type="info">
我们使用 `pnpm run example-dev` 命令来运行示例，这与我们用于处理单个包的 `turbo run dev` 命令不同。
</Callout>

现在导航到 http://localhost:3000/presentation，你应该能看到示例正在运行。你对 CopilotKit 包所做的任何更改都会立即在这里反映出来。

## 第 5 步：格式化和代码检查

在提交你的更改之前，确保在 monorepo 的根目录下运行以下命令来正确格式化你的文件：
```bash
turbo run format
```

此外，确保你没有代码检查错误：
```bash
turbo run lint
```

## 第 6 步：提交 Pull Request

现在你已经完成了更改，提交并推送它们。然后，只需前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls) 创建一个 Pull Request。干得好！

## 使用热重载启动开发环境

CopilotKit 包含一个现成的脚本，用于基于其中一个 CoAgent 示例启动开发环境。它可以让你在处理 CopilotKit 核心 TypeScript 和 Python 代码的同时，看到你选择的示例中应用的变化。

作为先决条件，请确保你已安装 GNU parallel 和 langgraph CLI。

接下来，进入 `CopilotKit/` 目录并运行你想要处理的示例的 `example.sh` 脚本：

```bash
./scripts/develop/example.sh coagents-starter
```

这将启动一个支持热重载的开发环境。

你也可以选择通过运行以下命令在 LangGraph 平台上运行相同的示例：

```bash
./scripts/develop/example.sh coagents-starter langgraph-platform
```

## 调试

每次你在本地运行 CopilotKit 时，都能在聊天窗口中看到 **CopilotKit 开发控制台**。开发控制台为你提供了有用的功能来调试你的 Copilot（例如查看 Copilot 知道什么状态、可以执行什么操作等）。

    src="https://cdn.copilotkit.ai/docs/copilotkit/images/contributing/copilotkit-dev-console.png"
    className="w-auto max-w-[420px]"
  />
</Frame>

如果你想在本地禁用开发控制台，只需在你的 `<CopilotKit />` 提供器中设置 `showDevConsole` 为 `false`。

## （高级）包链接

 在某些情况下，你想在自己的项目中测试你的 CopilotKit 更改。例如，你尝试将 CopilotKit 集成到自己的代码库中，并遇到了想要修复的错误。

 方便的是，你可以将你本地的 CopilotKit 包链接到你自己的项目来测试你的更改。

 查看 [高级：包链接](/contributing/code-contributions/package-linking) 指南了解如何操作。
