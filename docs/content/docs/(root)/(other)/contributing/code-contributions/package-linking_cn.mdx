title: "高级：包链接"
---

在本指南中，我们将教你如何将 CopilotKit 包链接到你自己的项目以测试你的更改。这样，你可以在 CopilotKit monorepo 中运行 `turbo run dev`，并在自己的项目中立即看到更改。

## 使用 `pnpm` 进行全局包链接

我们将使用 pnpm 的[全局链接功能](https://pnpm.io/cli/link#pnpm-link---global)将 CopilotKit 包链接到你自己的项目。

<Steps>
  <Step>
  ### 在 CopilotKit Monorepo 中
  假设你已按照贡献指南完成了所有步骤，你应该已经正确设置好了一切，可以开始了。

  导航到 CopilotKit monorepo 并运行以下命令来全局链接包：

  ```bash
  turbo run link:global
  ```
  </Step>
  <Step>
  ### 在你的项目中
  在你的项目中，确保你已配置好 pnpm。这不会阻止你同时使用 npm 或 yarn。但对于全局链接的目的，你必须使用 pnpm。

  ```bash
  cd 你的项目
  pnpm i
  ```

  接下来，在你的项目中链接所需的包：
  ```bash
  # 例如，要链接 @copilotkit/react-core 包：
  pnpm link --global @copilotkit/react-core
  ```

  你可以为所有包运行此命令，或仅为你需要的包运行。你的更改现在将会同步。
  </Step>
  <Step>
  ### 取消链接
  完成后，你可以通过在 CopilotKit monorepo 中运行以下命令来撤销全局链接：

  ```bash
  turbo run unlink:global
  ```

  然后在你的项目中：
  ```bash
  pnpm install
  ```

  就这样，一切都恢复正常了！
  </Step>
</Steps>
