### CopilotKit：您的应用 + MCP 应用

CopilotKit 和 AG-UI 将 MCP 应用带入您的应用程序 —— 由您控制 UX、权限、工作流和智能体行为 —— 而不是将它们限制在第三方 AI 聊天体验中。

通过 CopilotKit 使用 MCP 应用让您的应用超越纯文本 copilot，成为交互式、智能体驱动的产品，工具可以在关键时刻向用户请求输入、确认和决策。
