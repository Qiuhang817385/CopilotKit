# A2A 和 MCP 握手

AG-UI 现在包含与 **MCP** 和 **A2A** 协议的**握手**功能，确保在整个智能体栈中实现顺畅的互操作性。

## 什么是协议握手？

协议握手允许 AG-UI 与使用不同交互协议的智能体无缝通信。这意味着您可以将前端连接到内部使用 MCP 或 A2A 的智能体，而无需任何额外配置。

## 优势

### 完全互操作性
如果您的主机智能体使用 **MCP** 或 **A2A** 连接到子智能体，它们的 UI 属性可以通过整个链路传播到面向用户的应用程序。

### 安全和控制
握手在整个通信链中保留**完整的安全、策略和可观察性控制**。

### 简化架构
无需在协议之间做出选择 —— 在单个应用程序中将它们全部一起使用。

## 工作原理

1. **前端通过 AG-UI 连接** — 您的应用程序使用 AG-UI 连接到主机智能体
2. **主机智能体使用 MCP/A2A** — 主机智能体可以使用 MCP 或 A2A 与子智能体通信
3. **UI 属性传播** — 生成式 UI 和其他属性自动流回您的前端
