## A2UI 发布 — 完全兼容

CopilotKit 一直与 Google 密切合作开发 A2A 和 A2UI 集成，并很荣幸成为 **A2UI 的发布合作伙伴**。

### 什么是 A2UI？

A2UI（Agent-to-UI）是 Google 的声明式、LLM 友好的生成式 UI 规范。它定义了*渲染什么*以及如何以视觉方式构建 Agent 响应——使 Agent 能够生成丰富的交互式 UI 组件，可以在不同的平台和框架中渲染。

CopilotKit 为 A2UI 提供**零日支持**，意味着您可以立即在 CopilotKit 驱动的应用程序中开始使用 A2UI 组件。

- [生成式 UI 规范概览](/learn/generative-ui/specs)
- [更多关于 A2UI](/learn/generative-ui/specs/a2ui)
- [A2A 协议](/a2a-protocol)
