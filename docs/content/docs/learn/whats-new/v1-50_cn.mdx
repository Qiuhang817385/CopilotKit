# 向后兼容

您已经在使用的所有功能都将继续工作。v1.50 与使用 v1.10 的客户端代码完全向后兼容。事实上，作为此预发布阶段的第一步，我们希望您从重新构建开始，如果遇到任何问题请告诉我们。

### V2 接口

如上所述，所有 v1（或未版本化）的 hooks 在 v1.50 中继续工作。要利用新的 hooks，您需要使用标记为 /v2 的接口（如下所示）。

您可以选择使用任何新的开发人员接口或继续使用旧的。允许在以下配置中混合使用：

- 新的 Chat 组件 + 旧的 hooks
- 旧的组件 + 新的 hooks
- 新的 v2 API 暴露在子路径下：
    
    ```tsx
    import { CopilotChat, useAgent } from "@copilotkit/react-core/v2";
    ```

# `useAgent`

v2 hook useAgent 是 `useCoAgent` 的完整超集，提供更多对智能体连接的控制，包括：

### 共享状态
    
    ```tsx
    import { useAgent } from "@copilotkit/react-core/v2";
    
    const { agent } = useAgent({ agentId: "my-agent" });
    
    agent.state
    agent.setState
    ```
    
### 时间旅行
    
    ```tsx
    import { useAgent } from "@copilotkit/react-core/v2";
    
    const { agent } = useAgent({ agentId: "my-agent" });
    
    agent.setMessages()
    ```
    
### 多智能体执行
    
    ```tsx
    import { useAgent } from "@copilotkit/react-core/v2";
    
    const { agent: langgraph } = useAgent({ agentId: "langgraph" });
    const { agent: pydantic } = useAgent({ agentId: "pydantic" });
    
    [langgraph, pydantic].forEach((agent) => {
      agent.addMessage({ id: crypto.randomUUID(), role: "user", content: message });
      agent.runAgent();
    });
    ```
    
### 智能体相互感知

您甚至可以让智能体相互感知！
    
    ```tsx
    import { useAgent } from "@copilotkit/react-core/v2";
    
    const { agent: langgraph } = useAgent({ agentId: "langgraph" });
    const { agent: pydantic } = useAgent({ agentId: "pydantic" });
    
    langgraph.setMessages(pydantic.messages)
    pydantic.setMessages(langgraph.messages)
    ```

## 即将推出
v1.50 现已可用，useAgent 已完全就绪。其他功能（如下所列）将在不久的将来添加。

### 线程和持久化

v1.50 提供对线程对话的支持，内置线程存储和连接组件。为开发提供 InMemory 或 SQLite 的开箱即用支持。

#### 线程存储
    - **开发环境：** 开箱即用支持 `InMemory` 或 `SQLite`
        
        ```tsx
        import { CopilotRuntime } from "@copilotkit/runtime";
        
        const runtime = new CopilotRuntime({
          agents: {
            default: agent,
          },
          runner: new InMemoryAgentRunner(), // 用于持久化的新抽象
        });
        ```
        
    - **生产环境**
        - **即将推出！** 使用 **Copilot Cloud**（托管）或 **Copilot Enterprise**（自托管）将线程持久化到您自己的数据库，获得自动流重新连接、内置产品分析。
            - **👉 加入 [Enterprise 抢先体验](https://go.copilotkit.ai/enterprise-threads-waitlist) 等待名单！**
        
#### 线程连接
    - 加载线程
        
        ```tsx
        import { CopilotChat } from "@copilotkit/react-core/v2"
        
        <CopilotChat threadId="xyz" /> // 连接到运行时的 runner
        ```
        
    - 流重新连接
        
        ```tsx
        import { CopilotChat } from "@copilotkit/react-core/v2"
        
        <CopilotChat threadId="xyz" /> // 如果页面重新加载将重新连接
        ```

### 新设计系统

您可以继续使用 v1 接口中的设计系统，但 v2 提供了全面的 UI 改造和更深度的定制：

- 新的 `CopilotChat`、`CopilotSidebar`、`CopilotPopup`

    - 新的插槽系统，可灵活覆盖
    - 开箱即用的 Markdown 渲染效果大大提升
- 与智能体完美协作的建议 API

### Zod Schema 支持

许多 CopilotKit hooks 现在接受 Zod schemas，在编译时和运行时强制执行类型安全。

- `useHumanInTheLoop` - 现在接受 Zod schemas
- `useFrontendTool` - 现在接受 Zod schemas
- `useRenderToolCall` - 新的开发体验原则

---

### 简化的基础设施

早期版本的 CopilotKit 需要安装 GraphQL。新架构完全移除了这一要求。

---

### 直接到 LLM 的改进

我们的直接到 LLM 集成现在支持更多模型并实现共享状态。

#### BasicAgent - 现在支持更广泛的模型

```tsx
import { BasicAgent } from "@copilotkit/runtime"

const runtime = new CopilotRuntime({
  agents: {
    myBasicAgent: new BasicAgent({
		  model: "openai/gpt-5.2", // 更广泛的模型支持
		  prompt: "你是一个乐于助人的 AI 助手。",
		  temperature: 0.7,
		});
  },
});
```

#### 共享状态支持

```tsx
import { useAgent } from "@copilotkit/react-core/v2";

const { agent } = useAgent({agentId: "myBasicAgent"});  
const { state, setState } = agent;
```
