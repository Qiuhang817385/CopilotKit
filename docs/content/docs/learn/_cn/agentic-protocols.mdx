## **混合搭配协议**

CopilotKit 允许开发人员**直接或以组合方式**连接到这些协议中的任何一个。
CopilotKit 可以通过任何交互协议连接到您的智能体后端。

<Image 
  src="/images/any-agentic-backend-light.png"

或者，由于 AG-UI 还包含与 **MCP** 和 **A2A** 的**握手**，CopilotKit 可以通过 AG-UI 连接到支持 MCP 或 A2A 的智能体。

这意味着如果您的主智能体使用 **MCP** 或 **A2A** 连接子智能体，它们的 UI 属性可以通过 AG-UI 一直传播到面向用户的应用程序——同时保留**完整的安全性、策略和可观察性控制。**
