## 这是什么？

程序化控制让您可以在聊天 UI 之外运行 Agent —— 触发 Agent 运行、访问结果并完全从代码中管理状态。构建不需要聊天窗口的 Agent 驱动功能。

<Tabs items={['page.tsx']}>
  <Tab value="page.tsx">
  ```tsx
  import { useAgent, useCopilotKit } from "@copilotkit/react-core/v2";

  export function AgentButton() {
    const { agent } = useAgent();
    const { copilotkit } = useCopilotKit();

    const handleClick = async () => {
      await copilotkit.runAgent("分析当前数据");
    };

    return (
      <button onClick={handleClick} disabled={agent.isRunning}>
        {agent.isRunning ? "分析中..." : "运行分析"}
      </button>
    );
  }
  ```
  </Tab>
</Tabs>

## 什么时候应该使用？

当您想要执行以下操作时使用程序化控制：
- 从按钮、表单或其他 UI 元素触发 Agent 运行
- 无需聊天窗口即可构建 Agent 功能
- 以编程方式访问 Agent 状态和结果
- 创建完全自定义的 Agent 驱动工作流
