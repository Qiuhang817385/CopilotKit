# 常见问题

我们有一些常见问题的答案！

<Accordions>
  <Accordion title="什么是 Copilot？">
    Copilot 是一个生活在您的应用程序中帮助用户完成任务的值得信赖的伙伴。
    有两种主要类型，**Concierge** 和 **Worker**。

    ### Concierge

    Concierge Copilot 了解您的应用程序功能和完整的用户上下文。它作为智能中介将高级用户意图转化为操作。

    例如，我们的[银行助手](https://github.com/CopilotKit/demo-banking)实现了 Concierge Copilots 来帮助用户管理他们的（假）银行需求。


    ### Worker

    Worker Copilot 是一个特定领域的 Agent，可以帮助用户执行他们的核心工作任务。
    它作为用户的合作伙伴，在某些任务上表现更好，在其他任务上表现较差。
    最终，它增强用户的能力，使他们能够产生比想象中更好的工作成果。这种模式通常用于后台 Copilot。

    将 Worker Copilot 视为 Cursor、Replit Agent 或 Windsurf，但适用于任何领域。例如，
    查看我们的 [Open Researcher ANA](https://github.com/CopilotKit/open-research-ana)。
  </Accordion>

  <Accordion title="它是如何工作的？">
    好问题！CopilotKit 有三个主要组件：
    1. **CopilotKit UI**：用于构建 Copilots 和 Agent 的 UI 组件。
    2. **CopilotKit Runtime**：用于构建 Copilots 和 Agent 的运行时。这是您的 Copilots 和 Agent 的后端。
    3. **CopilotKit SDK**：在更复杂的应用程序中，您将使用 SDK 将 CopilotKit 深度集成到您的 Agent 中。
  </Accordion>

  <Accordion title="我可以将任何 LLM 与 CopilotKit 一起使用吗？">
    是的！CopilotKit 支持大多数 LLM，包括 OpenAI、Anthropic、Google 等。此外，您可以使用 LangGraph 或 LangChain 支持的任何 LLM。

    有关更多信息，请查看我们关于[使用自己的 LLM](/built-in-agent/model-selection)的文档。
  </Accordion>
