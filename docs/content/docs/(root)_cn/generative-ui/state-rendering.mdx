## 这是什么？

状态渲染让你可以构建反映 Agent 实时状态的 UI。当你的 Agent 在各个节点间推进并发出状态更新时，你的前端会渲染这些变化 —— 显示进度、草稿或中间结果。

## 什么时候使用？

在以下情况下使用状态渲染：
- 显示实时进度（例如 "正在研究... 2/5 完成"）
- 展示随着 Agent 工作而更新的草稿
- 构建反映 Agent 状态的仪表板
- 在聊天外渲染结构化输出
