## 这是什么？

交互式生成式 UI 扩展了展示组件，增加了用户交互功能。你的 Agent 渲染用户可以点击、输入或操作的组件 —— 结果会流回 Agent。

## 什么时候使用？

在以下情况下使用交互式生成式 UI：
- 让用户 inline 确认或修改 Agent 的建议
- 在聊天中构建类似表单的交互
- 创建用户可以接受/拒绝 Agent 操作的审批工作流
- 为 Agent 输出添加交互式控件（滑块、开关、选择器）
