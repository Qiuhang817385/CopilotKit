## 这是什么？

交互式生成式 UI 创建 Agent 暂停执行并等待用户输入后再继续的流程。这实现了审批工作流、确认对话框以及任何需要人工判断的场景。

## 什么时候使用？

在以下情况下使用交互式生成式 UI：
- 批准/拒绝流程（例如 "运行此命令？"）
- Agent 应该知道的用户决策
- 带有结构化响应的确认对话框
- 任何 Agent 暂停等待人工判断的流程
