## 用于 Agent 聊天的预构建组件

CopilotKit 的聊天组件为您提供了一个开箱即用的、可自定义的 AI 聊天界面。
它们处理流式传输、生成式 UI 和深度定制 —— 因此您可以专注于 Agent 的行为，而不是 UI  plumbing。

## 选择您的 AI 后端开始

聊天组件可与任何 AI 后端配合使用。选择您的集成以开始使用。
