## 欢迎使用 CopilotKit！

CopilotKit 是面向 **Agent** 和 **生成式 UI** 的 **前端技术栈**。将任何 Agent 框架或模型连接到您的 React 应用，实现 **聊天**、**生成式 UI**、**画布应用** 和 **人机协同** 工作流。

请查看下方的指南，找到适合您需求的指南，无论您是从零开始还是已有现有的 Agent 想要为其提供预构建的聊天 UI 或完全自定义的 UI。
