## 这是什么？

前端工具让您的 AI Agent 能够直接与应用程序的 UI 进行交互和更新。它们弥合了 Agent 的决策与前端交互元素之间的差距。

<Tabs items={['page.tsx']}>
  <Tab value="page.tsx">
  ```tsx
  import { z } from "zod";
  import { useFrontendTool } from "@copilotkit/react-core/v2";

  useFrontendTool({
    name: "setTheme",
    description: "切换应用的颜色主题",
    parameters: z.object({
      theme: z.enum(["light", "dark"]),
    }),
    handler: async ({ theme }) => {
      document.documentElement.dataset.theme = theme;
      return `主题已设置为 ${theme}！`;
    },
  });
  ```
  </Tab>
</Tabs>

## 什么时候应该使用？

当您的 Agent 需要执行以下操作时，请使用前端工具：
- 动态更新 UI 元素
- 触发动画或过渡效果
- 显示警告或通知
- 修改应用程序状态
