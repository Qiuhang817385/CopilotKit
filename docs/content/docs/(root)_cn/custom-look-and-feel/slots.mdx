## 这是什么？

插槽允许你在不完全从头构建的情况下自定义 CopilotKit 预构建的聊天组件。覆盖 UI 的特定部分 —— 消息气泡、输入区域、标题栏 —— 同时保留其余的默认行为。

## 什么时候使用？

在以下情况下使用插槽：
- 自定义聊天 UI 的特定部分（例如消息渲染、输入区域）
- 在不构建完全自定义聊天界面的情况下匹配应用的设计系统
- 添加自定义元素，如打字指示器、头像或操作按钮
