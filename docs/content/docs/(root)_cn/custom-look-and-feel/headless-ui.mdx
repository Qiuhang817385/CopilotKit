## 这是什么？

无头 UI 让你完全控制聊天体验 —— 你提供自己的组件、布局和样式，而 CopilotKit 处理 Agent 通信、消息管理和流式传输。

## 什么时候使用？

当[插槽系统](/custom-look-and-feel/slots)不够用时使用无头 UI —— 例如，当你需要完全不同的布局、想要将聊天嵌入到现有 UI 中，或者正在构建一个仍然与 Agent 通信的非聊天界面时。
