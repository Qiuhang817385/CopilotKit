## 什么是共享状态？

CoAgents 维护一个共享状态，将您的 UI 与智能体的执行无缝连接。此共享状态系统允许您：

- 显示智能体的当前进度和中间结果
- 通过 UI 交互更新智能体的状态
- 在整个应用程序中实时响应状态更改

该系统的基础建立在 AG2 `ContextVariables` 和 AG-UI `StateSnapshotEvent` 之上。

<Callout type="info">
  CopilotKit 通过 <code>/chat</code> 消费 AG2 流式传输的 AG-UI 协议事件。请参阅 <a href="https://docs.ag2.ai/latest/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI 集成文档</a>。
</Callout>

## 什么时候应该使用它？

当您希望促进智能体与用户之间的协作时，状态流是完美的。您的 AG2 后端
在快照事件中发出的任何状态都将由 UI 自动共享。同样，用户在 UI 中更新的任何状态都将自动反映。

这允许获得一致的体验，智能体和用户都在同一页面上。
