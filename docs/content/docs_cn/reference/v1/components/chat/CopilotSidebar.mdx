CopilotKit 框架的聊天机器人侧边栏组件。通过各种属性和自定义 CSS 高度可定制。

请参见 [CopilotPopup](/reference/v1/components/chat/CopilotPopup) 了解此组件的弹出窗口版本。

## 安装依赖

此组件是 [@copilotkit/react-ui](https://npmjs.com/package/@copilotkit/react-ui) 包的一部分。

```shell npm2yarn "@copilotkit/react-ui"\
npm install @copilotkit/react-core @copilotkit/react-ui
```

## 用法

```tsx
import { CopilotSidebar } from "@copilotkit/react-ui";
import "@copilotkit/react-ui/styles.css";

<CopilotSidebar
  labels={{
    title: "Your Assistant",
    initial: "Hi! 👋 How can I assist you today?",
  }}
>
  <YourApp/>
</CopilotSidebar>
```

### 使用可观察性钩子

要监控用户交互，请提供 `observabilityHooks` 属性。
注意：这需要在 `<CopilotKit>` provider 中提供 `publicApiKey`。

```tsx
<CopilotKit publicApiKey="YOUR_PUBLIC_API_KEY">
  <CopilotSidebar
    observabilityHooks={{
      onChatExpanded: () => {
        console.log("Sidebar opened");
      },
      onChatMinimized: () => {
        console.log("Sidebar closed");
      },
    }}
  >
    <YourApp/>
  </CopilotSidebar>
</CopilotKit>
```

## 属性

<PropertyReference name="instructions" type="string"  >
要添加到系统消息的自定义指示。使用此属性可提供
  额外的上下文或指导给语言模型，影响
  其响应。这些指示可以包括具体的方向、
  偏好或模型在生成其输出时应考虑的标准，
  从而更精确地将对话定制到用户的需求或应用程序的要求。
</PropertyReference>

<PropertyReference name="suggestions" type="ChatSuggestions"  >
控制聊天界面中建议的行为。

  `auto`（默认）- 建议自动生成：
    - 当聊天首次打开时（空状态）
    - 每次消息交换完成后
    - 使用 `useCopilotChatSuggestions` 钩子的配置

  `manual` - 建议以编程方式控制：
    - 使用 `setSuggestions()` 设置自定义建议
    - 使用 `generateSuggestions()` 触发 AI 生成
    - 通过 `useCopilotChat` 钩子访问

  `SuggestionItem[]` - 静态建议数组：
    - 始终显示相同的建议
    - 不涉及 AI 生成
</PropertyReference>

<PropertyReference name="onInProgress" type="(inProgress: boolean) => void"  >
