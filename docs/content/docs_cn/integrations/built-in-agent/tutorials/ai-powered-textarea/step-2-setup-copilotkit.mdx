现在我们的待办事项列表应用已经运行起来了，我们准备集成 CopilotKit。在本教程中，我们将安装以下依赖：

- `@copilotkit/react-core`：CopilotKit 的核心库，包含 CopilotKit 提供者和有用的 Hook。
- `@copilotkit/react-textarea`：CopilotKit 的文本域组件，使您能够在应用中获得即时的上下文感知自动补全。

## 安装依赖

要安装 CopilotKit 依赖，请运行以下命令：

```npm
npm install @copilotkit/react-core @copilotkit/react-textarea
```

### 配置 CopilotKit 提供者

```tsx title="app/page.tsx" showLineNumbers {5,10,14}
"use client";

import { EmailThread } from "@/components/EmailThread";
import { EmailsProvider } from "@/lib/hooks/use-emails";
import { CopilotKit } from "@copilotkit/react-core"; // [!code highlight]
import "@copilotkit/react-textarea/styles.css"; // [!code highlight]

export default function Home() {
  return (
    <CopilotKit runtimeUrl="/api/copilotkit">
      {" "}
      // [!code highlight]
      <EmailsProvider>
        <EmailThread />
      </EmailsProvider>
    {/* [!code highlight:1] */}
    </CopilotKit>
  );
}
```

</Step>

- 首先，我们从 `@copilotkit/react-core` 导入 `CopilotKit` 提供者。

- 我们从 `@copilotkit/react-textarea` 导入内置样式。
