## 接下来做什么？

对于后续步骤，这里有一些想法：

- 使用 [`useCopilotChatSuggestions`](/reference/v1/hooks/useCopilotChatSuggestions) Hook 为您的助手添加建议。
- 在聊天窗口中添加初始助手消息（更多信息，请查看 [`<CopilotPopup />`](/reference/v1/components/chat/CopilotPopup) 的文档）。
- 深入了解有用的 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) Hook，它使您能够设置系统消息、追加消息等。
- 使用 [`<CopilotTextarea />`](/reference/v1/components/CopilotTextarea) 组件实现自动补全。
- 跟随 [文本域自动补全教程](/built-in-agent/tutorials/ai-powered-textarea) 了解更多关于 CopilotKit 的内容。

我们很快会有更多教程。
