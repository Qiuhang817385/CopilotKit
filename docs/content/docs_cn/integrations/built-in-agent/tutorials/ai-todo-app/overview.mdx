## 您将学到什么

在本教程中，您将采用一个简单的待办事项列表应用，并用助手为其增添超能力。您将学习：

- 💡 如何使用聊天 UI 嵌入应用内助手
- 💡 如何使用 `useCopilotReadable` 让助手读取应用的状态
- 💡 如何使用 `useFrontendTool` 让助手执行工具
