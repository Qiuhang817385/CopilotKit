现在我们的待办事项列表应用已经运行起来了，我们准备集成 CopilotKit。在本教程中，我们将安装以下依赖：

- `@copilotkit/react-core`：CopilotKit 的核心库，包含 CopilotKit 提供者和有用的 Hook。
- `@copilotkit/react-ui`：CopilotKit 的 UI 库，包含 CopilotKit UI 组件，如侧边栏、聊天弹出窗口、文本域等。

## 安装依赖

要安装 CopilotKit 依赖，请运行以下命令：

```npm
npm install @copilotkit/react-core @copilotkit/react-ui
```

### CopilotKit 聊天弹出窗口

我们提供了几个即插即用的组件供您与助手交互。其中一些是 `<CopilotPopup/>`、`<CopilotSidebar/>` 和 `<CopilotChat/>`。当然，您也可以以无头模式使用 CopilotKit，并通过 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) 提供您自己的完全自定义 UI。

在本教程中，我们将使用 `<CopilotPopup/>` 组件来显示聊天弹出窗口。

```tsx title="app/page.tsx" showLineNumbers {6-7,15}
"use client";

import { TasksList } from "@/components/TasksList";
import { TasksProvider } from "@/lib/hooks/use-tasks";
import { CopilotKit } from "@copilotkit/react-core";
import { CopilotPopup } from "@copilotkit/react-core/v2"; // [!code highlight]
import "@copilotkit/react-ui/v2/styles.css"; // [!code highlight]

export default function Home() {
  return (
    <>
      <TasksProvider>
        <TasksList />
      </TasksProvider>
      {/* [!code highlight:1] */}
      <CopilotPopup />
    </>
  );
}
```

这是我们做的：

- 我们从 `@copilotkit/react-ui` 导入 `<CopilotPopup />` 组件。
- 我们用 `<CopilotKit>` 提供者包裹页面。
- 我们从 `@copilotkit/react-ui` 导入内置样式。

现在，回到您的应用，您会在页面右下角找到一个聊天弹出窗口。此时，您可以开始与助手交互了！🎉

在下一步中，我们将通过提供待办事项列表的可读状态来让我们的助手更智能。
