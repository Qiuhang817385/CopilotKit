---
title: "共享状态"
icon: "lucide/Repeat"
description: "您的应用与内置 Agent 之间的双向状态共享。"
---

在您的 React 应用和内置 Agent 之间双向共享状态。您的应用可以读取和写入 Agent 状态，Agent 也可以更新您的 UI 实时响应的状态。

## 这是什么？

共享状态让您的前端和 Agent 保持同步。Agent 可以更新状态（如向列表添加项目或更改设置），您的 React 组件会自动重新渲染。您的应用也可以写入 Agent 可以读取的状态。

## 什么时候使用？

- Agent 应该能够修改您的应用 UI（添加项目、更新字段、切换设置）
- 您希望在 Agent 工作时实时更新 UI
- 您的应用需要读取 Agent 正在执行的操作（进度指示器、中间结果）

## 读取 Agent 状态

使用 `useAgent` Hook 访问 Agent 的当前状态：

```tsx title="app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

function TaskBoard() {
  // [!code highlight:3]
  const { agent } = useAgent({
    agentId: "assistant",
  });

  // 读取 Agent 设置的状态 // [!code highlight]
  const tasks = (agent.state.tasks as any[]) ?? [];

  return (
    <div>
      <h2>任务</h2>
      <ul>
        {tasks.map((task, i) => (
          <li key={i}>
            {task.title} — {task.status}
          </li>
        ))}
      </ul>
    </div>
  );
}
```

<Callout type="info">
  `agent.state` 是响应式的 —— 当 Agent 更新状态时，您的组件会自动重新渲染。
</Callout>

## 从前端写入状态

您也可以将状态从前端推送到 Agent：

```tsx title="app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2";

function SettingsPanel() {
  const { agent } = useAgent({
    agentId: "assistant",
  });

  const handleThemeChange = (theme: string) => {
    agent.setState({ // [!code highlight]
      ...agent.state, // [!code highlight]
      userPreferences: { theme }, // [!code highlight]
    }); // [!code highlight]
  };

  return (
    <div>
      <button onClick={() => handleThemeChange("dark")}>深色模式</button>
      <button onClick={() => handleThemeChange("light")">浅色模式</button>
    </div>
  );
}
```

## 工作原理

内置 Agent 通过 AG-UI 协议自动访问状态工具（`AGUISendStateSnapshot` 和 `AGUISendStateDelta`）。当 Agent 调用这些工具时：

1. Agent 发送状态更新（完整快照或增量）
2. CopilotKit 运行时通过 SSE 将更新传递到前端
3. 您的 `useAgent` Hook 接收更新并触发重新渲染

无需额外的后端配置 —— 状态工具默认对内置 Agent 可用。

## 示例：协作待办事项列表

这是一个完整的示例，Agent 可以添加和管理任务：

```tsx title="app/page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";
import { useAgent } from "@copilotkit/react-core/v2";

function TodoApp() {
  const { agent } = useAgent({
    agentId: "assistant",
  });

  const todos = (agent.state.todos as any[]) ?? [];

  return (
    <div style={{ display: "flex", gap: "1rem" }}>
      <div>
        <h2>我的待办事项</h2>
        <ul>
          {todos.map((todo, i) => (
            <li key={i} style={{ textDecoration: todo.done ? "line-through" : "none" }}>
              {todo.text}
            </li>
          ))}
        </ul>
      </div>
      <CopilotChat
        labels={{
          welcomeMessageText: "I can help manage your todos. Try 'Add a task to buy groceries'.",
        }}
      />
    </div>
  );
}
```

当您告诉 Agent "Add a task to buy groceries" 时，它会更新共享状态，您的待办事项列表会立即渲染新项目。
