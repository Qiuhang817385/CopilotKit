## 这是什么？

前端工具允许您定义客户端函数，供 Agent Spec 智能体调用，执行完全在用户的浏览器中进行。当智能体调用前端工具时，逻辑在客户端运行，让您直接访问前端环境。

这可以用于让[您的智能体控制 UI](/agent-spec/frontend-tools)、[生成式 UI](/agent-spec/frontend-tools)，或用于人机协作交互。

在本指南中，我们介绍将前端工具用于人机协作的场景。

## 什么时候使用？

当您需要智能体与客户端原语交互时使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问浏览器 API，如 localStorage、sessionStorage 或 cookies
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户即时浏览器上下文的操作

## 实现步骤

<Steps>
    <Step>
      ### 运行并连接您的智能体
      <RunAndConnect components={props.components} />
    </Step>

    <Step>
        ### 创建前端人机协作工具

        前端工具可以以多种方式利用。其中一种方式是实现人机协作流程，工具响应由用户决策控制。

        在此示例中，我们将模拟执行命令的"审批"流程。首先，使用 `useHumanInTheLoop` 钩子创建一个提示用户审批的工具。

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: [
              {
                name: "option_1",
                type: "string",
                description: "The first option",
                required: true,
              },
              {
                name: "option_2",
                type: "string",
                description: "The second option",
                required: true,
              },
            ],
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 设置您的智能体

        人机协作工具通过 Agent Spec 中的 `ClientTool` 概念启用。更多详情请参阅[前端工具指南](/agent-spec/frontend-tools)。简而言之，在您的 Agent Spec 配置中，您需要提供工具声明，但执行发生在客户端（在您的前端）。
    </Step>
    <Step>
        ### 试试看！

        您现在赋予了智能体向用户显示两个选项并让他们选择其中一个的能力。智能体随后将知晓用户的选择，并可以在后续步骤中使用它。

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>
</Steps>
