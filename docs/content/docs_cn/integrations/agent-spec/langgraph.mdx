## 这是什么？

通过 AG-UI 事件协议将基于 LangGraph 的 Agent Spec 智能体连接到 CopilotKit 的 UI。您将运行一个 FastAPI 端点，发出 AG-UI 事件，并将您的 Next.js 应用指向它。

关键部分：
- 后端端点：`ag-ui/integrations/agent-spec/python/ag_ui_agentspec/endpoint.py`
- 示例服务器：`ag-ui/integrations/agent-spec/python/examples/server.py`
- 模板 UI：`npx copilotkit@latest create`

## 什么时候使用？

当您已经有一个由 Agent Spec 描述的基于 LangGraph 的智能体，并希望获得一个能流式传输助手文本、工具调用/结果和运行生命周期的现成 UI 时使用此集成。

## 前置要求

- Python 3.10–3.14
- Node.js 20+
- Agent Spec 配置 JSON/YAML 文件（或通过 `pyagentspec` 的 Python 代码）

## 安装 Agent Spec AG-UI 集成

从 AG-UI 仓库的 Agent Spec 集成包：

```bash
git clone https://github.com/ag-ui-protocol/ag-ui.git
cd ag-ui/integrations/agent-spec/python
uv pip install -e .[langgraph]
```

注意，这会从源代码安装 `pyagentspec`。或者，您可以用 pip 安装：

```bash
pip install pyagentspec[langgraph]
```

## 步骤

<Step>
### 1. 启动 FastAPI 端点（最小化示例）

使用 LangGraph 运行时执行您的 Agent Spec 并流式传输 AG-UI 事件。

```python
from fastapi import FastAPI
from ag_ui_agentspec.agent import AgentSpecAgent
from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint

agentspec_json = <loaded json/yaml string of your Agent Spec config> 

app = FastAPI()
agent = AgentSpecAgent(agentspec_json, runtime="langgraph")
add_agentspec_fastapi_endpoint(app, agentspec_agent=agent, path="/")
```

本地运行：

```bash
uvicorn backend.app:app --reload --port 8000
```

</Step>

## 工作原理

- `AgentSpecAgent(runtime="langgraph")` 使用 LangGraph 框架执行您的 Agent Spec 智能体。
- 在 `AgentSpecAgent` 包装器中，`AgUiSpanProcessor` 将 Agent Spec 追踪跨度映射到每个请求队列（`EVENT_QUEUE`）的 AG-UI 事件。
- FastAPI 端点将这些事件作为 SSE 流式传输供 CopilotKit 渲染：
  - 助手文本：`TEXT_MESSAGE_START/CONTENT/END`
  - 工具调用：`TOOL_CALL_START/ARGS/END` 和 `TOOL_CALL_RESULT`
  - 生命周期：`RUN_STARTED/RUN_FINISHED`

## 故障排除

- 端点路径必须匹配您的 UI 预期的智能体端点（入门仓库中为 8000 端口）。
- 端点断言队列已绑定。如果收到队列错误，请检查请求是否通过提供的 FastAPI 路由。
- 如果没有收到任何事件，请确保智能体正在运行且没有崩溃。
