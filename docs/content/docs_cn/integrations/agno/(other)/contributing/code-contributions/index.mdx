我们非常感谢你对贡献 CopilotKit 的兴趣。我们欢迎新的贡献者，并感谢你的帮助使 CopilotKit 变得更好。

本指南将帮助你尽可能顺利地开始。

## 第 1 步：安装前提条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- [pnpm](https://pnpm.io/) v9.x 全局安装 (`npm i -g pnpm@^9`)
- [Turborepo v2.x](https://turborepo.org/) 全局安装 (`npm i -g turbo@2`)

## 第 2 步：仓库设置

<Steps>
  <Step>
  ### Fork 仓库
  首先，前往 [CopilotKit 仓库](https://github.com/CopilotKit/CopilotKit) 并创建一个 fork。

  然后，将你的 fork 克隆到你的本地机器：
  ```bash
  git clone https://github.com/<your-username>/CopilotKit
  cd CopilotKit
  ```
  </Step>
  <Step>
  ### 安装依赖
  <Callout type="info">
    CopilotKit 仓库是一个基于 [Turborepo](https://turborepo.org/) 的 monorepo。
    我们使用 [pnpm](https://pnpm.io/) 作为我们的包管理器。
  </Callout>

  使用 pnpm 安装依赖：
  ```bash
  pnpm install
  ```
  </Step>
  <Step>
  ### 构建包
  为了确保一切正常工作，让我们先构建所有包：
  ```bash
  turbo run build
  ```
  </Step>
</Steps>

## 第 3 步：开发模式
现在一切设置完成并按预期工作，你可以开始开发了：

```bash
# 以开发模式启动所有包
turbo run dev

# 以开发模式启动特定包
turbo run dev --filter="@copilotkit/package-name"
```

现在你可以开始对代码进行修改。

<Callout type="info">
你可以在 monorepo 的 `packages` 文件夹下找到所有 `@copilotkit/*` 包。
</Callout>

## 第 4 步：实时测试更改

在大多数情况下，你希望在开发时能够无缝地实时测试你的更改。

我们在 monorepo 中有一个 `examples` 文件夹，其中包含几个使用 CopilotKit 的不同示例。你可以运行这些示例以测试你的更改，因为它们已链接到 monorepo 中的 `@copilotkit/*` 包。

在本教程中，我们将使用 `next-openai` 示例，特别是 Presentation Demo (`/presentation`)。

在单独的终端中，运行以下命令以启动示例：

```bash
cd examples/next-openai
export OPENAI_API_KEY=<your-openai-api-key>
pnpm run example-dev
```

<Callout type="info">
我们使用 `pnpm run example-dev` 命令来运行示例，这与我们用于处理单个包的 `turbo run dev` 命令不同。
</Callout>

现在导航到 http://localhost:3000/presentation，你应该会看到示例正在运行。你对 CopilotKit 包所做的任何更改都将立即反映在这里。

## 第 5 步：格式化和代码检查

在提交更改之前，通过在 monorepo 的根目录运行以下命令确保你的文件已正确格式化：
```bash
turbo run format
```

此外，确保你没有代码检查错误：
```bash
turbo run lint
```

## 第 6 步：提交 Pull Request

现在你已经完成了更改，提交并推送它们。然后，只需前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls) 并创建一个 pull request。做得好！

## 使用热重载启动开发环境

CopilotKit 包含一个现成的脚本，用于基于 CoAgent 示例之一启动开发环境。它可以让你在开发核心 TypeScript 和 Python 代码的同时，看到你的更改应用于所选示例。

作为前提条件，请确保你已安装 GNU parallel 和 langgraph CLI。

接下来，进入 `CopilotKit/` 目录并运行你想要处理的示例的 `example.sh` 脚本：

```bash
./scripts/develop/example.sh coagents-starter
```

这将启动一个具有热重载功能的开发环境。

你可以通过运行以下命令选择在 LangGraph 平台上运行相同的示例：

```bash
./scripts/develop/example.sh coagents-starter langgraph-platform
```

## 调试

每次在 localhost 上运行 CopilotKit 时，你都可以在聊天窗口中看到 **CopilotKit 开发控制台**。开发控制台为你提供了调试 copilot 的有用功能（例如，查看 copilot 知道什么状态、可以执行什么操作等）。

<Frame description="CopilotKit Dev Console">
  <img
    src="https://cdn.copilotkit.ai/docs/copilotkit/images/contributing/copilotkit-dev-console.png"

  />
</Frame>

如果你想在本地禁用开发控制台，只需在你的 `<CopilotKit />` provider 中将 `showDevConsole` 设置为 `false`。

## （高级）包链接

在某些情况下，你想在你自己的项目中测试你的 CopilotKit 更改。例如，你尝试将 CopilotKit 集成到你自己的代码库中并遇到了想要修复的错误。

方便的是，你可以将你本地的 CopilotKit 包链接到你自己的项目以测试你的更改。

查看[高级：包链接](/contributing/code-contributions/package-linking)指南以了解如何操作。
