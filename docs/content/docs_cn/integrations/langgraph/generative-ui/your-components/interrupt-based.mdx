## 这是什么？

[LangGraph 的中断流程](https://docs.langchain.com/oss/python/langgraph/interrupts)提供了一种直观的方式来实现人机协同工作流。

本指南将向你展示如何使用 `interrupt` 以及如何将其与 CopilotKit 集成。

## 什么时候使用？

人机协同是实现生产就绪复杂工作流的强大方式。通过在循环中加入人工，你可以确保智能体始终做出正确的决策，并最终朝着正确的方向前进。

基于中断的流程是实现人机协同的非常直观的方式。节点可以在执行过程中中断以允许用户输入，而不是在执行前后等待用户输入。权衡是智能体不会意识到交互，然而 [CopilotKit 的 SDK 提供了辅助工具来缓解这个问题](#让智能体意识到中断)。

    ### 在你的 LangGraph 智能体中调用 `interrupt`
    现在我们可以在 LangGraph 智能体中调用 `interrupt`。

    <Callout type="info">
        默认情况下，你的智能体不会意识到 LangGraph 中的 `interrupt` 交互。

    <Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
        <Tab value="Python">
            ```python title="agent.py"
            from langgraph.types import interrupt # [!code highlight]
            from langchain_core.messages import SystemMessage
            from langchain_openai import ChatOpenAI
            from copilotkit import CopilotKitState

            # 添加上一步的智能体状态定义
            class AgentState(CopilotKitState):
                agent_name: str

            def chat_node(state: AgentState, config: RunnableConfig):
                if not state.get("agent_name"):
                    # 中断并等待用户回复名称
                    state["agent_name"] = interrupt("在我们开始之前，你想叫我什么？") # [!code highlight]

                # 告诉智能体它的名称
                system_message = SystemMessage(
                    content=f"你是一个有用的助手，名叫 {state.get('agent_name')}..."
                )

                response = ChatOpenAI(model="gpt-5.2").invoke(
                    [system_message, *state["messages"]],
                    config
                )

                return {
                    **state,
                    "messages": response,
                }
            ```
        </Tab>

            import { interrupt } from "@langchain/langgraph"; // [!code highlight]
            import { SystemMessage } from "@langchain/core/messages";
            import { ChatOpenAI } from "@langchain/openai";

            export const AgentStateAnnotation = Annotation.Root({

                ...CopilotKitStateAnnotation.spec,

            export type AgentState = typeof AgentStateAnnotation.State;

            async function chat_node(state: AgentState, config: RunnableConfig) {
                const agentName = state.agentName

                const systemMessage = new SystemMessage({

                    config

                    ...state,
                    agentName,
                    messages: response,
                };

<Step>
    ### 在你的前端处理中断
    此时，你的 LangGraph 智能体的 `interrupt` 将被调用。但是，我们目前在前端没有处理中断的渲染或响应。

    为此，我们将使用 `useInterrupt` 钩子，给它一个渲染组件，然后调用 `resolve` 并传入用户的响应。

    ```tsx title="app/page.tsx"
    import { useInterrupt } from "@copilotkit/react-core/v2"; // [!code highlight]
    // ...

    const YourMainContent = () => {
    // ...
    // [!code highlight:15]
    // 为简洁起见省略样式
    useInterrupt({
        render: ({ event, resolve }) => (
            <div>
                <p>{event.value}</p>
                <form onSubmit={(e) => {
                    e.preventDefault();
                    resolve((e.target as HTMLFormElement).response.value);
                }}>
                    <input type="text" name="response" placeholder="输入你的响应" />
                    <button type="submit">提交</button>
                </form>
            </div>
        )
    });
    // ...

    return <div>{/* ... */}</div>
    }
    ```

## 高级用法

### 条件 UI 执行

当在智能体中渲染多个 `interrupt` 事件时，UI 中多个 `useInterrupt` 钩子调用之间可能存在冲突。
因此，该钩子可以接受一个 `enabled` 参数，用于条件应用：

<Steps>
    <Step>
        ### 定义多个中断
        首先，让我们定义两个不同的中断。我们将包含一个 "type" 属性来区分它们。

                    content=f"你是一个有用的助手..."

                    config

                  return {
                    ...state,
                    messages: response,
                  };
                }

        ### 添加多个前端处理程序
        考虑到区分器，我们将添加一个处理程序来处理任何 "ask" 和任何 "approve" 类型。
        在我们的页面中使用两个 `useInterrupt` 钩子，我们可以利用 `enabled` 属性在正确的时间启用每个钩子：

        ```tsx title="app/page.tsx"
        import { useInterrupt } from "@copilotkit/react-core/v2"; // [!code highlight]
        // ...

        const ApproveComponent = ({ content, onAnswer }: { content: string; onAnswer: (approved: boolean) => void }) => (
            // 为简洁起见省略样式
            <div>
                <h1>你批准吗？</h1>
                <button onClick={() => onAnswer(true)}>批准</button>
                <button onClick={() => onAnswer(false)}>拒绝</button>
            </div>
        )

        const AskComponent = ({ question, onAnswer }: { question: string; onAnswer: (answer: string) => void }) => (
        // 为简洁起见省略样式
            <div>
                <p>{question}</p>
                <form onSubmit={(e) => {
                    e.preventDefault();
                    onAnswer((e.target as HTMLFormElement).response.value);
                }}>
                    <input type="text" name="response" placeholder="输入你的响应" />
                    <button type="submit">提交</button>
                </form>
            </div>
        )

        const YourMainContent = () => {
            // ...
            // [!code highlight:13]
            useInterrupt({
                enabled: ({ eventValue }) => eventValue.type === 'ask',
                render: ({ event, resolve }) => (
                    <AskComponent question={event.value.content} onAnswer={answer => resolve(answer)} />
                )
            });

            useInterrupt({
                enabled: ({ eventValue }) => eventValue.type === 'approval',
                render: ({ event, resolve }) => (
                    <ApproveComponent content={event.value.content} onAnswer={answer => resolve(answer)} />
                )
            });

            // ...
        }
    ```

### 中断的预处理和编程处理中断值

当选择自定义聊天 UI 时，某些情况可能需要对传入的中断事件值进行预处理，甚至完全解决它而不显示 UI。
这可以使用 `handler` 属性实现，该属性不需要返回 React 组件。

处理程序的返回值将作为 `result` 参数传递给 `render` 方法。
```tsx title="app/page.tsx"
// 我们假设中断事件的形状如下
type Department = 'finance' | 'engineering' | 'admin'
interface AuthorizationInterruptEvent {
    type: 'auth',
    accessDepartment: Department,
}

import { useInterrupt } from "@copilotkit/react-core/v2";

const YourMainContent = () => {
    const [userEmail, setUserEmail] = useState({ email: 'example@user.com' })
    function getUserByEmail(email: string): { id: string; department: Department } {
        // ... 用户获取的实现
    }

    // ...
    // 为简洁起见省略样式
    // [!code highlight:28]
    useInterrupt({
        handler: async ({ result, event, resolve }) => {
            const { department } = await getUserByEmail(userEmail)
            if (event.value.accessDepartment === department || department === 'admin') {
                // 解决事件后，我们不会继续到 render 方法
                resolve({ code: 'AUTH_BY_DEPARTMENT' })
                return;
            }

            return { department, userId }
        },
        render: ({ result, event, resolve }) => (
            <div>
                <h1>{event.value.type} 请求</h1>
                <p>{result.department} 部门的成员无法访问此信息</p>
                <p>你可以向管理员请求访问权限以继续。</p>
                <button
                    onClick={() => resolve({ code: 'REQUEST_AUTH', data: { department: result.department, userId: result.userId } })}
                >
                    请求访问
                </button>
                <button
                    onClick={() => resolve({ code: 'CANCEL' })}
                >
                    取消
                </button>
            </div>
        )
    });
    // ...

    return <div>{/* ... */}</div>
}
```
