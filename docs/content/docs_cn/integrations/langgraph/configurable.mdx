## 这是什么？
LangGraph 智能体能够接收执行参数，例如认证令牌和类似的属性。你可以使用此功能添加这些参数。

如果你想了解更多，可以参考 [LangGraph 的配置指南](https://docs.langchain.com/oss/python/langgraph/graph-api#add-runtime-configuration)

## 什么时候使用？

当你想要发送执行时的配置信息（例如不同会话的不同令牌或元数据）且这些信息不应属于智能体状态时，此功能非常有用。

## 实现

默认情况下，LangGraph 智能体使用 `config` 参数调用。此配置具有一个 `configurable` 属性，可以访问并填充你的数据。

<Steps>
<Step>
### 从前端传递配置
首先，按照你希望在智能体中接收的方式传递配置属性

```tsx title="app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

function YourMainContent() {
  // ...

  // [!code highlight:3]
  const { agent } = useAgent({
    agentId: "sample_agent",
  });

  // 运行智能体时传递配置
  // [!code highlight:8]
  agent.runAgent({
    forwardedProps: {
      config: {
        configurable: {
          authToken: 'example-token'
        },
        recursion_limit: 50,
      }
    }
  });

  // ...

  return (... 你的组件 UI 标记)
}
```
</Step>
<Step>
### 在智能体中使用可配置项
现在你可以在任何智能体节点中从提供的 config 参数中拉取值

<Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
    <Tab value="Python">
        ```python
        async def agent_node(state: AgentState, config: RunnableConfig):

            auth_token = config['configurable'].get('authToken', None)

            return state
        ```
    </Tab>
    <Tab value="TypeScript">
        ```typescript
        async function agentNode(state: AgentState, config: RunnableConfig): Promise<AgentState> {
            const authToken = config.configurable?.authToken ?? null;

            return state;
        }
        ```
    </Tab>
</Tabs>
</Step>
<Step>
    ### 可选：定义可配置项模式
    如果你愿意，可以定义一个模式来指示你希望接收哪些可配置项。
    任何传递给 "configurables" 但未包含在模式中的项目将被过滤掉。

    你可以阅读更多关于此的内容 [此处](https://docs.langchain.com/oss/python/langgraph/graph-api#add-runtime-configuration%23define-graph)。
    <Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
        <Tab value="Python">
            ```python
            from typing import TypedDict

            # 定义配置中允许哪些属性
            class ConfigSchema(TypedDict):
              authToken: str

            # ...添加所有必要的图节点

            # 定义状态图时，应用配置模式
            workflow = StateGraph(AgentState, config_schema=ConfigSchema)
            ```
        </Tab>
        <Tab value="TypeScript">
            ```typescript
            import { Annotation } from "@langchain/langgraph";

            // 定义配置中允许哪些属性
            export const ConfigSchemaAnnotation = Annotation.Root({
              authToken: Annotation<string>
            })

            // ...添加所有必要的图节点

            // 定义状态图时，应用配置模式
            const workflow = new StateGraph(AgentStateAnnotation, ConfigSchemaAnnotation)
            ```
        </Tab>
    </Tabs>
</Step>
</Steps>
