CopilotKit 提供三个预构建的聊天组件，直接连接到你的 LangGraph 智能体。每个都是 `CopilotChat` 的包装器，具有不同的布局——选择适合你应用的组件即可。

</Callout>

## 设置

在你的根布局中导入默认样式：

```tsx title="layout.tsx"
import "@copilotkit/react-ui/v2/styles.css";
```

### CopilotChat

一个灵活的聊天组件，可以放置在你应用的任何地方并按需调整大小。

```tsx title="page.tsx"
// [!code word:CopilotChat]
import { CopilotChat } from "@copilotkit/react-core/v2";

export function YourComponent() {
  return (
    <CopilotChat
      labels={{
        modalHeaderTitle: "你的助手",
        welcomeMessageText: "你好！今天我能帮你什么？",
      }}
    />
  );
}
```

<img src="https://cdn.copilotkit.ai/docs/copilotkit/images/copilotchat-example.gif" alt="CopilotChat 示例" className="w-full rounded-lg my-4" />

### CopilotSidebar

包装你的主内容并提供一个可折叠的侧边栏聊天。

```tsx title="page.tsx"
// [!code word:CopilotSidebar]
import { CopilotSidebar } from "@copilotkit/react-core/v2";

export function YourApp() {
  return (
    <CopilotSidebar
      defaultOpen={true}
      labels={{
        modalHeaderTitle: "侧边栏助手",
        welcomeMessageText: "今天我能帮你什么？",
      }}
    >
      <YourMainContent />
    </CopilotSidebar>
  );
}
```

<img src="https://cdn.copilotkit.ai/docs/copilotkit/images/sidebar-example.gif" alt="CopilotSidebar 示例" className="w-full rounded-lg my-4" />


### CopilotPopup

一个浮动聊天气泡，位于你的内容旁边，可以打开/关闭。

```tsx title="page.tsx"
// [!code word:CopilotPopup]
import { CopilotPopup } from "@copilotkit/react-core/v2";

export function YourApp() {
  return (
    <>
      <YourMainContent />
      <CopilotPopup
        labels={{
          modalHeaderTitle: "弹出助手",
          welcomeMessageText: "需要帮助吗？",
        }}
      />
    </>
  );
}
```

## 自定义

所有三个组件都支持[插槽系统](/langgraph/custom-look-and-feel/slots)进行深度定制——从 Tailwind 类到完整组件替换：

```tsx title="page.tsx"
<CopilotChat
  // 使用 Tailwind 类设置插槽样式
  input={{
    textArea: "text-lg",
    sendButton: "bg-blue-600 hover:bg-blue-700",
  }}
  // 自定义嵌套消息插槽
  messageView={{
    assistantMessage: {
      className: "bg-gray-50 rounded-xl p-4",
      toolbar: "border-t mt-2",
    },
    userMessage: "bg-blue-100 rounded-xl",
  }}
  // 通过返回 null 隐藏元素
  scrollView={{
    feather: () => null,
  }}
/>
```
