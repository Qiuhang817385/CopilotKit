## 这是什么？

工具是 LLM 调用预定义的、通常是确定性函数的一种方式。CopilotKit 允许您在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 什么时候使用这个？

当您的智能体调用工具时，如果您想向用户提供关于智能体正在做什么的反馈，那么在 UI 中渲染工具会很有用。CopilotKit 允许您完全自定义这些工具在聊天中的渲染方式。

### 给您的智能体一个可调用的工具

在您的 Strands 智能体中定义一个工具：

```python title="main.py"
import os
from strands import Agent, tool
from strands.models.openai import OpenAIModel
from ag_ui_strands import StrandsAgent, create_strands_app

@tool
def get_weather(location: str) -> dict:
    """
    获取某个位置的天气信息。

    Args:
        location: 要获取天气的位置

    Returns:
        包含温度和天气状况的天气数据
    """
    # 模拟天气数据（在生产环境中，调用真实的天气 API）
    return {
        "temperature": 72,
        "conditions": "晴朗",
        "humidity": 45,
        "wind_speed": 8
    }

# 设置您的 Strands 智能体
api_key = os.getenv("OPENAI_API_KEY", "")
model = OpenAIModel(
    client_args={"api_key": api_key},
    model_id="gpt-5.2",
)

agent = Agent(
    model=model,
    system_prompt="您是一个可以获取天气信息的 helpful 助手。",
    tools=[get_weather],  # [!code highlight]
)

# 使用 AG-UI 集成进行包装
agui_agent = StrandsAgent(
    agent=agent,
    name="weather_agent",
    description="一个 helpful 的天气助手",
)

# 创建 FastAPI 应用
app = create_strands_app(agui_agent, "/")
```

</Step>

<Step>
### 在您的前端中渲染工具调用

现在我们将使用 `useRenderTool` 钩子来在 UI 中使用自定义组件渲染工具调用。

<Callout type="info" title="重要">
  `useRenderTool` 中的工具名称必须与在您的智能体中定义的工具名称匹配。
</Callout>

```tsx title="app/page.tsx"
"use client";

import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
import { CopilotSidebar } from "@copilotkit/react-core/v2";

export default function Page() {
  // [!code highlight:41]
  useRenderTool({
    name: "get_weather",
    parameters: [
      {
        name: "location",
        description: "要获取天气的位置",
        required: true,
      },
    ],
    render: ({ status, args, result }) => {
      if (status === "executing") {
        return (
          <div className="p-4 bg-blue-50 rounded-lg">
            <p className="text-sm text-blue-600">
              正在获取 {args.location} 的天气...
            </p>
          </div>
        );
      }

      if (status === "complete" && result) {
        const weather = result;
        return (
          <div className="p-4 bg-white border rounded-lg shadow-sm">
            <h3 className="font-semibold text-lg mb-2">
              {args.location} 的天气
            </h3>
            <div className="space-y-1 text-sm">
              <p>🌡️ 温度：{weather.temperature}°F</p>
              <p>☁️ 天气状况：{weather.conditions}</p>
              <p>💧 湿度：{weather.humidity}%</p>
              <p>💨 风速：{weather.wind_speed} mph</p>
            </div>
          </div>
        );
      }

      return null;
    },
  });

  return (
    <main>
      <CopilotSidebar />
    </main>
  );
}
```

## 高级：在执行期间访问工具参数

您可以在工具仍在执行时访问工具参数：

```tsx
useRenderTool({
  name: "get_weather",
  parameters: [
    {
      name: "location",
      description: "要获取天气的位置",
      required: true,
    },
  ],
  render: ({ status, args, result }) => {
    // 即使状态为 "executing"，args 也是立即可用的
    const location = args.location;

    return (
      <div className="p-4 bg-blue-50 rounded-lg">
        {status === "executing" && (
          <p>正在获取 {location} 的天气...</p>
        )}
        {status === "complete" && result && (
          <p>{location} 的天气：{result.temperature}°F</p>
        )}
      </div>
    );
  },
});
```
