## 概述

`useRenderTool` 为工具调用注册聊天渲染器。
您可以定位特定工具名称（使用类型化的 Zod `parameters` 模式）或使用通配符（`"*"`）回退渲染器。

这是 v2 工具渲染 Hook 集的一部分，包括 [`useComponent`](/reference/v2/hooks/useComponent)、[`useDefaultRenderTool`](/reference/v2/hooks/useDefaultRenderTool) 和 [`useRenderToolCall`](/reference/v2/hooks/useRenderToolCall)。

此 Hook 仅处理渲染。它不注册前端处理程序。

## 签名

### 通配符重载

```tsx
import { useRenderTool } from "@copilotkit/react-core/v2";

useRenderTool(
  {
    name: "*",
    render: (props) => React.ReactElement,
    agentId?: string,
  },
  deps?: ReadonlyArray<unknown>,
);
```

### 命名重载

```tsx
import { z } from "zod";
import { useRenderTool } from "@copilotkit/react-core/v2";

useRenderTool(
  {
    name: string,
    parameters: z.ZodTypeAny,
    render: (props) => React.ReactElement,
    agentId?: string,
  },
  deps?: ReadonlyArray<unknown>,
);
```

## 渲染 Props

`render` 接收以下状态之一：

- `{ status: "inProgress", parameters: Partial<T>, result: undefined }`
- `{ status: "executing", parameters: T, result: undefined }`
- `{ status: "complete", parameters: T, result: string }`

`name` 始终存在于所有状态中。

## 行为

- 使用 `defineToolCallRenderer` 构建渲染器条目。
- 通过 `agentId:name` 键去重（最新注册获胜）。
- 故意不在清理时移除渲染器，以便之前的聊天历史记录仍然可以渲染。
- 通过 `config.name` 加上 `deps` 中的值跟踪更新（在 `deps` 中包含变化的捕获）。

## 用法

### 命名工具渲染器

```tsx
import { z } from "zod";
import { useRenderTool } from "@copilotkit/react-core/v2";

function App() {
  useRenderTool(
    {
      name: "searchDocs",
      parameters: z.object({ query: z.string() }),
      render: ({ name, parameters, status, result }) => {
        if (status === "inProgress") return <div>正在准备 {name}…</div>;
        if (status === "executing") return <div>正在搜索：{parameters.query}</div>;
        return <div>完成：{result}</div>;
      },
    },
    [],
  );

  return null;
}
```

### 通配符回退渲染器

```tsx
import { useRenderTool } from "@copilotkit/react-core/v2";

function App() {
  useRenderTool(
    {
      name: "*",
      render: ({ name, status }) => (
        <div>
          {status === "complete" ? "✓" : "⏳"} {name}
        </div>
      ),
    },
    [],
  );

  return null;
}
```
