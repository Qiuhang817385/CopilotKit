## 概述

`useHumanInTheLoop` 注册一个暂停 Agent 执行直到用户通过自定义 UI 响应的交互式工具。与 `useFrontendTool` 不同，它没有 `handler` 函数。相反，Hook 提供内部状态机（`InProgress` -> `Executing` -> `Complete`），并在工具处于 `Executing` 状态时向渲染组件提供 `respond` 回调。Agent 保持暂停状态直到使用用户的输入调用 `respond`。

此 Hook 基于 `useFrontendTool` 构建，带有内部管理的处理程序，当调用 `respond` 时解析工具调用 promise。将其用于确认对话框、审批工作流、表单收集或任何需要人工提供输入 Agent 才能继续的场景。

## 签名

```tsx
import { useHumanInTheLoop } from "@copilotkit/react-core/v2";

function useHumanInTheLoop<T extends Record<string, unknown>>(
  tool: ReactHumanInTheLoop<T>,
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

<PropertyReference name="tool" type="ReactHumanInTheLoop<T>" required>
  交互式工具定义。

  <PropertyReference name="name" type="string" required>
    工具的唯一名称。当 Agent 需要人工输入时引用此名称。
  </PropertyReference>

  <PropertyReference name="description" type="string" required>
    告诉 Agent 工具做什么以及何时调用它的自然语言描述（例如，"在删除记录之前询问用户确认"）。
  </PropertyReference>

  <PropertyReference name="parameters" type="z.ZodSchema" required>
    定义 Agent 传递给工具的参数的 Zod 模式。这些参数会转发到渲染组件，因此您可以构建上下文感知的 UI。
  </PropertyReference>

  <PropertyReference name="render" type="React.ComponentType<RenderProps>" required>
    驱动人工交互的 React 组件。组件根据当前状态接收不同的 props：

    **当 `status` 为 `ToolCallStatus.InProgress` 时：**
    - `args: Partial<T>` -- 部分流式传输的参数
    - `respond: undefined` -- 尚不可用
    - `result: undefined`

    **当 `status` 为 `ToolCallStatus.Executing` 时：**
    - `args: T` -- 完全解析的参数
    - `respond: (result: unknown) => Promise<void>` -- 调用此函数将用户的响应发送回 Agent 并恢复执行
    - `result: undefined`

    **当 `status` 为 `ToolCallStatus.Complete` 时：**
    - `args: T` -- 原始参数
    - `respond: undefined` -- 不再可用
    - `result: string` -- 序列化结果
  </PropertyReference>

  <PropertyReference name="available" type='"enabled" | "disabled" | "remote"' default='"enabled"'>
    控制工具可用性。设置为 `"disabled"` 以暂时阻止 Agent 通过此工具请求人工输入。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="ReadonlyArray<unknown>">
  可选的依赖数组。提供时，当数组中的任何值更改时，工具注册会刷新。
</PropertyReference>

## 用法

### 确认对话框

Agent 要求用户确认破坏性操作的常见模式。

```tsx
import { z } from "zod";
import { useHumanInTheLoop, ToolCallStatus } from "@copilotkit/react-core/v2";

function DeleteConfirmation() {
  useHumanInTheLoop({
    name: "confirmDeletion",
    description: "在删除项目之前询问用户确认",
    parameters: z.object({
      itemName: z.string().describe("要删除的项目名称"),
      itemCount: z.number().describe("要删除的项目数量"),
    }),
    render: ({ args, status, respond, result }) => {
      if (status === ToolCallStatus.InProgress) {
        return <div className="p-4 text-gray-500">正在准备确认...</div>;
      }

      if (status === ToolCallStatus.Executing && respond) {
        return (
          <div className="p-4 border rounded">
            <p>
              您确定要删除 {args.itemCount} 个 {args.itemName} 吗？
            </p>
            <div className="flex gap-2 mt-4">
              <button
                onClick={() => respond({ confirmed: true })}
                className="bg-red-500 text-white px-4 py-2 rounded"
              >
                删除
              </button>
              <button
                onClick={() => respond({ confirmed: false })}
                className="bg-gray-300 px-4 py-2 rounded"
              >
                取消
              </button>
            </div>
          </div>
        );
      }

      if (status === ToolCallStatus.Complete && result) {
        const parsed = JSON.parse(result);
        return (
          <div className="p-2 text-sm text-gray-600">
            {parsed.confirmed ? "项目已删除。" : "删除已取消。"}
          </div>
        );
      }

      return null;
    },
  }, []);

  return null;
}
```

### 表单输入收集

在 Agent 继续之前从用户收集结构化输入。

```tsx
import { useState } from "react";
import { z } from "zod";
import { useHumanInTheLoop, ToolCallStatus } from "@copilotkit/react-core/v2";

function ShippingAddressForm() {
  useHumanInTheLoop({
    name: "collectShippingAddress",
    description: "在下订单之前从用户收集送货地址",
    parameters: z.object({
      orderSummary: z.string().describe("正在下的订单摘要"),
    }),
    render: ({ args, status, respond }) => {
      const [address, setAddress] = useState({
        street: "",
        city: "",
        zip: "",
      });

      if (status === ToolCallStatus.Executing && respond) {
        return (
          <div className="p-4 border rounded space-y-3">
            <p className="font-medium">订单：{args.orderSummary}</p>
            <p>请输入您的送货地址：</p>
            <input
              placeholder="街道地址"
              value={address.street}
              onChange={(e) => setAddress({ ...address, street: e.target.value })}
              className="w-full border p-2 rounded"
            />
            <input
              placeholder="城市"
              value={address.city}
              onChange={(e) => setAddress({ ...address, city: e.target.value })}
              className="w-full border p-2 rounded"
            />
            <input
              placeholder="邮政编码"
              value={address.zip}
              onChange={(e) => setAddress({ ...address, zip: e.target.value })}
              className="w-full border p-2 rounded"
            />
            <button
              onClick={() => respond(address)}
              className="bg-blue-500 text-white px-4 py-2 rounded"
            >
              提交地址
            </button>
          </div>
        );
      }

      if (status === ToolCallStatus.Complete) {
        return <div className="p-2 text-green-600">送货地址已提交。</div>;
      }

      return null;
    },
  }, []);

  return null;
}
```

### 带上下文的审批工作流

```tsx
import { z } from "zod";
import { useHumanInTheLoop, ToolCallStatus } from "@copilotkit/react-core/v2";

function ExpenseApproval() {
  useHumanInTheLoop({
    name: "approveExpense",
    description: "请求经理批准费用报告",
    parameters: z.object({
      employeeName: z.string().describe("员工姓名"),
      amount: z.number().describe("费用金额（美元）"),
      category: z.string().describe("费用类别"),
      description: z.string().describe("费用描述"),
    }),
    render: ({ args, status, respond, result }) => {
      if (status === ToolCallStatus.Executing && respond) {
        return (
          <div className="p-4 border rounded">
            <h3 className="font-bold">需要费用审批</h3>
            <div className="mt-2 space-y-1 text-sm">
              <p>员工：{args.employeeName}</p>
              <p>金额：${args.amount.toFixed(2)}</p>
              <p>类别：{args.category}</p>
              <p>描述：{args.description}</p>
            </div>
            <div className="flex gap-2 mt-4">
              <button
                onClick={() => respond({ approved: true })}
                className="bg-green-500 text-white px-4 py-2 rounded"
              >
                批准
              </button>
              <button
                onClick={() => respond({ approved: false, reason: "需要更多细节" })}
                className="bg-red-500 text-white px-4 py-2 rounded"
              >
                拒绝
              </button>
            </div>
          </div>
        );
      }

      if (status === ToolCallStatus.Complete && result) {
        const parsed = JSON.parse(result);
        return (
          <div className={`p-2 text-sm ${parsed.approved ? "text-green-600" : "text-red-600"}`}>
            {parsed.approved ? "费用已批准。" : `费用被拒绝：${parsed.reason}`}
          </div>
        );
      }

      return null;
    },
  }, []);

  return null;
}
```

## 行为

- **阻止 Agent 执行**：当调用此工具时，Agent 暂停并等待调用 `respond` 回调后才能继续。
- **内部状态机**：Hook 管理三种状态 -- `InProgress`（参数正在流式传输）、`Executing`（等待用户响应）和 `Complete`（用户已响应）。您的渲染组件接收每个状态的适当 props。
- **单次响应**：`respond` 回调每个工具调用应仅调用一次。调用它会使用提供的值解析工具调用 promise。
- **基于 `useFrontendTool` 构建**：在底层，此 Hook 包装 `useFrontendTool` 并带有内部生成的处理程序，因此所有相同的生命周期行为（挂载/卸载注册、重复警告）都适用。
- **挂载/卸载生命周期**：工具和渲染组件在挂载时注册，在卸载时移除。
- **无返回值**：Hook 返回 `void`。

- [`ToolCallStatus`](#toolcallstatus) -- 跨工具 Hooks 使用的状态枚举

## ToolCallStatus

`ToolCallStatus` 枚举从 `@copilotkit/react-core/v2` 导出，定义工具执行的三个阶段：

| 值 | 描述 |
|-------|-------------|
| `ToolCallStatus.InProgress` | 参数正从 Agent 流式传输。工具尚未开始执行。 |
| `ToolCallStatus.Executing` | 参数已完全解析。对于 `useHumanInTheLoop`，`respond` 回调可用。 |
| `ToolCallStatus.Complete` | 执行完成。`result` 字符串可用。 |
