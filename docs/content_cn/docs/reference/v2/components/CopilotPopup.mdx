## 概述

`CopilotPopup` 渲染一个带切换按钮的浮动聊天弹出窗口。它包装 [`CopilotChat`](/reference/v2/components/CopilotChat) 并提供特定于弹出窗口的布局、大小和打开/关闭行为。弹出窗口包含一个带标题和关闭按钮的头部，可以通过点击外部关闭。

有关此组件的侧边栏变体，请参见 [`CopilotSidebar`](/reference/v2/components/CopilotSidebar)。

## 导入

```tsx
import { CopilotPopup } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## Props

### 自有 Props

<PropertyReference name="header" type="SlotValue<typeof CopilotModalHeader>">
  弹出窗口头部的插槽覆盖。接受替换组件、通过 `twMerge` 合并到默认类中的 `className` 字符串，或 partial props 对象。默认头部显示标题和关闭按钮。
</PropertyReference>

<PropertyReference name="defaultOpen" type="boolean" default="false">
  弹出窗口在组件首次挂载时是否应打开。
</PropertyReference>

<PropertyReference name="width" type="number | string">
  弹出窗口面板的宽度。接受数字（像素）或 CSS 字符串（例如 `"400px"`、`"30vw"`）。
</PropertyReference>

<PropertyReference name="height" type="number | string">
  弹出窗口面板的高度。接受数字（像素）或 CSS 字符串（例如 `"600px"`、`"80vh"`）。
</PropertyReference>

<PropertyReference name="clickOutsideToClose" type="boolean" default="true">
  点击弹出窗口面板外部是否关闭它。
</PropertyReference>

### 继承的 CopilotChat Props

`CopilotPopup` 接受 [`CopilotChatProps`](/reference/v2/components/CopilotChat) 的所有 props，**除了** `chatView`，它在内部设置为 `CopilotPopupView`。这包括：

<PropertyReference name="agentId" type="string">
  要使用的 Agent ID。必须与 `CopilotKitProvider` 中配置的 Agent 匹配。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  对话线程的 ID。
</PropertyReference>

<PropertyReference name="labels" type="Partial<CopilotChatLabels>">
  聊天内所有渲染文本字符串的部分标签覆盖。
</PropertyReference>

<PropertyReference name="autoScroll" type="boolean" default="true">
  当新消息到达时，聊天是否自动滚动到底部。
</PropertyReference>

<PropertyReference name="inputProps" type="Partial<Omit<CopilotChatInputProps, 'children'>>">
  转发到内部 `CopilotChatInput` 组件的额外 props。
</PropertyReference>

<PropertyReference name="welcomeScreen" type='SlotValue<React.FC<WelcomeScreenProps>> | boolean'>
  控制没有消息时显示的欢迎屏幕。
</PropertyReference>

所有 `CopilotChatView` 插槽 props（`messageView`、`input`、`scrollView`、`inputContainer`、`feather`、`disclaimer`、`suggestionView`）也都被接受并转发。

## 插槽系统

所有插槽属性都遵循 CopilotKit v2 组件中使用的相同覆盖模式。每个插槽接受以下三种值类型之一：

| 值 | 行为 |
|-------|----------|
| **组件** | 完全替换默认组件。接收默认组件会接收的相同 props。 |
| **`className` 字符串** | 通过 `twMerge` 合并到默认组件的类列表中。 |
| **Partial props 对象** | 作为额外或覆盖 props 展开到默认组件中。 |

## 用法

### 基本用法

```tsx
import { CopilotPopup } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";

function App() {
  return (
    <CopilotPopup
      agentId="my-agent"
      labels={{ modalHeaderTitle: "助手" }}
    />
  );
}
```

### 自定义大小和默认打开

```tsx
import { CopilotPopup } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";

function App() {
  return (
    <CopilotPopup
      agentId="my-agent"
      defaultOpen={true}
      width={450}
      height="80vh"
      clickOutsideToClose={false}
    />
  );
}
```

### 自定义头部

```tsx
import { CopilotPopup } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";

function App() {
  return (
    <CopilotPopup
      agentId="my-agent"
      header="bg-blue-600 text-white"
    />
  );
}
```

## 行为

- **切换按钮**：渲染一个浮动切换按钮（通常在右下角），用于打开和关闭弹出窗口。该按钮在内部使用 `CopilotChatToggleButton`。
- **模态状态**：打开/关闭状态通过聊天配置上下文管理。`defaultOpen` prop 设置初始状态；之后，状态变化来自用户交互（切换按钮、关闭按钮、点击外部）。
- **点击外部**：当 `clickOutsideToClose` 为 `true`（默认）时，点击弹出窗口面板外部的任何位置都会关闭它。
- **布局**：弹出窗口在内部使用 `CopilotPopupView`，它提供了一个特定于弹出窗口的欢迎屏幕布局，欢迎消息垂直居中，建议在输入上方。
- **Agent 连接**：所有 Agent 连接（消息、运行状态、建议）都由父 `CopilotChat` 逻辑处理。
